# 주간 이벤트와 보스 통일 패치

## 출격과 보상

- 던전 선택은 일반 6개 + 챌린지 + 이번 주 이벤트, 총 8개다. 이벤트 카드는 실제 던전 이름을 표시한다.
- 기기 현지 시각 월요일 0시 기준 주간 키로 5개 이벤트 중 하나를 결정한다. 같은 주에는 새로고침이나 재접속해도 바뀌지 않는다. 서버 없는 오프라인 게임이므로 기기 시계 변경 방지는 제공하지 않는다.
- 주마다 일반 6종, 챌린지, 이벤트에서 각각 첫 보상을 받는다. 쉬움/보통 1장, 어려움 2장으로 최대 16장이다. 난이도 변경이나 결과 화면 재열기로 중복 지급되지 않는다.
- 이벤트 보상 슬롯은 다섯 던전이 공유한다. 비활성 이벤트의 보상 요청은 거부한다.
- **출격이 실제 시작된 주**에 보상을 귀속한다. 일요일 출발해 월요일에 마쳐도 출발 주의 보상을 받으며, 재도전 시 새 주의 이벤트로 갱신된다. 랜덤 수호자 확인창에서 기다렸다면 출격 버튼을 누른 시점 기준이다.
- 챌린지의 주간 티켓만 영구 저장한다. 런 중 얻은 유물, 업적, 최고 기록은 기존처럼 일반 모드의 영구 진행에 섞지 않는다.

## 이벤트 구성

| 던전 | 보스 | 일반몹의 특수 기믹 | 보스의 시각적 테마 |
|---|---|---|---|
| 디저트킹덤 | 하모니어스 | 분열 후 0.5초 무적. 둔화로 무적이 길어지지 않음 | 양옆 사탕 리본, 하트와 민트 꽃탄 |
| 용의둥지 | 골드드래곤 | 해저신전과 동일한 5초 반사탄 | 금빛 날개 부채꼴, 보석 고리 |
| 속삭임의동굴 | 에인션트소울 | 요정의 숲과 동일한 위치 예고 후 순간이동 | 넓은 틈이 있는 혼령 나선 |
| 봉인된대지 | 베히모스 | 자폭 반경 120, 1초 경고. 마도제국은 기존 82 / 0.75초 유지 | 통로를 먼저 보여주는 대지 파동 |
| 시간의도서관 | 시간의지배자 | 어둠의 신전과 동일한 3초 주기 대량 발사 | 시계 고리탄의 정지·재출발 |

보스는 체력에 따라 3개 페이즈를 사용한다. 모양·색·대칭으로 화려함을 만들되 느린 탄속과 넓은 고리 통로, 대지 파동의 1초 예고를 둔다. 탄수 상한 360은 유지한다. 정지된 시계탄도 실제 탄이므로 닿으면 위험하다.

오픈소스 동방풍 슈팅 [Taisei](https://github.com/taisei-project/taisei)의 [Perfect Freeze 패턴](https://github.com/taisei-project/taisei/blob/master/src/stages/stage1/spells/perfect_freeze.c)을 참고해 시간 정지/재출발의 리듬을 연구했다. 코드·이미지·음악은 복사하지 않고 이 게임의 엔진으로 새 패턴을 작성했다.

## 난이도 수치

- 기존 일반 6던전의 체력은 유지한다.
- 이벤트 5종은 모두 같은 단계 수치 5.35를 사용한다. 목록 번호 7~11을 그대로 난이도로 사용하지 않는다.
- 일반몹 단계 배율 1.40 (혼돈 1.35), 기본 일반몹 HP 91.5 (혼돈 88), 보스 기본 HP 18,200 (혼돈 17,000).
- 천계 일반몹 단계 배율 1.55 (기존 1.48), 아스테아 기본 HP 23,100 (기존 22,000).
- 실제 HP에는 기존 난이도·방·엘리트 보정이 적용된다. 소폭 높은 수치와 읽기 쉬운 탄막을 함께 적용했으며, 사람의 체감 난이도가 정확히 몇 퍼센트 높다는 뜻은 아니다.

## UI와 아트

- 랜덤 선택 문양의 박스를 이름 위 영역 중앙에 고정했다.
- 기적의증명은 아틀라스 셀 대신 실제 별 중심 기준으로 잘라 표시한다. 원본 전체 유물 시트는 변경하지 않는다.
- 8개 카드가 공통 높이·내용 순서를 사용한다. 짧은 화면에서는 카드 영역만 스크롤하고 난이도/확정 버튼을 유지한다.
- 아스테아 및 신규 5보스는 원화 디자인을 보존하며 게임용으로 재작화했다. 머리 크기를 기준으로 전체 배율을 정하고 키 차이는 유지한다.
- 이벤트별 배경 5종을 추가했다. [보스 통일 가이드](BOSS_ART_GUIDE.md), [제작 프롬프트](ART_WEEKLY_EVENTS.md)를 참고한다.

## 검증

`npm run verify`는 변경된 Shooter만 검사한다. 이벤트 단위 검사와 오프라인 브라우저 검사는 주간 경계·저장/재로드·중복 보상 방지·각 이벤트 3스테이지·보스 15페이즈·새 이미지 로드와 실제 배율 비교를 포함한다.
기존 챌린지 검사는 21스테이지 전체, 주간 티켓 지급, 런 유물 분리와 재도전을 확인한다.

실제 Android/iPhone 기기의 터치 성능·메모리·브라우저별 전체화면과 인간 플레이어의 체감 난이도는 별도 확인 대상이다.
