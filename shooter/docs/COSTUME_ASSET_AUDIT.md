# 코스튬 에셋 크기 검증

2026-09-29, `origin/main`의 기존 슈터 에셋과 `C:\Users\romar\Downloads\코덱스코스튬`의 PNG 5장을 적용 전에 비교했다. 의상 시트 네 장은 모두 1254×1254 픽셀, 신규 아스테아는 1254×1254 픽셀이다. 기존 `heroes.png`와 `companions.png`는 각각 1254×1254 픽셀, 기존 `astea.png`는 1223×1286 픽셀이다.

원본 의상 시트를 단순히 4등분하면 서로 다른 캐릭터의 일부가 중앙 경계에 들어간다. 각 시트에서 캐릭터 본체의 연결된 비녹색 실루엣을 분리하고 주변 칸의 픽셀을 제외했다. 게임용 투명 PNG는 각 캐릭터의 기존 WebP에서 알파값 30을 초과하는 경계와 정확히 같은 위치·가로·세로 크기로 배치했다. 다크페어리도 기존 반전색 WebP의 크기에 맞췄다. 새 아스테아는 기존 원본 캔버스 크기로 조정해 동일한 게임용 경계를 얻었다.

게임용 경계는 512×512 WebP 캐릭터 캔버스의 불투명 픽셀 기준이다. 아스테아는 384×384 WebP 캔버스다. 기존과 신규 경계의 `x,y,width,height`도 모두 같다. 전투 캐릭터는 기존과 같은 82 게임 좌표 크기로 그려진다. 타이틀의 초상화는 기존과 같은 CSS 영역과 `object-fit: contain`을 사용한다.

![기존 캐릭터, 첫 번째 의상, 두 번째 의상 순서의 크기 비교](costume-size-comparison.webp)

비교 이미지의 행 순서는 루미, 루나, 지크, 자스민, 눈토끼, 밤토끼, 다크페어리, 아스테아다. 각 행의 첫 열이 기존 에셋이고 다음 열이 새 에셋이다. 마지막 행은 384×384 게임용 WebP에서 아스테아의 신규 손과 전체 실루엣을 비교한다.

오프라인 단일 HTML을 Chromium 터치 에뮬레이션 320×568, 390×844, 844×390에서 열어 상점·라인업·의상실의 가로 넘침, 타이틀 장착 이미지, 전투 스프라이트의 82 좌표 크기를 확인했다. 이 검증은 실제 Android/iOS 기기의 터치·성능을 대신하지 않는다.
