# 일곱 하늘 챌린지

## 진행과 저장

- 출격 준비의 던전 선택에서 **챌린지 · 일곱 하늘 이어가기**를 선택한다. 현재 난이도를 유지한다.
- 마도제국 → 빛의 신전 → 어둠의 신전 → 요정의 숲 → 해저신전 → 혼돈의 틈 → 천계의 계단, 각 3스테이지를 연속 진행한다.
- 프로필의 장착 유물 최대 3개로 시작한다. 최초 여섯 보스 뒤 선택 퀴즈를 맞히면 현재 미적용 유물 전체에서 등급·소유 여부와 무관하게 균등 추첨한 3개 중 하나를 추가한다. 최대 9개. 목록을 확인하고 돌아와도 선택지는 바뀌지 않는다.
- 1·2스테이지 퀴즈는 생명 1 / 봄 1 중 선택. 아스테아 뒤 마지막 퀴즈는 당시 누적 점수 +10%. 거절·오답도 다음 단계나 결과 화면으로 이어진다.
- 부활 퀴즈 기회 1회, 광기의가면 생명 지불 3회는 런 전체에서 공유한다. 가면 제한은 일반 던전에서도 런당 3회다.
- 챌린지는 일반 던전의 최고 기록·업적·주간 보상·유물 소유·장착 상태를 갱신하지 않는다. 학습 정오답 기록은 기존대로 저장한다. 런 도중 종료/새로고침하면 진행과 획득 유물은 사라진다.
- 재시작은 마도제국부터 프로필 장착 상태로 다시 출발한다. 적용 유물은 HUD의 ◇, 일시정지, 유물 선택, 결과 화면에서 확인할 수 있다.

## 유물

| 등급 | 이름 | 일반 던전 효과 |
|---|---|---|
| 에픽 | 요정의망토 | 피격 반경 2 감소, 최대 생명 1 증가 |
| 에픽 | 드림초콜릿 | 보스에게 주는 피해 50% 증가 |
| 레어 | 기사회생 | 성공적으로 부활할 때 생명 전부 회복 |
| 에픽 | 기적의증명 | 성공적으로 부활할 때 봄 3 획득, 최대치 적용 |
| 에픽 | 여신의가호 | 매 스테이지 시작에 단일 보호막 생성 |

챌린지에서는 기사회생·기적의증명·네잎클로버가 적용되는 즉시 각각 완전 회복·봄 3·보호막을 부여한다. 부활에 재발동하지 않는다. 초기 장착 상태에서도 같은 즉시 효과가 적용된다. 보호막은 중첩되지 않고 파괴될 때 기존 피격 무적을 적용한다.

중간 획득 시 전체 유물 능력치를 다시 계산하되 기존 생명·봄 소모량을 보존한다. 최대치 변경은 차이만큼 반영하며, 생명 감소 유물 획득만으로 사망하지 않는다. 시작의보석을 중간 획득하면 활성화 시 파워 1을 얻는다. 신록의이슬 획득으로 이미 모은 P가 새 요구량에 도달하면 즉시 파워업한다.

강철방패·저주의검·버닝코어·레인보우링·스타파우더·카오스카니발도 전체 추첨 풀에 들어간다. 레인보우링을 얻어 최대 봄이 현재 보유량보다 낮아지면 즉시 새 상한에 맞추며, 카오스카니발은 화면 상단 자동 흡인을 제거하고 소지 봄과 최대 봄을 각각 2 늘린다.

뽑기 분포는 기본 **일반 84% / 레어 15% / 에픽 1%**, 퀴즈 정답 시 **일반 68% / 레어 30% / 에픽 2%**다. 기존 레어 확률을 유지하고 에픽 몫을 일반에서 배분했다. 게임 UI에는 확률을 표시하지 않는다.

## 천계의 계단

- 1스테이지 엘리트: 순간이동 / 사망 후 자폭을 번갈아 배치.
- 2스테이지 엘리트: 사망 시 분열 / 분열탄을 번갈아 배치.
- 앱솔루트 라이트: 조준 7웨이와 하단 역방향 탄. 하단 공격은 1.2초 전 예고하고 124px 통로를 남긴다.
- 디바인 블레이드: 산탄과 1.5초 간격 십자 레이저. 레이저는 플레이어 조준과 랜덤 위치를 번갈아 사용한다.
- 저지먼트: 좌·중·우 안전 통로의 기존 하단탄과 조준 5웨이를 함께 사용하고, 3초마다 십자 레이저를 추가한다.
- 일반 적 HP 배율 1.48, 보스 기준 HP 22000. 기존 난이도 배율을 적용한다. 기존 탄·적·이펙트 상한을 유지한다.

## 검증

`npm run verify`에 엔진 회귀 테스트와 오프라인 챌린지 화면 검증을 포함한다. 21개 클리어/퀴즈 화면, 획득 선택지 재추첨 방지, 런과 프로필 분리, 자원 제한, 부활 효과, 신규 패턴, 전체화면 320×568 / 390×844 / 430×932 / 844×390 정렬을 확인한다.

기준 main `35a971c`에서 이미 불일치한 테스트 기대값도 현재 동작에 맞췄다: 드래곤하트 50%, 코로나 1900, 보스 시간·랭크 보너스, 해령 HP의 기존 0.9167 계수, 삭제된 업적 보상 안내. 이들 게임 수치는 이번 패치에서 변경하지 않았다. 실제 휴대폰 성능·브라우저별 전체화면 지원은 데스크톱 모바일 에뮬레이션과 별도다.
