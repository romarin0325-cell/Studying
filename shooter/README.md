# 별의 잔향 · ASTRAL BLOOM

아홉 수호자와 여섯 개의 던전을 여행하며 영어를 기억하고 유물을 수집하는 모바일 세로 판타지 슈팅게임입니다.

## 바로 실행

**`dist/AstralBloom.html` 하나만 휴대폰으로 옮겨 JavaScript를 지원하는 브라우저에서 열면 됩니다.** 그림·코드·음악·학습 데이터가 모두 포함된 약 21 MiB의 오프라인 파일입니다. 계정이나 외부 이미지 서버가 필요하지 않습니다.

일부 모바일 파일 앱의 미리보기는 JavaScript를 실행하지 않습니다. 그 경우 HTML을 미리보기 대신 브라우저로 열어주세요. 실제 Android/iOS 기기별 파일 연결 동작은 별도 확인이 필요합니다. 기록 저장이 제한되는 환경에서도 게임은 실행됩니다.

## 플레이

- 화면 어디서든 드래그하면 손가락이 이동한 만큼 캐릭터가 이동합니다. 공격은 자동입니다.
- 피격 판정은 캐릭터 중앙의 작은 빛입니다. 머리·옷·망토에는 판정이 없습니다.
- 적탄을 가까이 피하면 스침 점수를 얻습니다. 연속 처치로 점수 배율이 최대 5배가 됩니다.
- `P`를 세 개 모을 때마다 파워가 올라갑니다. 최대 5단계이며, 피격 시 한 단계 감소합니다.
- 화면 위쪽 32%에 올라가면 아이템이 자동으로 끌려옵니다.
- 오른쪽 아래 **BLOOM** 버튼은 캐릭터 전용 봄입니다. 적탄 제거와 일시 무적이 공통으로 적용됩니다.
- 던전당 3스테이지. 종료마다 단어 → 숙어 → 문법 퀴즈 도전 여부를 선택합니다. 1·2스테이지 정답은 생명 1 또는 봄 1 회복, 3스테이지 정답은 최종 점수 +10%입니다. 아니오를 누르면 바로 다음 스테이지/결과로 진행합니다.
- 쉬움 / 보통 / 어려움은 체력·탄속·일반 적 발사 간격을 바꿉니다. 뒤쪽 던전일수록 강해집니다. 기본 생명은 쉬움 4/4, 보통 3/4, 어려움 3/3이며 유물로 늘릴 수 있습니다. 신데렐라·루나&자스민·시간의마술사는 시작 생명과 최대 생명이 1 더 높습니다. 밤토끼·루나&자스민은 시작 봄과 최대 봄도 1 더 높습니다. 이번 패치는 기존 대비 적 체력을 쉬움 10% / 보통 15% / 어려움 20% 올리고, 엘리트·중간보스·최종보스는 여기에 1.2배를 추가 적용합니다.
- 패배 시 문법 퀴즈로 던전 도전당 한 번 부활할 수 있습니다. 틀리거나 포기하면 끝나며 부활 생명은 최대 2입니다.
- 키보드: 방향키 / WASD 이동, Shift 정밀 이동, Space 봄, Escape 일시정지.

## 도서관과 유물

도서관에는 Card의 단어 381개, 숙어 130개, 문법 35강과 문법 문제 전체를 담았습니다. 전체 단어를 30개씩 넘겨 볼 수 있으며 검색·강의·연습·오답 재학습·학습 횟수가 저장됩니다. 오답은 개별 삭제 또는 확인 후 전체 초기화할 수 있습니다. 전체 초기화는 정답 통계와 읽은 강의를 보존합니다. `learning/data.js`는 원본 Card 데이터에서 생성한 배포 스냅샷이며 직접 편집하지 않습니다. `node shooter/sync-learning.mjs [Card 데이터 폴더]`로 갱신하고 `learning/provenance.json`에서 원본 해시와 수량을 확인합니다. 기본 원본은 활성 데이터인 `card/game/`입니다. 검증 시 원본 데이터, 스냅샷 또는 해시 기록이 서로 다르면 실패합니다.

각 던전의 주간 첫 클리어로 쉬움·보통은 뽑기권 1장, 어려움은 2장을 받습니다. 여섯 던전을 어려움으로 처음 클리어하면 주당 최대 12장입니다. 월요일 0시 초기화, 난이도 변경에 따른 중복 지급은 없습니다. 모든 티켓은 기존 저장 티켓까지 일반 85%·레어 15%이며 등급 안에서는 동일 확률입니다. 뽑기 전에 단어·숙어 퀴즈 도전 여부를 묻고, 정답이면 해당 1회만 일반 70%·레어 30%를 적용합니다. 거절·오답은 기본 확률이며 티켓은 결과 생성 시 한 장만 소모합니다. 수치 확률은 게임 UI에 노출하지 않습니다. 이전 혼돈의틈 클리어 기록과 미사용 티켓은 새 최종 던전으로 이전합니다.

일반 22종·레어 16종·에픽 4종은 `meta.js`에 설명과 수치가 함께 있습니다. 처음에는 마도서·프로즌하트·마나수정이 제공됩니다. 소유한 유물 세 개까지 장착하며 같은 유물 중복 장착은 불가합니다. 상시·조건부 공격력 보너스는 합쳐서 모든 일반 공격·추가 공격·봄 피해에 한 번 적용됩니다. 일반 공격 전용 증감은 봄 피해에서 제외되고, 봄 전용 보너스와 캐릭터 고유 배율은 각각 별도로 적용됩니다. 수호방패는 피격 시 봄을 우선 소모합니다. 광기의가면은 봄이 없고 생명 2 이상일 때 런당 최대 3회 생명 1로 발동합니다. 세계수의잎은 실제 자동 공격을 하는 페어리를 소환합니다.

황금자석은 기존 125인 획득 반경에 300을 더합니다. 투명망토는 피격 후 4초 무적입니다.

학습 원본 해시는 UTF-8/LF 텍스트를 기준으로 계산합니다. Windows 체크아웃의 CRLF 차이는 무시하지만 내용 변경은 검증 실패로 처리합니다. 현재 해시는 커밋된 Card 원본의 바이트 해시와 일치합니다.

## 여섯 개의 하늘

1. 마도제국 — **인조마신** / 프리즘 집행관 / 죽은 뒤 0.75초 경고 후 자폭하는 마력핵.
2. 빛의 신전 — **사랑의 여신 아이리스** / 장미의 성전기사 / 작은 고속 적 세 마리로 분열하는 세라핌.
3. 어둠의 신전 — **저주의 여신 아이리스** / 황혼의 심판관 / 3초 안에 잡지 않으면 탄막을 쏘는 저주 시계.
4. 요정의 숲 — **꽃의 여신 플로라** / 꽃숲의 파수꾼 / 체력이 높은 공간의 요정은 꽃무늬를 0.7초 예고한 후 순간이동.
5. 해저신전 — **해신 포세이돈** / 해저의 성기사 / 해령은 5초 동안 화면 가장자리에서 반사되는 탄을 발사. 포세이돈만 가로·세로 십자 레이저를 사용하며 1.4초 예고.
6. 혼돈의 틈 — **마신 벨제뷔트** / 심연의 문지기 / 플레이어 근처에서 작은 탄으로 갈라지는 느린 대형탄.

2스테이지에는 던전별 중간보스, 3스테이지에는 기존 최종보스가 등장합니다. 보스마다 체력에 따라 세 패턴이 있으며 세로 광선은 1.4초 먼저 예고합니다. 한 던전은 대략 2~3분과 학습 시간으로 구성됩니다. 루미 레이저는 현재 위치에 붙어 렌더링되고, 0.15초 이상 조준이 끊기면 집중 보너스가 초기화됩니다. 자스민 체인은 적이 없으면 꽃탄을 쏘지 않고 다시 탐색합니다.

## 이번 전투 조정

- 신규 유물: 악마의거울(속도 −300, 다크페어리), 수호의의지(스테이지 클리어마다 생명 +1), 시작의보석(시작 P+1), 바람의장화(속도 +200), 월광의목걸이(클리어마다 봄 +1), 황금의태양(코로나로 교체). 회복은 퀴즈 도전 여부와 무관하며 상한을 지킵니다. 두 페어리는 동시에 각각 동일 화력으로 보조합니다.
- 코로나는 기본 피해 1700, 지속·무적 1초. 기존 캐릭터의 회복·강화·변신·감속·파워 소모를 대체하며 기존 공격력/봄 유물 배율은 적용됩니다.
- 시간의마술사 외 봄의 지속·무적을 1초 단축했습니다. 이전 60Hz 실행의 총 직접 피해(루미 1058, 루나 1300, 지크 1248, 자스민 773, 눈토끼 1058, 신데렐라 1305, 듀오 1058)를 유지합니다. 밤토끼는 요청한 1900으로 변경합니다. 실제 전투에서는 적의 등장·퇴장·처치 시점에 따라 적중량이 달라집니다.
- 눈토끼 감속은 4초 봄 종료 뒤 5초 더 지속합니다. 시간의마술사는 10초 변신·2.5초 무적을 유지합니다.
- 톱니 피해·크기 +20%, 궤도 가로·세로 폭 +15%. 매 프레임 상대 이동 경로를 검사하며 적별·톱니별 0.12초 재피격 대기시간을 적용합니다.
- 일반 던전의 P는 기존 드랍 대상의 90%에서 생성됩니다. 챌린지의 일반 몬스터는 처치할 때마다 약 20% 확률로 P를 떨어뜨리며, 엘리트 드랍은 유지됩니다. 일반 적 체력 배율은 마도제국 1.12에서 해저신전 1.30까지 단계적으로 증가하고 혼돈의틈 1.35·천계의 계단 1.48은 유지됩니다. 보스 기본 체력은 5500·7200·9400·11900·14500·17000·22000 순서입니다.
- 일반/레어 유물 목록과 장착 완료 버튼을 분리하고, 캐릭터·던전 선택 시 스크롤을 보존합니다. 랜덤도 무기 선택 영역의 크기를 유지합니다.


- 루미 유도탄 −10%, 레이저 +20%; 레이저 시각 효과도 화면 최상단까지 이어집니다.
- 눈토끼 −10% 및 코어 반경 4. 지크 +10%, 코어 반경 6, 드래그 추적 최대 속도 1100. 밤토끼 반경 4, 루나&자스민 반경 6.
- 자스민 꽃탄 −15%. 루나 근접 주기는 0.56→0.70초, 참격과 보조 검기 피해는 25% 증가해 이론 DPS를 유지합니다. 탄 삭제 반경은 공격 사거리의 80%→72%로 줄여 접근 위험을 남깁니다.
- 신데렐라 미드나잇 +10%, 크리스탈 킥 +30%.
- 퀴즈·등장·정리 시간과 화면에 적이 없는 동안에는 콤보 시간이 줄지 않습니다.
- 루나&자스민은 실제로 오지 않은 화해의 미래라는 설정이며, 새 공격 두 종류는 동일 측정에서 약 315 DPS(P3, 유물 없음)를 목표로 조정했습니다. 일반 캐릭터의 스타일 평균 약 266 대비 약 18% 높습니다. 대상 크기·거리·이동·적 수에 따라 달라집니다.
- 캐릭터 일러스트는 아틀라스의 여백과 얼굴 크기를 기준으로 정규화합니다. 통상·듀오 자스민은 같은 긴 흰 드레스와 금빛 태양 지팡이를 사용합니다. 최종 생성 기록은 `ART_UPDATE.json`입니다.
- 로비 우측 상단에서 전체화면을 전환합니다. 지원하지 않는 브라우저에서는 안내를 표시합니다.

## 챌린지·유물·전투 조정

- 챌린지 선택 버튼과 선택된 로비 경로에 천계의 계단 배경을 표시합니다.
- 강철방패, 저주의검, 버닝코어, 레인보우링, 스타파우더, 카오스카니발을 추가했습니다. 요정의망토와 드림초콜릿은 에픽으로 변경했습니다.
- 챌린지에서 시작의보석을 획득하면 즉시 파워가 1 증가합니다. 카오스카니발은 화면 상단 자동 흡인을 없애고, 레인보우링은 최대 봄보다 많은 봄을 즉시 상한에 맞춥니다.
- 아스테아는 1패턴 조준 7웨이, 2패턴 1.5초 간격의 유도·랜덤 교대 십자레이저, 3패턴 기존 하단탄·조준 5웨이·3초 간격 십자레이저를 사용합니다.
- 무기 DPS는 요청 수치를 각 공격 계수에 직접 반영했습니다: 별의 편지 2% 감소, 한낮의 태양 4% 증가, 루나틱위치·어쌔신·프레임윙·프로즌 샤드·문드롭·크리스탈 킥·리와인드 2% 증가, 프로미넌스 3% 증가, 라이트닝체인 2% 감소, 홀리 플라워 3% 감소, 스노우 바운드·슬립리스 나이트·미드나잇 스펠·이어 쓴 내일·우리의 작은 집 2% 감소.

## 개발 및 검증

저장소 루트에서:

```powershell
node shooter/serve.mjs
# http://127.0.0.1:4188/
npm run verify --prefix shooter
node shooter/tests/balance.mjs
node shooter/tests/balance-probe.mjs
# 로컬 서버 실행 중 부하 확인:
node shooter/tests/stress.mjs
node shooter/tests/flow.mjs
node shooter/tests/patch-flow.mjs
```

루트 `npm run verify`가 필수 완료 검사입니다. 슈터 검사에는 엔진·진행 규칙 테스트, 단일 HTML 재생성, 네 가지 화면 크기의 오프라인 Chromium 실행이 포함됩니다. `flow.mjs`는 배포 HTML의 테스트 전용 복사본에서 전투 상태에 접근해 강의·퀴즈·회복·중간보스 관문·최종 보상·뽑기·저장·부활 UI를 검증합니다. 배포본에는 테스트 조작 기능이 없습니다. 부하 검사는 별도의 실제 렌더링 fixture로 실행합니다.

`tests/balance.mjs`의 자동 조작은 밸런스 비교용입니다. 사람의 체감 난이도를 보장하는 지표는 아닙니다. 브라우저 검사 또한 데스크톱 Chromium의 모바일 크기 검증이며 실제 휴대폰 측정과 구분해야 합니다.

## 성능 설계

- 고정 60 Hz 전투 업데이트, 과도한 지연 시 따라잡기 횟수 제한.
- Canvas 렌더링, 적탄 텍스처와 발광 텍스처 캐시.
- 적탄 360 / 플레이어 탄 170 / 파티클 180 / 적 40 / 아이템 55개 / 장판 8개 상한.
- 기본 DPR 상한 1.75, 지속적인 프레임 저하 시 DPR 1 및 장식 밀도 축소.
- 필살기는 기존 컷인과 공용 마법진에 새 피닉스·코로나·눈꽃·성화 아틀라스를 더합니다. 그림은 로딩 시 캐시하며 전체화면 필터를 추가하지 않습니다.
- 아틀라스에서 게임용 투명 텍스처를 시작할 때 한 번 추출하고 재사용.
- 화면을 숨기면 자동 일시정지, 결과·퀴즈 화면에서는 전투 프레임 루프 중단.
- 음악과 효과음은 Web Audio로 로컬 합성하며, 사용자 입력 뒤 재생.

## 파일

- `content.js`: 캐릭터·무기·던전·보스 정의.
- `meta.js`, `menus.js`, `learning.js`: 유물·주간 보상·요일·학습과 메뉴.
- `engine.js`: 입력·충돌·공격·패턴·진행.
- `render.js`: 아트 준비와 전투 연출, 적응형 렌더링.
- `audio.js`: 음악과 효과음.
- `app.js`, `style.css`, `index.html`: 출격·HUD·조작·결과 UI.
- `assets/`: 직접 생성한 캐릭터·보스·적 아틀라스와 배경.
- `ART_PROMPTS.md`: 내장 이미지 생성 도구에 사용한 디자인 프롬프트와 참조 역할.
- `build.mjs`: 외부 의존성 없이 코드와 이미지를 단일 HTML로 패킹.
- `dist/AstralBloom.html`: 휴대폰에 복사할 최종 파일.
- `artifacts/`: 로컬 검증 결과와 실제 화면 캡처. Git에서는 제외.
