# 별의 잔향 · ASTRAL BLOOM

네 명의 수호자와 네 개의 하늘을 여행하는 모바일 세로 판타지 슈팅게임입니다. 기존 Defense Hero V2와 독립적인 게임입니다.

## 바로 실행

**`dist/AstralBloom.html` 하나만 휴대폰으로 옮겨 JavaScript를 지원하는 브라우저에서 열면 됩니다.** 인터넷, 계정, 설치, 외부 이미지 서버가 필요하지 않습니다. 그림과 게임 코드, 합성 음악과 효과음이 모두 포함되어 있습니다. 약 9.5 MiB입니다.

일부 모바일 파일 앱의 미리보기는 JavaScript를 실행하지 않습니다. 그 경우 HTML을 미리보기 대신 브라우저로 열어주세요. 실제 Android/iOS 기기별 파일 연결 동작은 별도 확인이 필요합니다. 기록 저장이 제한되는 환경에서도 게임은 실행됩니다.

## 플레이

- 화면 어디서든 드래그하면 손가락이 이동한 만큼 캐릭터가 이동합니다. 공격은 자동입니다.
- 피격 판정은 캐릭터 중앙의 작은 빛입니다. 머리·옷·망토에는 판정이 없습니다.
- 적탄을 가까이 피하면 스침 점수를 얻습니다. 연속 처치로 점수 배율이 최대 5배가 됩니다.
- `P`를 세 개 모을 때마다 파워가 올라갑니다. 최대 5단계이며, 피격 시 한 단계 감소합니다.
- 화면 위쪽 32%에 올라가면 아이템이 자동으로 끌려옵니다.
- 오른쪽 아래 **BLOOM** 버튼은 캐릭터 전용 봄입니다. 적탄 제거와 일시 무적이 공통으로 적용됩니다.
- 보스를 쓰러뜨리면 공격력·생명·봄 중 하나를 선택하고 다음 스테이지로 갑니다.
- 시작 화면의 `01`은 전체 이야기, `02~04`는 해당 스테이지부터 시작하는 연습입니다. 최고 기록은 난이도와 시작 스테이지별로 저장됩니다.
- 난이도 `편안하게`는 적탄 속도 22% 감소, 보스 체력 15% 감소, 시작 생명 6개입니다. 오리지널은 생명 5개입니다.
- 키보드: 방향키 / WASD 이동, Shift 정밀 이동, Space 봄, Escape 일시정지.

## 수호자와 공격

| 수호자 | 스타일 1 | 스타일 2 | 봄 |
|---|---|---|---|
| 루미 · 남성 대현자 | 별의 편지: 유도 별탄 | 한낮의 태양: 집중할수록 강해지는 관통 레이저 | 천체의 교향곡: 탄 제거와 유성우 |
| 루나 · 여성 암살자 | 그믐의 칼날: 고속 관통 단검 | 월하난무: 근접 참격, 적탄 절단, 보조 검기 | 월식: 무적과 분신 연속 참격 |
| 지크 · 남성 전사 | 홍련의 날개: 화염 3웨이 | 여명을 가르는 검: 거대 관통 화염검 | 홍련: 불사조 공격, 5초간 화력 +60% |
| 자스민 · 여성 성녀 | 원소의 노래: 최대 5체 연쇄 번개 | 성화의 정원: 꽃탄, 주기적 근거리 방어 | 에덴의 기도: 생명 1 회복과 성역 |

## 네 개의 하늘

1. 푸른 시간의 유적 — **인조마신**: 조준 부채탄, 회전 프리즘, 예고 광선.
2. 영원한 장미 정원 — **사랑의 여신 아이리스**: 하트 탄막, 곡선 나선, 이중 부채탄.
3. 빛을 잃은 성당 — **저주의 여신 아일스**: 회전 수정탄, 빈틈이 있는 탄벽, 추적 예고 광선.
4. 검은 태양의 왕좌 — **마신 벨제뷔트**: 양쪽 탄막, 심연 광선, 조준탄 복합 패턴.

보스마다 체력 구간에 따라 세 가지 패턴이 있습니다. 위험한 세로 광선은 1.4초 먼저 위치를 표시합니다. 예상 캠페인 길이는 약 5분이며 플레이 방식에 따라 달라집니다.

## 개발 및 검증

저장소 루트에서:

```powershell
node shooter/serve.mjs
# http://127.0.0.1:4188/
npm run verify --prefix shooter
node shooter/tests/balance.mjs
# 로컬 서버 실행 중 부하 확인:
node shooter/tests/stress.mjs
node shooter/tests/flow.mjs
```

`npm run verify --prefix shooter`은 전투 단위 테스트, 단일 HTML 재생성, 실제 오프라인 Chromium 실행을 포함합니다. 320×568 / 390×844 / 430×932 세로 화면, 844×390 가로 전환, 캐릭터·무기 선택, 터치 이동, 봄, 일시정지, 연습 스테이지, 저장소 차단 환경을 검사합니다. `flow.mjs`는 실제 HTML의 첫 보스 처치와 축복 선택 후 다음 스테이지 재개를 가상 시계로 검증합니다.

`tests/balance.mjs`의 자동 조작은 밸런스 비교용입니다. 사람의 체감 난이도를 보장하는 지표는 아닙니다. 브라우저 검사 또한 데스크톱 Chromium의 모바일 크기 검증이며 실제 휴대폰 측정과 구분해야 합니다.

## 성능 설계

- 고정 60 Hz 전투 업데이트, 과도한 지연 시 따라잡기 횟수 제한.
- Canvas 렌더링, 적탄 텍스처와 발광 텍스처 캐시.
- 적탄 360 / 플레이어 탄 170 / 파티클 180 / 적 40 / 아이템 55개 상한.
- 기본 DPR 상한 1.75, 지속적인 프레임 저하 시 DPR 1 및 장식 밀도 축소.
- 아틀라스에서 게임용 투명 텍스처를 시작할 때 한 번 추출하고 재사용.
- 화면을 숨기면 자동 일시정지, 결과·축복 화면에서는 전투 프레임 루프 중단.
- 음악과 효과음은 Web Audio로 로컬 합성하며, 사용자 입력 뒤 재생.

## 파일

- `content.js`: 캐릭터·무기·보스·축복 정의.
- `engine.js`: 입력·충돌·공격·패턴·진행.
- `render.js`: 아트 준비와 전투 연출, 적응형 렌더링.
- `audio.js`: 음악과 효과음.
- `app.js`, `style.css`, `index.html`: 출격·HUD·조작·결과 UI.
- `assets/`: 직접 생성한 캐릭터·보스·적 아틀라스와 배경.
- `ART_PROMPTS.md`: 내장 이미지 생성 도구에 사용한 디자인 프롬프트와 참조 역할.
- `build.mjs`: 외부 의존성 없이 코드와 이미지를 단일 HTML로 패킹.
- `dist/AstralBloom.html`: 휴대폰에 복사할 최종 파일.
- `artifacts/`: 로컬 검증 결과와 실제 화면 캡처. Git에서는 제외.

이 버전에는 광고·결제·분석 서버가 없습니다.
