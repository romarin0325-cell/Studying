다음은 `meta.js`의 최종 난이도 기본값이다. 던전별 HP 계수, 보스/관문 추가 보정, 심연 전용 보정과 패턴을 적용하기 전이다.

## 수호자·파워·피격·봄

기본 난이도 자원에 신데렐라·루나&자스민·시간의마술사는 생명/최대 생명 +1, 밤토끼·루나&자스민은 봄/최대 봄 +1을 더한다. 피격 반경은 기본 5, 지크·루나&자스민 6, 눈토끼·밤토끼 4다. 유물 반경 보정 후 최소 1을 적용한다.

P는 최대 5단계다. 루미·루나&자스민은 기본 4아이템, 나머지는 3아이템으로 다음 단계에 오른다. 신록의이슬은 요구 아이템을 1 줄인다. 피격은 기본 한 단계 감소이며 강철방패가 막고, 버닝코어의 초기화 등 예외도 실제 피격 경로에서 처리한다.

| 특수 자원/대응 | 현재 조건 |
| --- | --- |
| 보호막 | 네잎클로버·유리구두·여신의가호가 생성, 중첩 불가. 보호막에 막힌 피격과 실제 생명 손실은 구분 |
| 수호방패 | 피격 때 생명 대신 봄 우선 소비 |
| 광기의가면 | 봄 0·생명 2 이상에서 생명 1로 발동, 런당 3회 |
| 부활 | 기본 1회, 불사조의깃털 +1. 퀴즈 오답/포기는 종료 |
| 코로나 | 기본 피해 2000, 지속/무적 1초, 고유 봄 교체 |
| 홀리플레임 | 기본 피해 5800, 지속/무적 2초, 남은 봄 전부와 P 소모. 코로나와 함께면 우선 |
| 챌린지 즉시 효과 | 기사회생·기적의증명은 시작/획득 시 적용, 부활 때 반복하지 않음 |

홀리플레임의 5800은 기본값이다. 공격/봄 유물과 거리 등 적용 조건이 최종 피해를 바꾼다. 고유 회복·변신·공격 강화·감속을 대체하므로 숫자만 비교하지 않는다.

## 유물 효과를 조합하는 법

상시·조건부 공통 공격력 보너스는 합산해 일반 공격·추가 공격·봄에 한 번 적용한다. 일반 공격 전용 보너스는 봄에서 제외하고 봄 전용 배율은 별도로 적용한다. 동명 설명의 수치를 매 공격 경로에서 두 번 곱하지 않도록 한다.

| 효과 축 | 비교할 기회비용/예외 |
| --- | --- |
| 공통 화력 | 생명 감소·회복 아이템 제거·낮은 생명/P/봄 조건과 함께 비교 |
| 일반 공격 화력 | 빅뱅/만화경 등 봄과의 교환, 피격 시 P 초기화 |
| 봄 화력/교체 | 일반 공격 감소, 남은 봄·P 소모, 고유 회복·변신 손실 |
| 생존/피격 | 생명·반경·무적·봄 대체·부활을 같은 자원으로 합산하지 않음 |
| 표적별 추가 피해 | 일반/엘리트/중간보스/최종보스 대상 구분 |
| 거리 기반 성검 | 적과 플레이어 중심 거리 d, 전장 대각선 D: `+50% × (1−(d/D)²)`; 대각선 절반은 +37.5% |
| 지원체 | 페어리·다크페어리 실제 발사/명중. 물망초는 두 지원체 기본 탄 피해 15→30 |

전설 유물 2개는 예약 데이터다. 현재 소지/장착/추첨/챌린지 보상에 포함하지 않으므로 수집 가능한 총수는 48개다.

## 수치 변경과 문서 갱신

같은 수호자·무기·P·유물·난이도·던전·표적 거리·대상 수·봄 소비 조건을 고정한다. 근접 화력을 올릴 때 적탄 절단·피격 위험·보스 패턴 통로와 함께 본다. 제어 무기는 둔화 시간과 다수 적 명중을 단일 표적 DPS와 별도 기록한다.

전투 패치의 갱신 원본은 `engine.js/content.js/meta.js`, 설명은 `docs/manual-content.js`다. 기존 생성 도구로 `MANUAL.md`·`manual-data.js`를 함께 갱신하고 `--check` 및 선택된 검증을 따른다. 문서만 변경한 이번 작업은 생성/게임 빌드/실측을 다시 실행하지 않았다.
