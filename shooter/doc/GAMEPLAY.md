# Shooter 진행 방식과 기능 의도

[문서 시작점](README.md) · [정량 매뉴얼](../docs/MANUAL.md) · [수호자 능력](CHARACTERS.md)

기준: `7635238`의 `content.js`, `engine.js`, `meta.js`, `app.js`, `menus.js`, `learning.js`, `tutoring.js`, `tutoring-ui.js`. 아래 의도는 현재 구현과 기존 문서를 연결한 설계 해석이다.

## 한 출격의 흐름

1. 오늘 사용 가능한 수호자와 두 공격 스타일 중 하나를 고른다. 일반 수호자 6명은 요일별로 열리고 다른 요일의 캐릭터는 문법 정답으로 당일 해금한다. 랜덤은 히든 3명을 포함한 9명 각각 1/9, 하루 기본 3회다.
2. 보유 유물 최대 3개, 난이도, 일반 던전·챌린지·이번 주 이벤트를 선택한다. 일반 던전은 6개이며 천계의 계단은 챌린지 전용이다.
3. 자동 공격을 유지하며 드래그 또는 키보드로 탄을 피하고 P·점수 아이템을 모은다. 중앙의 작은 피격 판정, Shift 정밀 이동, BLOOM 봄을 사용한다. 별도 손가락으로 봄을 누를 때 이동 포인터를 유지한다.
4. 한 던전은 3스테이지다. 첫 구간은 웨이브 및 남은 엘리트, 둘째는 관문, 셋째는 최종보스를 처리한다. 시간이 끝났다는 이유만으로 살아 있는 관문/엘리트를 생략하지 않는다.
5. 스테이지 종료 시 단어 → 숙어 → 문법 퀴즈를 선택적으로 진행한다. 일반 진행에서 1·2구간 정답은 생명/봄 회복, 마지막 정답은 최종 점수 +10%다. 기본 클리어 보상과 선택 학습 보상을 구분한다.
6. 생명을 잃으면 문법 퀴즈 부활을 제안한다. 기본 출격당 한 번이며 불사조의깃털은 한 번 추가한다. 종료 후 기록·주간 티켓·심연 업적을 정산한다.

챌린지는 7던전·21스테이지를 연속 진행하며 생명·봄·파워를 이어간다. 초기 유물 3개에 보스 퀴즈 보상으로 새로운 유물을 추가해 최대 9개를 사용한다. 중간 획득 유물은 런 전용이며 일반 보유 목록으로 지급하지 않는다. 챌린지의 부활/즉시 발동 예외는 [매뉴얼의 조건과 예외](../docs/MANUAL.md#조건과-예외)를 따른다.

## 기능별 의도

| --- | --- | --- |
| 두 무기 스타일 | 수호자마다 서로 다른 조준·도달·범위·부가효과 | 회피 안정성, 근접 위험, 다수 적 처리와 보스 화력의 선택 |
| 작은 피격점 | 그림의 머리·옷은 판정에 포함하지 않음 | 외형을 크게 유지하면서 탄막 통로를 읽기 쉽게 함 |

| 봄 | 탄 제거·일시 무적·고유 피해/효과, 횟수 자원 | 위기 탈출과 보스 화력을 같은 자원으로 판단 |
| 스침·콤보 | 가까운 회피와 연속 처치에 점수 | 클리어 외에 숙련과 위험 감수를 기록 |
| 유물 | 상시·조건부·일반 공격·봄·지원체 효과를 구분 | 약점을 보완하거나 위험을 늘려 특정 스타일 강화 |
| 요일·랜덤 | 요일 해금과 9명 균등 랜덤, 공개 시 횟수 소모 | 평소 선택과 새로운 수호자 경험을 함께 제공 |
| 주간 이벤트 | 5개 중 하나 순환, 월요일 현지 0시 경계 | 다른 기믹을 반복 방문할 계기. 같은 던전의 주간 중복 보상 제한 |
| 학습 퀴즈 | 출격·부활·보상·유물 뽑기에 선택 학습 연결 | 게임 행동과 복습을 연결하되 거절하면 기본 흐름 진행 |
| 오답장·과외 | 저장된 실제 문항과 해설을 재사용 | 틀린 내용을 다시 확인하고 설명에서 정답 재풀이로 연결 |
| 의상 | 획득·착용을 저장, 능력 동일 | 전투 밸런스와 독립된 수집·표현 목표 |

## 전투 밖의 경제

주간 던전 첫 클리어는 쉬움/보통 티켓 1장, 어려움/심연 2장이다. 난이도를 바꿔도 동일 던전은 같은 주에 다시 지급하지 않는다. 보상 기록은 일반 6던전 각각, 챌린지 1개, 순환 이벤트 공통 1개로 구분하며 이벤트는 이번 주 활성 던전만 지급 대상이다. 유물 뽑기는 기본 일반/레어/에픽 84/15/1%, 해당 뽑기 전 퀴즈 정답은 68/30/2%다. 중복은 꿈의결정 1/3/5개로 환급한다.

꿈의결정으로 유물 티켓(5), 랜덤 리셋(1), 일상/판타지/스페셜 의상 티켓(각 10), 미라클 선택권(30)을 산다. 의상 12벌은 일반 수호자 6명에게 2벌씩이며 중복 의상 환급은 3개다. 일반 의상권은 해당 4벌 중 균등 추첨, 미라클은 12벌 중 선택 후 결제한다.

12던전 각각의 심연 첫 클리어 업적은 꿈의결정 3개를 한 번 지급한다. 기존 심연 기록을 소급할 때도 중복 지급하지 않는다. 주간·요일 경계는 기기의 현지 날짜 기준이다.

## 최신 오답 복습과 루미 과외

`learning.js`는 오답에 문항 ID·문제·보기·정답·선택한 오답·해설·연결 강의를 저장한다. 같은 문항을 맞히면 오답장에서 지운다. 유효한 오답은 최대 200개이며 전체 초기화는 별도 정답 통계와 강의 진도를 보존한다.

루미 과외는 선택 문항의 설명을 요청하고, 실패하거나 API 키가 없을 때 내장 기본 해설로 복습할 수 있게 한다. AI 설명이 필요한 경우에만 네트워크와 사용자의 API 키를 사용한다. API 키의 기억 여부와 연결 해제는 캠페인 보상 저장과 별개다. 과외/복습 화면이 닫히거나 다른 문항으로 바뀌면 이전 요청을 취소해 오래된 응답이 덮어쓰지 않게 한다.

유효한 저장 오답 복습 보상은 하루 한 번 꿈의결정 1개다. 보상 판정 시 저장된 문제·정답과 날짜를 확인한다. 자세한 수정 위치는 [SOURCE_MAP.md](SOURCE_MAP.md)에 있다.

## 저장과 오프라인 경계

`astral-bloom-v1`은 설정·기록·캠페인을 저장한다. 현재 전투를 임의 지점에서 이어가는 범용 실행 상태 저장으로 해석하지 않는다. 배포 HTML에는 전투·기본 학습·이미지·글꼴이 들어 있으며 선택 AI 과외를 제외한 기본 플레이는 오프라인이다.
