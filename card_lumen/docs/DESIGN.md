# Lumen 설계 노트

## 무엇을 위한 화면인가

DREAMWEAVER는 광고 버튼을 누를 타이밍에 **학습 버튼을 누르게 하려고** 만든 카드 RPG입니다. 그래서 화면 위계를 이렇게 정했습니다.

1. **출전**이 화면당 하나뿐인 주 행동입니다(아쿠아).
2. **소환**은 바로 아래에 두되, 학습이 섞인 도전 소환 쪽에 편의를 줍니다.
3. **학습**은 하단 탭 하나를 통째로 차지하고, 받을 것이 있으면(포춘쿠키·미션) 점으로 부릅니다.
4. 기록·카드풀·저장·테마 같은 관리 기능은 설정 한 곳에 모읍니다.

## 참고와 재해석

- **별빛 정원 Bright(Postcard):** 사용자가 가장 세련됐다고 본 기준입니다. 코발트 네이비는 구조(머리띠, 선택된 탭, 이름 리본, 섹션 띠), 아쿠아는 행동, 따뜻한 종이와 12px 격자는 배경, 네 갈래 금별과 소인은 장식입니다. 같은 세계관이므로 소환 제단과 루미의 서재 그림도 같은 에셋을 씁니다.
- **수집형 RPG의 카드 표현:** 등급은 카드 테두리(액자)와 뱃지로만 말하고, 이름은 네이비 리본에 둡니다. 모든 카드 그림은 3:5 비율이므로 파티·편성·도감·소환·전투 어디서도 잘라내지 않고 3:5 그대로 둡니다.
- **턴제 전투의 피드백:** 숫자 팝업, 잔상 HP 바, 행동 배너처럼 "무슨 일이 일어났는지"를 읽게 하는 장치만 가져왔습니다. 입자 효과나 화면 흔들림처럼 그림 없이 코드로 흉내 내면 싸 보이는 효과는 넣지 않았습니다.

"AI가 만든 듯한" 화면을 피하려고 다음을 지켰습니다. 그라데이션 유리 패널을 겹치지 않는다. 같은 정보에 상자를 씌우지 않는다. 장식 아이콘을 문장 앞에 붙이지 않는다(원본 대화창 제목의 이모지도 빌드에서 걷어냅니다). 강조 색은 화면마다 하나만 쓴다.

## 온도

기본 테마 드림스카이는 밝은 종이와 하늘 사진으로 낮의 온도를 유지합니다. 관측소 그림은 흐리게 처리하지 않고 위쪽에만 씻김을 깔아 글자가 놓일 자리를 만듭니다. 아스트라(밤)와 마법소녀(분홍)는 색 토큰만 바꾸고 모양·배치·글자 크기는 같습니다. 테스트가 세 테마에서 출전 버튼 좌표가 같은지 확인합니다.

## 메뉴별 판단

| 메뉴 | 의도 | 처리 |
| --- | --- | --- |
| 출전 | 다음 전투로 간다 | 로비의 유일한 아쿠아 버튼. 스테이지 번호, 상대, 보스/목표를 버튼 안에 넣어 따로 볼 필요를 없앴습니다. |
| 파티 | 지금 누구로 싸우는지 | 3:5 카드 세 장. 빈자리는 점선 자리로 남기고 누르면 편성으로 갑니다. |
| 소환 | 티켓을 카드로 | 일반 1장 / 도전 1장 / 연속 도전. 카드풀은 소환 제목 옆의 보조 링크. |
| 축복·미션 | 가끔 확인 | 준비 줄의 작은 버튼. 남은 축복 수와 받을 미션 점만 표시합니다. |
| 편성 | 세 자리를 채운다 | 하단 탭을 숨기고 완료 버튼을 고정. 첫 빈자리 자동 선택, 놓을 때마다 다음 빈자리로. |
| 도감 | 무엇을 가졌고 무엇이 있는지 | 이번 여정/전체, 등급 칩, 검색. 상세는 목록 안에서 넘깁니다. |
| 학습 | 광고 대신 누를 버튼 | 루미 그림 + TOEIC 주 행동 + 나머지 목록. |
| 설정 | 관리 | 저장·기록·카드풀·과외 이벤트·타이틀·테마·기록 파일·초상화 폴더. |

## 연속 도전

편의 기능을 검토할 때 가장 먼저 나오는 것은 10연 뽑기입니다. 하지만 이 게임에서 일반 소환을 묶어 주면 퀴즈를 건너뛰는 길이 더 편해져 게임의 목적과 반대가 됩니다. 도전 소환의 비용을 올리는 것도 같은 이유로 맞지 않습니다.

그래서 편의는 학습 쪽에만 줍니다.

- 티켓이 2장 이상이면 **연속 도전**이 생깁니다. 최대 10문제입니다.
- 한 문제마다 원본 도전 소환을 그대로 한 번 실행합니다(티켓 1장, 단어 퀴즈, 도전 확률). 규칙 코드는 건드리지 않았습니다.
- 바뀐 것은 공개 시점뿐입니다. 정답마다 소환 연출을 끊어 보여주지 않고, 마지막에 얻은 카드를 한꺼번에 뒤집습니다. 오답은 결과 아래에 개수로만 남기고 다음 문제로 바로 넘어갑니다.
- 진행 막대에 몇 번째 문제인지와 지금까지 얻은 카드 수를 보여주고, "그만하기"로 지금 문제까지만 풀 수 있습니다.
- 결과창의 다음 버튼은 남은 티켓으로 연속 도전을 이어갑니다(1장 남으면 도전 소환 한 번).
- 일반 소환은 계속 1장씩입니다.

## 움직임

- 유지: 카드 뒤집기, 희귀 등급의 짧은 암전·섬광, 피해 숫자, 잔상 HP 바, 행동 배너, 결과창 진입.
- 생략: 상시 반짝임, 배경 입자, 화면 흔들림, 버튼마다 다른 호버 효과.
- 모션 감소 설정에서는 소환이 바로 공개되고 배너·팝업이 생략됩니다.

## 글자와 대비

밝은 테마에서 글자가 배경과 같은 색이 되는 문제를 막으려고, 모든 화면과 대화창(40여 상태 × 3테마)의 글자 대비를 브라우저에서 계산해 점검했습니다. 762건에서 시작해 보조 글자색, 등급 뱃지, 레거시 대화창의 인라인 색을 고쳤습니다.

남은 예외는 아쿠아(마법소녀는 분홍) 버튼 위의 흰 굵은 글자입니다. 별빛 정원 Bright와 같은 처리로, 진한 그림자를 함께 써서 실제 크기에서 읽히는 것을 확인했지만 WCAG 계산값은 기준 아래입니다. 그 밖에 남은 수치는 테두리 그라데이션을 배경으로 잘못 계산한 점검 도구 쪽 오차입니다.

## 확인하지 못한 것

- 실제 휴대폰(iOS Safari·Android Chrome), WebKit 엔진, 노치·홈 표시줄 여백.
- 플레이어의 실제 초상화와 음악 파일. 미리보기는 저장소의 별빛 정원 일러스트를 임시 초상화로 썼습니다.
- Gemini 키가 필요한 AI 질문·과외 응답.
- 모든 모드(드래프트, 팩토리, 카오스, 퍼즐 등)의 끝까지 이어지는 플레이. 각 모드의 첫 화면과 대화창은 확인했습니다.
