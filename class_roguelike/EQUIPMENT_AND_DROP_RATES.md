# 장비·드랍·경험치 수치 메모

테스트 빌드 기준의 수치입니다. 장비의 평면 능력치는 레벨 기본 능력치와 합쳐진 **베이스 스탯**이고, 그 뒤에 직업 패시브·버프·디버프의 퍼센트 합연산이 한 번 적용됩니다.

## 장비 목록 (티어 1 → 5)

같은 등급 설명은 장비 종류와 능력치 종류가 달라도 동일한 티어 계열을 사용합니다. 티어 1 기준은 `낮음 5`, `보통 10`, `높음 20`, `매우 높음 30`이며, 티어가 오를 때마다 해당 기준값에 티어를 곱합니다.

| 종류 | 슬롯 | 티어별 수치 | 고정 효과 |
| --- | --- | --- | --- |
| 대검 | 무기 | 물리공격력(매우 높음) `30 / 60 / 90 / 120 / 150`, 마법공격력(보통) `10 / 20 / 30 / 40 / 50` | 없음 |
| 단검 | 무기 | 물리공격력(보통) `10 / 20 / 30 / 40 / 50`, 마법공격력(보통) `10 / 20 / 30 / 40 / 50` | 치명타확률 `+10%` |
| 스태프 | 무기 | 물리공격력(낮음) `5 / 10 / 15 / 20 / 25`, 마법공격력(높음) `20 / 40 / 60 / 80 / 100` | 마나 `+30` |
| 오브 | 무기 | 물리공격력(낮음) `5 / 10 / 15 / 20 / 25`, 마법공격력(보통) `10 / 20 / 30 / 40 / 50` | 마나회복 `+4` |
| 중갑옷 | 방어구 | 물리방어(매우 높음) `30 / 60 / 90 / 120 / 150`, 마법방어(높음) `20 / 40 / 60 / 80 / 100` | 메인스킬 가드 |
| 경갑옷 | 방어구 | 물리방어(높음) `20 / 40 / 60 / 80 / 100`, 마법방어(보통) `10 / 20 / 30 / 40 / 50` | 메인스킬 회피태세 |
| 천옷 | 방어구 | 물리방어(낮음) `5 / 10 / 15 / 20 / 25`, 마법방어(보통) `10 / 20 / 30 / 40 / 50` | 마나 `+20`, 메인스킬 배리어·매직가드 |

총 장비는 35종(무기 20종, 방어구 15종)입니다. 동일한 `종류 + 티어` 장비는 중복으로 획득되지 않습니다.

## 던전 보상과 드랍 확률

## 이번 테스트 조정

- 모든 던전의 실제 지급 경험치는 `기본 경험치 × 3`입니다. 던전 상세와 승리 결과에도 3배 적용 후 수치를 표시합니다.
- 최초 클래스와 Lv.11/Lv.21 클래스 선택은 각각 무작위 6개 후보로 고정됩니다. 새로고침해도 같은 6개가 유지됩니다.
- 선택한 클래스는 숙련도 1에서 첫 번째 스킬을 즉시 보유합니다.
