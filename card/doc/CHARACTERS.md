# Card 전체 능력과 전투 컨셉

[문서 시작점](README.md) · [밸런스와 실제 적용 예외](BALANCE.md) · [수정 위치](SOURCE_MAP.md)

기준: 2026-10-04, `7635238`의 최종 콘텐츠 정의. 아래 기본값/문구는 해당 코드에서 추출한 정적 자료이며 새 실측 결과가 아니다.

최종 [data.js](../game/data.js)와 `GameUtils.getAllCards()` 기준 수집 가능 정의는 **161개**다: 기본 50(클래식 45+루미 의상 5), 보너스 74, 시즌 특별 25, 기본 초월 7, 보너스 초월 5. 여기에 독립 수집하지 않는 전투 형태 3개가 있다. 같은 캐릭터의 의상/초월/변신을 각각 별도 인물로 세지 않는다. 적 정의 15종도 아래에 구분했다.

컨셉은 데이터의 속성·역할·특성·스킬이 만드는 **전투 역할**이다. 원작의 성격/관계/세계관을 새로 정한 자료가 아니다. 스킬 해설은 [SkillDisplay](../game/skill_display.js)의 `type/cost/tier/val/effects` 해석을 그대로 사용했다. 특성 조건의 실행 위치는 `logic.js`와 `battle_runtime.js`에 있으며, 문구를 고치는 것만으로 조건이 바뀌지 않는다.

기본 능력은 축복·배치·덱 시너지·필드·아티팩트 적용 전이다. 기본 MP는 100이며 자동 회복은 없다. `unlockSource`는 데이터 분류로 표시한다. 실제 출현은 해금·모드·활성 카드풀·시즌 조건에 따라 달라지며 미리보기는 지급이 아니다. 초월형도 항상 일반 뽑기에서 나오는 카드가 아니다.

미라클라바는 전투 중 미러코쿤으로, 이후 오로라윙 또는 어비스윙으로 변신한다. 형태는 기본 카드의 획득/편성 식별자와 분리한다. 시즌 특별형은 별도 스킬 override가 있고 루미 의상 5개도 독립 카드 데이터이므로 외형만 다른 Shooter 의상 규칙과 혼동하지 않는다.

## 갱신할 때

`data.js`의 최종 확장/override 후 전체 정의와 전투 전용 목록을 따로 대조한다. 새 스킬/조건은 `SkillDisplay` 해설과 실제 실행을 함께 확인한다. 이름 변경 시 다른 조건 코드·로컬 초상화 경로·시즌/미션·세트 저장을 함께 확인하고 안정 ID는 유지한다. 이번 표는 정적 문서이며 이후 데이터 변경 시 이 문서를 함께 갱신한다.
