# Card 진행 방식과 기능 의도

[문서 시작점](README.md) · [밸런스](BALANCE.md) · [카드 능력](CHARACTERS.md)

기준: `7635238`의 활성 Card 코드. 구현 규칙은 현재 코드와 [구현 매뉴얼의 정오표](../GAME_MANUAL.md#0-코드-동기화-정오표-필독)를 기준으로 한다. 기능 의도는 기존 설계와 실제 규칙을 연결한 해석이다.

## 기본 진행

1. 진행 종류와 모드를 선택한다. 고정 구간을 돌파하는 챌린지와 끝없이 기록을 쌓는 엔드리스는 시작 카드풀·보상·종료 조건이 다르다.
2. 이번 런의 카드와 티켓을 얻고 선봉·중견·대장 3칸을 채운다. 빈칸이 있으면 전투에 들어가지 못한다. 보유 수량과 해당 모드의 편성 제한이 적용된다.
3. 전투에서는 현재 출전 카드가 평타 또는 스킬로 행동한다. 플레이어와 적의 턴, 지연 스킬, 필드버프와 상태 효과가 진행되며 아군이 죽으면 다음 슬롯이 출전한다. 아군의 전투 준비와 전투 순서는 별도 상태다.
4. MP는 기본 100으로 시작하고 스킬 비용을 지불한다. 기본 자동 MP 회복은 없다. 고효율 평타, 보호, 조건 만들기, 큰 스킬을 사용할 순서를 결정해야 한다.
5. 적을 처치하면 모드별 티켓과 진행 보상을 처리하고 다음 전투를 준비한다. 보스·창조신·숨은 보스·시즌 보스에는 추가 퀴즈나 해금 경로가 있다.
6. 패배·클리어 시 모드별 종료 루틴으로 이동한다. 카오스/드래프트의 런 정리와 팩토리의 저장 유지처럼 차이가 있으므로 모든 모드를 같은 패배 규칙으로 취급하지 않는다.

## 기능별 의도

| 기능 | 현재 규칙의 핵심 | 기능 의도 |
| --- | --- | --- |
| 3칸 순서 | 배치 특성과 사망 후 교대가 슬롯을 참조 | 같은 카드 목록도 순서에 따라 다른 전투 계획 |
| 보유 수량 | 카드를 보유한 만큼 편성 가능 | 수집과 편성을 연결하며 도감 열람과 지급을 구분 |
| 평타·MP | 일반 행동과 MP 소모 스킬을 구분, 자동 회복 없음 | 당장 피해와 후반에 남길 자원을 비교 |
| 필드버프 | 아군 전체에 영향을 주고 일부 스킬이 소모 | 앞 카드가 조건을 만들고 뒤 카드가 마무리하는 연계 |
| 디버프·중첩 | 부식·암흑·작열·디바인 등에 별도 조건/소모 | 낮은 기본 위력도 준비된 조건에서 역할을 갖게 함 |
| 초월·축복 | 후보·해금·런 상태를 각각 관리 | 장기 목표와 이번 런의 선택을 구분 |
| 아티팩트 | 일부 모드는 획득/풀/활성/사용 횟수가 다름 | 같은 카드 조합을 다른 자원·조건으로 사용 |
| 모드 | 카드 등급·뽑기·소멸·상태·보상 규칙을 변경 | 매번 같은 최상위 카드 편성으로 끝나지 않는 변주 |
| 기본 카드 세트 | 클래식과 5개 테마 세트, 세트 revision과 프리셋 유지 | 서로 다른 연계를 중심으로 출발 카드풀을 탐색 |
| 학습 | 단어·연어·문법·TOEIC·오답 복습, 일부 게임 보상과 연결 | 학습 진행을 전투 진행과 연결하며 내장 문제를 오프라인 제공 |
| 루미 AI | API 키를 사용하는 선택 기능 | 내장 해설 외에 개인 질문/과외를 제공 |
| 테마·초상화 | 테마는 색·프레임·배경, 로컬 초상화는 별도 | 규칙과 배치를 유지하면서 표현을 선택 |

## 모드 지도

현재 UI의 모드 ID는 다음 16개다. `overdrive`는 남은 내부 분기이며 선택 모드로 세지 않는다. 시작 티켓과 세부 클리어 조건은 [현재 모드 표](../GAME_MANUAL.md#8-모드)를 참고한다.

| 묶음 | 모드 | 달라지는 선택 |
| --- | --- | --- |
| 기본/기록 | 오리진 `origin`, 퍼펙트플랜 `perfect_plan` | 기본 진행, 제한된 40장 전용 풀로 계획 |
| 등급/보상 제한 | 제약의 시련 `restriction`, 균형의 도전 `balance`, 고난의 여정 `suffering` | 낮은 등급 조합, 보상과 축복의 교환 |
| 학습/소모 | 퍼즐 `puzzle`, 아카이브 `archive`, 꿈의회랑 `dream_corridor` | 퀴즈 기반 확보·소멸·정답률·숨은 TOEIC 진행 |
| 상태 규칙 | 저주의 증폭 `curse`, 축복의 범람 `flood` | 디버프·필드 계수의 강화와 적 강화 |
| 매 전투 재구성 | 카오스 `chaos`, 아티팩트카오스 `artifact_chaos` | 다음 전투 풀을 다시 조립, 후자는 아티팩트 조합 추가 |
| 선택형 확보 | 드래프트 `draft`, 팩토리 `factory` | 선택지/리롤, 40장 번들 선택 |
| 아티팩트 중심 | 아티팩트 `artifact`, 아티팩트리저브 `artifact_reserve` | 획득과 장착, 12개 풀에서 각 2회·전투 전 최대 4개 활성 |

꿈의회랑은 실전마법연습 3회 후 나타나는 숨은 흐름이다. TOEIC Part 5/6/7 세트에서 2문제 이상 오답이면 세트 실패 1회로 세고, 3회째 종료한다. TOEIC 세트 개정과 저장 프리셋은 학습 데이터·런 상태와 함께 관리한다.

## 저장과 실행

런 저장, 글로벌 해금, 학습 진도, 설정은 서로 다른 키다. 저장 이동은 설정의 기록 내보내기/가져오기를 사용하며 API 키는 백업에 포함하지 않는다. 브라우저·경로 변경이 저장을 자동 이전하지 않는다.

배포 파일은 `card/dist/DREAMWEAVER.html`이다. 기본 게임과 내장 학습은 오프라인이며, 실제 초상화·음원은 로컬 파일로 제공한다. Gemini 질문·과외·데이트는 네트워크와 API 키가 필요하다. 새 화면의 표시 작업은 `src/`에서, 전투 및 저장 규칙은 `game/`에서 수정한다.
