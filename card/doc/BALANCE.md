기준: `7635238`의 `game/data.js`, `logic.js`, `battle_runtime.js`, `rpg_features.js`. 아래 기본 수치와 단순 계산 예시는 플레이 승률/실측 DPS가 아니다. 같은 게임 안에서 조건을 고정해 비교하기 위한 자료다.

## 카드 수치를 읽는 법

| 항목 | 뜻 | 비교 시 주의 |
| --- | --- | --- |
| HP | 전투용 최대/현재 생명의 기본값 | 시작 시 덱·슬롯 특성, 전투 중 회복·변신과 구분 |
| ATK / MATK | 물리 / 마법 공격력 | 스킬 유형에 맞는 값 사용 |
| DEF / MDEF | 물리 / 마법 방어력 | 공격력에서 단순 빼기 방식이 아님 |
| MP | 기본 최대 100, 비용 지불 | 기본 턴·피격·행동 자동 회복 없음 |
| 위력 `val` | 기본 공격력에 적용할 스킬 배율 | 조건 배율·소모·관통·특성과 함께 계산 |
| 티어 `tier` | 스킬의 구분 메타데이터 | 비용·피해 배율과 같은 숫자라고 가정하지 않음 |
| 특성 | 덱·슬롯·상태·턴·피격·사망·보상 조건 | 초기 계산과 실시간 효과의 발동 시점 구분 |
| 역할 | 딜러·버퍼·디버퍼·밸런서·루터 등 데이터 분류 | 등급이나 직접 피해만으로 역할 가치를 결정하지 않음 |

현재 수집 가능 정의는 161개이고 별도 전투 전용 형태 3개가 있다. 이 숫자는 한 계정이 바로 획득할 수 있는 수량이 아니다. 기본 세트/보너스 활성/이벤트/초월 해금과 모드 규칙이 출현 풀을 결정한다. 모든 정의의 기본 스탯·특성·스킬은 [CHARACTERS.md](CHARACTERS.md)에 있다.

## 피해 계산의 핵심

보정 후 공격력 A × 최종 배율 M × `100 / (100 + 유효 방어력)`을 내림 처리한다. 물리는 ATK·DEF, 마법은 MATK·MDEF를 사용한다. 최종 가드 감소에는 다시 정수화가 있다. 적 공격은 별도 턴 경로에서 회피 → 배리어(물리) → 매직가드(마법) → 가드를 먼저 판단하며, 아군 공격과 같은 처리 함수를 공유한다고 가정하지 않는다.

| 다른 효과가 없는 예 | 계산 결과 |
| --- | --- |
| 공격력 100, 위력 2배, 방어 0 | 200 |
| 공격력 100, 위력 2배, 방어 100 | 100 |
| 위 조건 + 기본 치명타 1.5배 | 150 |
| 위 조건 + 상성 우위 1.2배 | 120 |
| 위 조건 + 치명타·상성 우위 모두 | 180 |

이 예는 초기 특성·필드·관통·가드·아티팩트가 없는 단순 비교다. 방어 100→200은 피해 계수 1/2→1/3이다. 방어 증가 100을 피해 100 감소로 읽으면 안 된다.

초기 자기/배치 특성은 순서대로 곱하고 정수화한다. 같은 파티 보너스는 합해 한 번 적용한다. 전투 중 필드/특성/디버프는 해당 스탯 계수에서 가감한다. 스킬 효과에서 ‘배율 +N’과 ‘배율 ×N’은 다른 연산이다. 특성 피해 보너스는 각 `(배율−1)`을 더해 적용하므로 조건 두 개가 있다고 각각 무조건 연속 곱하지 않는다.

## 조건·상태·자원

| 규칙 | 현재 기준 |
| --- | --- |
| 기본 치명/회피 | 10% / 5%. 축복 카드 추가 +10/+5%p |
| 상성 우위 | 물→불, 불→자연, 자연→물, 빛↔어둠은 1.2배. 불리 상성 감산 없음 |
| 치명타 | 기본 1.5배, 태양의축복 +0.6, 사신강림 +0.4. 플러드는 해당 필드 가산 강화 |
| 달의축복 | MATK +30%, 회피 +15%p. 버프 자체에 관통 없음 |
| 필드버프 | 기본적으로 플레이어 카드에 적용, 팬텀 면역. 부여/소모/만료/중복은 효과별 규칙 |
| 작열/디바인 | 기본 최대 3중첩, 오버플레임/오버디바인은 5중첩과 부여 2중첩 |
| 아이스브레이크 | 기절 대상 2배, 신기 포세이돈 조건은 2.5배 |
| 블루문 | 30% 확률 MP 미소모 |
| 서포트부스트 | 보조 스킬 MP 비용 0 |
| 럭키비키 | 치명 또는 회피 시 MP +10 |
| 아레나 | 일반 공격 대미지 2배. 모든 스킬 피해 2배로 적용하지 않음 |
| 지연 스킬 | 예약과 발동 시점 분리. 시간의마술사 특성은 별도 즉시 발동 경로 |

스택 소모는 피해 계산용 가상 상태와 실제 사후 제거를 구분한다. 가드 감소의 ‘가디언’ 특성은 이름이 정확히 `가드`인 스킬 조건을 참조한다. 문구/ID 변경이 계산 조건에 영향을 주는 항목은 [코딩 계약](../CODING_GUIDE.md)을 따른다.

## 뽑기 확률과 성장 비교

`GACHA_RATES`의 누적 임계값을 개별 확률로 풀면 다음과 같다. 표의 ‘챌린지’는 티켓을 먼저 소모하고 학습 퀴즈에 정답을 맞힌 뒤 실행하는 챌린지 뽑기의 확률이다. 퀴즈에 실패하면 소모한 티켓은 돌아오지 않으며 카드도 지급하지 않는다. 해당 모드의 실제 출현 카드풀은 별도 필터와 해금 조건을 거친다.

| 확률표 | 노멀 | 레어 | 에픽 | 전설 |
| --- | --- | --- | --- | --- |
| 기본 일반 | 40% | 30% | 20% | 10% |
| 기본 챌린지 | 25% | 30% | 25% | 20% |
| 제약 일반 | 80% | 20% | 0 | 0 |
| 제약 챌린지 | 60% | 40% | 0 | 0 |
| 균형 일반 | 70% | 20% | 10% | 0 |
| 균형 챌린지 | 50% | 30% | 20% | 0 |

낮은 등급의 조건부 배율·필드 소모·사망 효과·마나 비용이 상위 등급의 기본 스탯 차이를 바꿀 수 있다. 등급별 스탯 평균만으로 조정하지 않고 실제 3칸 순서·필드 생성→소모·MP 잔량·적 방어를 고정한다.

클래식은 원래 45장, 나머지 테마 기본 세트는 등급별 10장씩 40장 구성이다. 6개 세트의 축은 [진행 문서](GAMEPLAY.md#카드-세트의-전투-컨셉)에 있다. 세트별 등장 빈도와 보너스 프리셋 활성 조건을 함께 고정해야 공정하게 비교할 수 있다.

## 보상·아티팩트·종료 조건

기본 아티팩트 26종과 신기/마신기 10종이 있다. 일부 신기는 기본 아티팩트를 대체하므로 36개를 항상 함께 소유/장착한다고 해석하지 않는다. 아티팩트리저브는 세트 4회 선택으로 12개 풀, 각 2회 사용, 전투 전 최대 4개 활성이라는 사용 자원을 가진다.

승리 티켓은 모드 기본 보상에 참가자의 루터 특성, 적의 추가 티켓 등 실제 분기를 더한다. 현재 루터 보상은 마지막 일격 카드만 검사하는 조건이 아니라 전투 참가 카드 목록을 확인한다. 기본 승리 보상 처리 뒤 선택형 퀴즈/축복/미션·해금 처리를 이어 간다. 고난의 여정의 기본 보상 0과 축복 보너스, 퍼즐의 카드 소멸, 꿈의회랑의 세트 실패는 별도의 비용이다.

클리어 길이와 시작 티켓은 [현재 16모드 표](../GAME_MANUAL.md#8-모드), 해금/보상은 [모드·보상 매뉴얼](../../card_manual/09_modes_rewards_unlocks.md), 아티팩트는 [구현 매뉴얼](../GAME_MANUAL.md#11-아티팩트)을 대조한다.

## 밸런스 검토용 기록 형식

같은 모드·일반/챌린지·하드 여부·스테이지·적·기본 세트 revision·보너스 프리셋·3칸 순서·축복·아티팩트를 고정한다. 시작과 종료 HP/MP, 사용 스킬 순서, 필드/중첩 생성과 소모, 교대 시점, 최종 티켓을 기록한다. 치명·회피·랜덤 효과는 한 결과만으로 일반화하지 않는다.

수치 변경 후에는 데이터 정의·계산 핸들러·턴 처리·표시 해설·매뉴얼을 함께 갱신한다. 필요한 검사와 배포 범위는 [SOURCE_MAP.md](SOURCE_MAP.md)를 따른다. 이번 문서 PR에서는 플레이/밸런스 시뮬레이션을 실행하지 않았다.
