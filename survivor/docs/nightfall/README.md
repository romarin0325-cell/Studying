# NOCTURNE Nightfall — 전투 보행과 새 밤

이 변경의 대상은 최신 main `34a0c13b1a2c86a117beca28e67f385680f1edc9`의 **ASTRA NOCTURNE (`survivor/`)** 입니다. 현재 승인된 Nocturne 전신·보행 그림을 수정 대상으로 삼았으며, Defense의 다른 SD 화풍을 새 캐릭터에 적용하지 않았습니다. 공유 Card/Shooter/Defense 소스는 수정하지 않았습니다.

## 지크와 루나: 전투 중 이동하는 자세

목표는 검을 들고 있다는 표시가 아니라 **무기를 준비한 채 전투 중 이동하는 모습**입니다. 첫 지크 후보는 대검을 한 손으로 치켜든 자세여서 거부했습니다. 채택본은 양손으로 몸 가까이 대검을 받치고 검과 상체를 안정시킨 보행입니다. 루나는 단검을 상체 가까이 든 자세를 사용합니다. 얼굴·머리·갑옷·코트·레이스·색상은 현재 Nocturne 그림을 기준으로 유지했습니다.

두 인물 모두 **왼쪽의 4단계 보행 전체를 오른쪽에 반전**합니다. 지크의 양손 자세와 루나의 독립 측면 사이의 상체 기울기 차이를 검토한 뒤 선택했습니다. 단검을 포함한 측면 손의 표현도 반전됩니다. 모든 방향에서 해부학적 오른손이 그대로라는 주장으로 표시하지 않습니다. 앞/뒤 그림은 각각 작성된 포즈를 사용합니다. 다리·얼굴·옷 일부만 잘라 바꾸거나 가로·세로를 따로 늘리지 않습니다.

## 다음 에셋 작업에서 지킬 기준

1. 현재 `assets/atelier/sources/walk-*.png`와 실제 `prepared/walk-*.webp`를 먼저 본 뒤 수정합니다. 과거 Defense 원화는 정체성의 참고이며 현재 Nocturne의 화풍·체형을 대체하지 않습니다.
2. 머리는 **정수리의 두개골에서 턱까지**입니다. 토끼귀, 머리카락 부피, 모자, 후광, 뿔, 무기를 머리에 포함하지 않습니다. 전체 불투명 영역 bbox는 잘림 검사용으로만 쓰고 몸을 셀에 자동 축소하는 기준으로 쓰지 않습니다.
3. 목표는 512px 셀의 명목 머리 높이 144px, 공통 발 기준 480입니다. 보행 캐시는 셀 208, 발 `(104,195)`, 화면 배율 1.3입니다. 원본 전체의 균등 배율과 발 위치 이동만 허용합니다. 얼굴/몸통/다리의 별도 배율은 금지합니다.
4. `body-profile.json`의 방향별 정수리·턱·발, 원본 SHA, 수동 추정과 영상 정합 결과를 기록합니다. 이번 두 인물의 가려진 기준점은 정수리 약 ±4px, 턱 ±2px, 발 ±1px의 수동 추정으로 기록했습니다. 이는 자동 해부학 검출의 정확도나 완벽한 1px 일치를 뜻하지 않습니다.
5. 무기 종류를 자세에 반영합니다. 대검은 무게를 받치는 두 손과 안정된 상체, 단검은 가까운 가드와 이동을 표현합니다. 보행의 접지/통과/반대 접지/통과가 연결되어야 합니다. 독립 측면의 단계가 어긋나면 원본의 온전한 주기를 반전하고 반전 사실을 기록합니다.
6. 64/96px, 실제 게임 크기, 밝고 어두운 바닥, 앞뒤좌우, 네 단계의 발/상체/무기 움직임을 눈으로 확인합니다. 공통 머리 목표를 설정했다는 사실과 실제 생성 그림의 해부학적 일치를 구분합니다.

수동 기준을 수정한 뒤 `node survivor/scripts/review-art.mjs --measure`, `node survivor/scripts/prepare-assets.mjs`를 실행합니다. 검토기는 `node survivor/scripts/review-art.mjs survivor/docs/nightfall/review 34a0c13b1a2c86a117beca28e67f385680f1edc9`로 다시 작성할 수 있습니다. `--measure`는 검토한 머리 영역의 영상 정합이며 해부학 검출이나 신체 일부 교체가 아닙니다. Windows에서는 폰트 준비 도구를 UTF-8 모드(`python -X utf8 survivor/scripts/prepare-font.py`)로 실행합니다.

## 무기·유물과 히든 융합

| 추가 요소 | 실제 게임 규칙 |
| --- | --- |
| 홀리벨 | 플레이어 주변 무작위 지점에 짧은 예고 후 성광이 떨어집니다. 성장 시 개수와 원형 범위가 증가하며, 진화하면 두 기둥과 더 큰 범위가 추가됩니다. |
| 아쿠아웨이브 | 현재 바라보는 방향의 부채꼴 파동이 전방으로 퍼집니다. 반대편은 맞지 않습니다. 진화 후 더 넓은 각도로 두 번 펼쳐집니다. |
| 산타보따리 | 1/2/3단계에서 40/32/24초마다 근처에 보물상자를 생성합니다. 아이템 한도가 찬 경우 잠시 뒤 재시도합니다. |
| 심해의구슬 | 1/2/3단계에서 32/24/16초마다 맵 전체의 경험치·금화·회복·자석·보물상자를 끌어당깁니다. 전투 시간으로 재며 저장·재개 시 남은 시간이 보존됩니다. |
| 극야의 불사조 | **불사조의 맹세 + 프로즌 월드**. 세 불사조가 날아가며 빙결과 화상을 남깁니다. |
| 몽환의 시계탑 | **깨어나지 않는 밤 + 스톱 더 월드**. 회전하는 세 시침이 대열을 가르고, 세 번째 박동마다 맞은 적의 시간을 잠시 멈춥니다. |
| 심해의 성가 | **새벽을 깨우는 종 + 해일의 문**. 세 성가의 눈이 플레이어 주위를 돌며 원형 파동을 반복해 냅니다. |

히든 융합은 **두 재료가 각각 진화 6단계**일 때 자동으로 이루어집니다. 재료 두 개와 진행 중인 재료 공격을 제거하고 새 무기 한 개를 넣어 장비 한 칸을 비웁니다. 피해 기록을 승계하고, 재료는 다시 선택 목록에 나타나지 않습니다. 새 무기를 위한 개수·소모 이력·공격 상태와 추적 목표를 저장합니다. 기존 2단계 공명은 별도 규칙입니다. 조합 도감과 전투 중 조합 지도에는 16개 진화·4개 공명·3개 융합의 조건과 진행을 표시합니다.

Vampire Survivors의 무기 합성과 도감 노출은 [poncle의 공식 패치 안내](https://store.steampowered.com/news/posts/?enddate=1655998463&feed=steam_community_announcements) 및 [후속 공식 안내](https://store.steampowered.com/news/posts/?enddate=1761672541&feed=steam_community_announcements)를 참고했습니다. 본 게임의 두 **진화 최고 단계** 조건과 효과는 사용자 요구에 맞춘 별도 설계입니다. 상대 게임의 아트/코드를 사용하지 않았으며 공식 위키의 Evolution 상세 페이지는 접근 차단으로 직접 확인하지 못했습니다.

## 화면·진행·저장

- 별의 기억: 20단계로 확장. 현재 누적 효과와 다음 단계에서 더해지는 실제 수치를 표시합니다. 증가량 `기본값 × 0.9^현재단계`, 가격 `기존 기본가격 × 1.45^현재단계`와 기존 5 단위 반올림을 유지합니다. 좁은 세로 화면은 2열, 짧은 가로 화면은 6열로 여섯 항목을 비교할 수 있습니다. 상단 결정 수치는 내장 폰트와 좁은 화면의 간격 조정으로 `100,000,000`까지 전체 숫자를 유지하며 브랜드·버튼과 겹치지 않습니다.
- 경험치 요구량: 기존 정수 요구량의 1.5배를 올림 처리, 시작 요구량 8→12입니다. 이미 얻은 경험치는 유지합니다.
- 적 체력: 일반 적, 정예, 보스·특별 등장 수치 모두 1.3배입니다. 모드·난이도에 공통 적용합니다. 오래 진행한 끝없는 밤의 저장 가능한 최대 체력은 13,000,000 미만으로 제한합니다.
- 새 지역: **침묵의 심해**, **깨진 별의 관측소**. 각각 기존 마지막 지역보다 높은 체력 배율 1.55/1.8, 추가 군세 밀도 1.18/1.3입니다. 짧은 원정은 3:30에 마지막 파수꾼이 등장하고 **살아서 4:00을 맞으면 종료**합니다. 마지막 보스를 먼저 처치해도 생존 시간은 이어집니다. 끝없는 밤은 4분 이후에도 기존 주기로 진행합니다.
- 회피: 필살기와 같은 버튼 크기, 오른쪽 엄지 위치를 유지합니다. 두 번째 포인터의 누르는 시점에 현재 이동 방향으로 실행하며, 호환 클릭의 중복 발동을 억제합니다. 이동 포인터는 그대로 유지합니다.
- 밤토끼: 흐르는 초승달과 꿈결의 장판. 시간의지배자: 금빛 시침·눈금의 정밀한 시계 장판입니다. 아군 효과는 캐릭터 아래, 적의 경고는 아군 효과 위에 표시합니다.
- 이전 v1 실행 기록은 균형 변경을 한 번만 적용합니다. 기존 프로필·최고 기록·영구 성장과 원정 길이 호환성을 유지합니다.

회피 도중 일시정지한 경우 위치와 남은 회피 시간을 그대로 복원하고, 재개 후 남은 이동만 이어갑니다. 브라우저 검사는 이어가기와 일시정지를 같은 이벤트 작업에서 실행해 다음 시뮬레이션 프레임 전의 복원 위치를 정확히 비교합니다. 재개한 게임을 잠시 진행한 뒤 위치가 전혀 바뀌지 않을 것이라고 가정하지 않습니다. 별도 전투 회귀 검사에서는 복원한 회피의 이후 결과를 원래 실행과 비교합니다.

## 배포·검증 자료

배포 파일은 `survivor/dist/AstraNocturne.html`입니다. 원본 PNG를 게임에 직접 넣지 않습니다. 캐시에는 아이템 160px 셀, 신규 효과 144px 셀, 신규 배경 640px / WebP quality 80을 사용합니다. 전신 도감은 같은 중립 방향도에서 잘라 그려 중복 `full-*` 디코딩과 임베딩을 제거했습니다. 배포 텍스처는 39개, 작성 검수용 캐시는 48개입니다. 텍스트 원본의 SHA는 Git의 CRLF/LF 차이를 정규화하고, 이미지 바이트의 SHA는 그대로 검증합니다.

[최종 검증 수치](VALIDATION.json), [실제 명령 출력](verify-local.txt), [입력만 사용하는 새 지역 생존 표본](survival-sample.json), [게임 화면](screens/)을 함께 확인합니다. 이 결과는 데스크톱 Chromium/WebKit에서 오프라인 파일을 실행한 근거이며 실제 Android/iOS 기기의 장시간 FPS·발열·터치 지연 또는 재미 평가를 인증하지 않습니다. 새로운 그림체, 자세, 재미에 대한 최종 수용은 사용자의 플레이 판단이 남습니다.
