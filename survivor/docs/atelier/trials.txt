A01 main fetch, #570 병합과 c958f64 확인. AGENTS.md·BODY_PROFILE·ART.md·Defense 지침/4방향 원화를 재검토. 기존 전체 캐스트/보행 비교 원본 보관.
A02 분할 머리/몸통/다리 배율을 실제 그림에서 재검토. 얼굴/목과 의복 드레이프의 연속성 손상이 생겨 현행 런타임 패킹에서 제거. 균등 전체 스케일만으로 내부 비율을 맞출 수 없으므로 새 원화 제작으로 진행.
A03 9인 공통 캐스트 마스터 이미지 생성. 실패/거부: 은토끼의 민소매 의상이 긴 코트처럼 바뀌고 성인 머리/몸 비율 불일치. 런타임에 채택하지 않음.
A04 루미 4x4 보행 전신 재생성. 채택: 원화의 맨발·종아리 리본·모자·망토, 자연스러운 연결된 관절/옷 유지. 비무장 좌우는 동일 주기의 전신 반전.
A05 루나 4x4 보행 전신 재생성. 채택: 오른손 단검 유지, 별도 좌우의 손/얼굴/주름 검토.
A06 지크 4x4 직접 보행 생성. 후보 보존/거부: 성인 체형과 고정 보행에 체형 가이드 버전이 더 적합.
A07 자스민 4x4 직접 보행 생성. 후보 보존/거부: 체형 가이드 버전의 드레스·손 방향·소폭 보행이 더 적합.
A08 눈토끼 4x4 직접 보행 생성. 후보 보존/거부: 긴 보폭과 단신의 구분을 개선하기 위해 체형 가이드 버전 선택.
A09 밤토끼 4x4 직접 보행 생성. 실패/거부: 왼쪽 마지막 프레임이 오른쪽을 향함. 수정 시도 A13.
A10 신데렐라 4x4 직접 보행 생성. 실패/거부: 왼쪽 마지막 프레임 방향과 파란 신발. 수정 시도 A14.
A11 은토끼 4x4 직접 보행 생성. 후보 보존/거부: 더 명확한 작은 몸으로 재생성. 민소매·베일·금빛 아래 머리색 확인.
A12 시간의지배자 4x4 직접 보행 생성. 후보 보존/거부: 체형 가이드 버전의 성인 팔다리·자연스러운 검은 치마가 더 적합.
A13 밤토끼 전체 시트에 국소 지시로 방향 수정 생성. 왼쪽 마지막의 방향은 고쳐졌으나 최종에는 A20의 단신 가이드 원화 선택. 런타임에는 채택하지 않음.
A14 신데렐라 전체 시트에 국소 지시로 신발/흰 머리/왼쪽 마지막 방향 수정 생성. 분홍 신발과 전신은 채택. 방향 수정은 실패: 마지막 왼쪽이 여전히 오른쪽. 온전한 오른쪽 네 포즈를 통째로 반전해 왼쪽 주기 제작. 머리/다리 조각 교체나 같은 passing 그림 복제는 쓰지 않음. 독립 측면 생성 성공이라 주장하지 않음.
A15 공통 전신 가이드 제작: 성인 2.55, 표준 2.35, 단신 2.0의 명목 두개골 높이. 첫 SVG의 몸통 경로 구문 오류로 몸통 누락; 좌표 공백을 수정해 육안 확인. 표준 가이드는 제작만 하고 재생성 참조로 사용하지 않음.
A16 시간의지배자: 체형/정체성/화풍 참조 역할을 분리해 성인 전신 재생성. 채택. 얼굴을 잘라 변형하지 않고 앞/뒤/측면의 목·머리·치마 연결 유지.
A17 자스민: 같은 성인 가이드로 재생성. 채택. 긴 드레스의 자연스러운 접힌 주름과 왼손 지팡이의 별도 좌우 검토.
A18 지크: 같은 성인 가이드로 재생성. 채택. 갑옷·코트·오른손 검과 다리 연결 검토.
A19 은토끼/눈토끼: 같은 단신 가이드로 두 시트 재생성. 두 후보 채택. 머리 크기에 귀/후광/베일을 포함하지 않고 몸이 작은 캐릭터의 실루엣 검토.
A20 밤토끼: 같은 단신 가이드로 재생성. 채택. 왼쪽 네 칸 모두 방향 확인; 검은 후드·흰 레그워머와 신발 관절 연결 검토.
A21 wholeFrame: 1개 이미지에 한 방향별 균등 전체 배율과 전신 이동만 적용. x/y 독립 배율과 부위별 배율 제거. 실제 잘림은 오류로 거절하며 몸을 억지로 축소하지 않음.
A22 영상 정합: 수동으로 검토한 머리 영역을 기준 passing 포즈에 맞춤. 초기 x ±28 탐색은 루미/눈토끼/밤토끼 등에 경계값 도달해 실패. ±65로 확대하고 144개 입력의 등록값·평균 제곱 오차·탐색 경계 여부 기록. 포즈 검출, 두개골 검출, 얼굴 치환으로 주장하지 않음.
A23 단순 4등분 추출은 일부 행의 귀·신발 끝이 경계에 걸림. 투명 추출 여백 x16/y18과 연결 성분 처리로 전신을 보존. 기본/보행 해시를 수동 BODY_PROFILE v3에 고정. 귀·무기 bbox로 몸 배율을 결정하지 않음.
A24 도감 시트 비교에서 Sharp의 resize/composite 순서 오류 발견. 합성 버퍼를 먼저 만든 뒤 최종 768px으로 축소. 추가 무기 주인 5명의 다리 잘림을 수정. 네 중립 방향 셀의 빈 테두리 검사를 추가.
A25 밝은 96px 검토에서 밤토끼 머리 위의 이전 행 부츠 조각 발견. 밤토끼 원화는 무기/분리 장식 없는 연결된 한 인물이므로 주 연결 성분만 채택. 흰 머리/의복을 RGB 밝기 키로 지우지 않음. 다른 무기/왕관은 검토된 근접 성분을 유지.
A26 로비/일시정지/결과/도감 캐시는 전투와 동일한 앞 passing 전신에서 제작. 전투 정지와 메뉴의 인물·의상·내부 비율 차이를 제거. 다른 게임 공유 원본은 변경하지 않음.
A27 실제 64/96px과 100/150px, 네 방향, 밝은/어두운 바닥, 모든 144칸과 같은 바닥선의 전체14명 검토. 비교 PNG, 좌우 주기 GIF(160ms 작성용), 재생/겹침 독립 HTML 보관. GIF 간격은 실제 게임의 FPS나 물리 기기 측정으로 주장하지 않음.
A28 새 authoring 스크립트 경로가 저장소 검증 매핑에 없어 verify:plan 차단. 검증 정책을 바꾸지 않고 기능을 기존 review-art.mjs의 --measure 옵션에 통합. 런타임에 작성 도구를 넣지 않음.
