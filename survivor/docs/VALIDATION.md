## 필수 검증

저장소 루트에서 다음 명령을 실행했고 **53개 계약/회귀 검사, 단일 HTML 빌드, Chromium·WebKit 오프라인 검사와 변경 JavaScript 문법 검사가 모두 통과**했습니다. 전체 실행은 59.13초였습니다. 검증 정책·다른 게임의 실행 코드는 변경하지 않았고 Card·Shooter·Defense 검사를 실행하지 않았습니다.

```sh
LD_LIBRARY_PATH=/workspace/review/webkit-libs/root/usr/lib/x86_64-linux-gnu \
PLAYWRIGHT_SKIP_VALIDATE_HOST_REQUIREMENTS=1 npm run verify
```

처음 일반 명령과 라이브러리 경로만 지정한 실행은 Playwright의 시스템 패키지 목록 검사에서 `libGLESv2.so.2`를 찾지 못해 실패했습니다. 사용자 디렉터리의 실제 Debian 13 라이브러리를 확인하고 **시스템 목록 검사만** 생략했습니다. 실제 WebKit 실행과 게임 검사를 모두 수행했습니다. [초기 실패 로그](ordeal/verify-environment-failure.txt)와 [시도 T21](ordeal/trials.txt)에 과정이 있습니다. 이 환경변수가 없는 일반 실행까지 성공했다고 주장하지 않습니다. CI는 저장소의 기존 `--with-deps` 설치를 사용합니다.

## 신체·이동·전투 계약

머리 목표144px, 토끼 몸140px/성인212px와 신체 기준점·원본 해시를 기록했습니다. 6명 오른쪽 보행은 실제 패킹 WebP의 alpha 좌표로 왼쪽 반전을 검사했습니다. 3명의 무기 손·고해상도 같은 통과 포즈·native alpha·빈 여백·44개 캐시와 메모리 예산도 검사했습니다. 숫자 검사만으로 표정·해부학·정체성을 보증하지 않습니다. [전체 14명](ordeal/cast-all.png), [main 비교](ordeal/before-after.png), [밝은 바닥 144칸](ordeal/walking-light.png), [64/96px 검토](ART.md)를 함께 확인했습니다.

엔진·실제 App 루프·Renderer의 60/90/120/144Hz와 불규칙한 간격에서 이동 정지/역방향/걷기 끊김은 모두0입니다. [motion-hz.json](ordeal/motion-hz.json)은 실제 코드에 합성 시간 간격을 공급한 검사이며 물리적인 144Hz 디스플레이 측정이 아닙니다. 고정60Hz 판정과 화면·카메라 보간, snapshot을 변경하지 않는 렌더링도 유지했습니다.

53개 계약에는 기존 9명 시작 무기·필살기, 14무기 기본/진화 피해, 선분 탄 충돌, 모든 지역·단계 보스의 몸통 조준, 진화·공명·폭주, 저장 이관/손상 거절/보상 중복 방지와 이번 아래 사항이 포함됩니다.

- 지역별 두 중간 보스와 최종 보스, 새벽 이후60초 간격, 체력/피해 한도와 저장 복원.
- 선분·고리의 실제 안전 영역·장판 판정, 회피 무적과 한 구역당 별빛 충전1회.
- 6개 보스 컨셉의 서로 다른 패턴, 패턴 상태 복원, 잘못된 새 저장 필드 거절.
- 일반 빙결의 보스 저항, 영구 정지장의 새벽 이후 저항과 여전히 작동하는 직접 필살기.
- 산책 난도9명 완주, 루나 성당/루미 혼돈의 틈 완주.

실제 배포 HTML에서 6보스 그림·패턴과 저장 재개를 **제어된 저장 fixture**로 확인했습니다. [장미사슴](ordeal/ordeal-thorn.png)·[종](ordeal/ordeal-clock.png)·[밤고래](ordeal/ordeal-eclipse.png)는 자연 플레이 사진과 구별합니다. 별도 테스트 HTML의 히든 상태 검사도 계속 실행합니다.

## 현재 난도와 성장

[balance-final.jsonl](ordeal/balance-final.jsonl)은 시드2026, 정원, 영구 성장 없이 정상 난도9명 × 짧은/무한 원정의 **이동·선택·회피·필살기 입력만** 사용한 18회입니다. 체력·시간·스폰을 변경하지 않았습니다. 파일의 모든 결과가 재현 가능한 한 시드의 자동 조작 결과이며 사람의 승률은 아닙니다.

짧은 원정은 **3/9 승리**, 승리 시간135.53~145.10초였습니다. 다른6명도 두 중간 보스를 처치하고 최종 보스에서 패배했습니다. 산책의9명 완주 검증은 따로 통과합니다. 강한 정상 보스를 전 캐릭터가 손쉽게 이기는 난도로 표시하지 않습니다.

끝없는 밤은 **9/9 패배**, 종료132.28~358.18초, 레벨44~94입니다. 120초 이후에는180·240·300·360초에 다음 보스가 추가됩니다. 시간이 지났다고 강제 종료하지 않으며, 강한 보스의 생존·패턴·누적 압력으로 끝납니다. 일부 캐릭터는 첫 추가 보스 전에 패배했습니다. 모든 시드·최대 메타·모든 빌드에 같은 종료 시간을 보장하지 않습니다. 선택/일시정지 시간은 전투 시계에서 제외됩니다.

은토끼는 강한 단일 대상에 기존 광선이 뒤처져 기본 피해/대기·단계별 밀도·투사체 유물 효율을 보정했습니다. 최종 원정135.53초 승리, 무한307.83초 패배입니다. 실패한 첫 시도와 수정 전 수치는 [trials.txt](ordeal/trials.txt)에 구분합니다.

## 실행 비용과 한계

전체 텍스처의 논리 `width × height × 4` 합은 **86.90 MiB**로 기존88MiB 계약 이하입니다. 보행은 최근2명만 디코딩하므로 전부 동시에 상주하는 합이 아닙니다. 브라우저 총 메모리나 GPU 측정으로 표시하지 않습니다. 광원·문양·피해 글자 캐시, 화면 밖 그림 생략, FX 풀·개체 한도, 품질별DPR, 고정 판정을 유지했습니다. 260적의 기존90프레임 동기 작업 표본은 평균 8.76ms였습니다.

보충 측정은 실제 release HTML에서 260적·6진화 무기·시계 보스와7위험의 저장 fixture를 이어갑니다. 30개 고유 rAF를 예열하고300개를 측정했습니다. 같은 timestamp의 UI 콜백은 합산합니다. 처음의 중복 timestamp0ms 표본은 폐기했습니다. [원자료](ordeal/render-raf.json)·[측정 스크립트 보관본](ordeal/performance-authoring.txt).

클라우드 CPU의 Chromium 측정입니다. 실제 iOS/Android의 열·장시간 FPS·터치 지연은 측정하지 않았습니다. WebKit 호환 검사와 브라우저 모바일 화면 검사를 실제 휴대폰 성능 인증으로 바꾸지 않습니다. 뼈대·모델 새 학습과 ControlNet/OpenPose/MediaPipe 실행도 하지 않았습니다. 생성 후보3개를 시험했지만 모두 기준에 못 미쳐 거부했습니다.
