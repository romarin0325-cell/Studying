# 별빛 원정 — 추가 에셋 기록

내장 이미지 생성 도구로 제작한 유물·축복·SD 전투 효과 세 아틀라스를 프로젝트에 포함한다.
CLI/API fallback이나 외부 게임 이미지 복사는 사용하지 않았다. 생성 원본의 정확한 이름, 요청 프롬프트,
최종 해시·크기는 [ART_PROMPTS.json](ART_PROMPTS.json)에 기록했다. 생성 결과의 크기는 요청 크기와 다를 수 있으며 기록에는 실제 배포 크기를 쓴다.

| 배포 파일 | 분할 | 실제 크기 | 처리 |
| --- | --- | --- | --- |
| `assets/merge/relics.webp` | 5열×4행, 유물 20개 | 1254×1254 | 생성 알파 보존, 753,090 bytes |
| `assets/merge/blessings.webp` | 3열×2행, 축복 6개 | 1536×1024 | 생성 알파 보존, 522,808 bytes |
| `assets/merge/effects.webp` | 7열×3행, 동료 21명 | 1792×768 | 순검정 바탕 screen 합성, 217,960 bytes |

아이콘은 content.js의 icon 순서대로 자른다. 유물 셀은 정수가 아닌 원본 크기 비율이므로 소수 좌표를 유지한다.
메뉴용 그림은 256px 캔버스에서 준비한다. 파일을 명도 키잉하거나 흰 재료를 투명하게 만들지 않는다.
전투 효과는 256×256 셀의 가장자리 5.5%를 인셋해 인접 셀 빛 번짐을 줄인다.
실제 생성된 참격/발톱의 기울기는 effects.js의 offset으로 교정했다.

## 선택과 검수

처음 검토한 더 사실적이고 세부가 많은 효과 후보 대신, 2–3색 핵심과 선명한 실루엣을 가진 21종 SD 시트를 선택했다.
PR #549에서는 캐릭터 방향도를 다시 생성하지 않았다. 후속 사용자 요청에 따른 신데렐라 수정은 아래에 별도 기록했다.
이펙트의 텍스처는 명중 실루엣이며, 비행 궤적·잔상·크기·범위·수명은 실제 전투 코드로 제어한다.

기본 브라우저 검사에서 아래 proof를 자동 생성한다.

- `all-21-attacks.png`: 모든 동료, 고유 투사체, 해당 명중 모양을 한 화면에서 비교.
- `directional-slashes.png`: 지크·루나·밤토끼·팬텀의 상하좌우 결과.
- `mobile-25-units.png`, `mobile-skill.png`: 실제 모바일 크기의 혼잡 전장.
- `relics.png`, `blessings.png`: 실제 메뉴 크기, 잘림·가독성 확인.

proof는 테스트가 출력하는 증거 디렉터리에 저장하며 제품 번들에 포함하지 않는다.
원본 생성 PNG는 생성 도구의 출력 위치에 보존하고, 런타임은 저장소의 세 WebP만 참조한다.
27개 출시 이미지 중 배경과 screen 합성용 효과를 제외한 25개는 실제 알파 검증을 받는다.

## 신데렐라의 소폭 머리 축소 — 2026-09-27

- 모드: 내장 image_gen의 reference-image edit, transparent_background=true. CLI/API fallback 없음.
- 입력: 승인된 `assets/merge/units/cinderella.webp`. 다른 인물 그림은 기준으로 바꾸지 않았다.
- 선택 원본: `exec-1b761670-9353-40d0-8ede-e6c11e79a4fb.png` (1254×1254 RGBA). 앞선 후보는 축소가 과해 선택하지 않았다.
- 배포: 같은 `assets/merge/units/cinderella.webp`, 1024×1024, 정면/후면/좌/우 네 방향.
- 최종 프롬프트·원본/출력 SHA는 ART_PROMPTS.json, 발·얼굴·두개부 추정 좌표는 docs/art/ANATOMICAL_LANDMARKS.json, 파생 결과는 units/manifest.json에 기록했다.
- HEAD_PROFILE의 신데렐라 전용 0.95 예외는 요청한 작은 머리를 다시 공통 목표로 확대하지 않기 위한 것이다. 다른 20개 캐릭터 파일은 바뀌지 않는다.
- 추정 정면 두개부는 기존 157.4×152.5 → 149.7×144.7px (약 5% 감소). 턱 아래 몸길이 추정은 213.1 → 217.9px로 약 2.3% 차이가 있다. 생성 편집이므로 몸이 픽셀 단위로 동일하다고 주장하지 않는다. 성별·평평한 가슴·의상·네 방향·발 기준선과 SD 인상을 비교 검수했다.
- 생성 원본의 칠해진 내부는 주로 alpha 253이었다. 원본별 `alphaOpaqueThreshold:250`을 기록하고 가져오기 단계에서 250~255만 255로 복구했다. RGB/흰색 밝기로 투명도를 추정하지 않으며 낮은 알파의 경계는 유지한다. 모든 방향의 실제 불투명도 검사를 통과해야 한다.

## 보스 단독 필살기

추가 전체 화면 비트맵 없이 기존 21종 SD 효과와 절차적 테두리/큰 문양을 조합했다. 큰 문양은 낮은 알파로 바닥에,
보스·동료·경고는 그 위에 둔다. 일반/줄인 효과 모드에서도 적 한 명만 있을 때 유지된다.
`all-21-single-boss-skills.png`, `one-boss-skill-no-preference.png`, `one-boss-skill-reduce.png`를 브라우저 검사에서 생성한다.
