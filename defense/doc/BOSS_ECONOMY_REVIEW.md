# 보스·경제 조정 검증 — balanceRevision 2

2026-09-27. 기준은 PR #549 이후 활성 `defense/merge/engine.js`다.
사용자가 경제 수치 변경까지 승인했다. 아래는 실제 수식과 타이밍을 고정한 시나리오 분석이며,
다양한 인간 플레이어의 승률·재미를 입증하는 대규모 플레이테스트가 아니다.

## 경제 역할과 조정

초기 45G, 무료 소환 3회, 유료 10→40G, 이자 없음, 강화 비용 28/52/76/100/124G는 유지한다.
공격 위력도 원래 기본 위력의 +28%p/단계를 유지한다. 경제 스킬의 고정 수입도 그대로다.

| 동료 | 수입 시점·조건 | 강화 전 기본 수입 | 단계당 추가 수입: 이전 → 변경 |
| --- | --- | --- | --- |
| 신데렐라 | 실제 합성 재료로 소모되는 순간 1회 | 소모 성급 × 18G | 소모 성급 × 2G → **× 4G** |
| 여왕 | 살아남은 물결 종료 시, 배치 개체마다 | 3 + 성급×2 + floor((물결−1)/3)G | 개체당 1G → **3G** |
| 머쉬룸킹 | 배치된 전투 시간 12초마다 | 성급 + 2G | 개체당 1G → **2G** |

신데렐라는 두 동일 개체가 하나로 합쳐지면서 돈과 화력을 함께 얻지만 재료가 필요하다.
루미를 먹여 성장시키면 신데렐라 재료가 사라지지 않으므로 환급하지 않는다. 양쪽 드래그 방향 모두 같다.
여왕은 빠른 클리어에도 배당을 받으며 전체 여왕의 합계는 물결당 45G로 제한한다.
머쉬룸킹은 긴 전투에서 유리하지만 전투가 끝나면 시간이 멈춘다. 이동은 수확 시간을 보존하고 합성은 12초부터 다시 센다.
전투 바깥에서 기다리기만 해 수입을 얻는 구조는 없다.

## 첫 강화 28G를 '추가 수입만으로' 회수하려면

할인·공격 증가·기회비용을 제외한 한계수입 비교다. 원래부터 벌던 돈은 회수액에 넣지 않는다.
여왕 상한이 걸리지 않으며, 표에 적힌 동일 개체 수를 계속 유지한다고 가정한다.

| 상황 | 이전 | 변경 | 판단 |
| --- | --- | --- | --- |
| 여왕 1기 | 배당 28회 | **10회** (9.33회분) | 초반 장기 투자. 9물결부터의 4회 배당은 추가 12G뿐이라 경제만으로는 손해 |
| 여왕 2기 | 14회 | **5회** | 여러 개체를 키울 때 빠르게 회수. 칸 점유와 합성 시 개체 감소를 감수 |
| 신데렐라 1성 재료 | 14회 소모 | **7회 소모** | 빠른 합성 순환 지원. 고정적으로 시간만 지나면 벌리는 돈은 아님 |
| 신데렐라 2성 재료 | 7회 소모 | **4회 소모** (3.5회분) | 고등급 재료는 추가 소환·합성이 필요하므로 공짜 이익으로 계산하지 않음 |
| 머쉬룸킹 1기 | 336초 | **168초** | 전투 12초 수확 14회. 보스 HP 하향으로 전투가 짧아질 가능성을 함께 고려 |
| 머쉬룸킹 2기 | 168초 | **84초** | 여러 칸을 경제에 쓰는 명확한 대가 |

두 번째 이후 강화비는 52/76/100/124G로 커지고, 경제 증가량은 동일하다.
예: 두 번째 여왕 강화는 1기 기준 추가 배당 18회가 필요해 일반 12물결 원정에서 수입만으로는 회수가 어렵다.
이 단계부터는 여러 개체의 공격·경제를 함께 개선할지, 소환·합성·다른 공격 동료에 투자할지의 선택이다.
모든 강화를 순수 경제 기준으로 흑자로 만들지 않았다.

## 타이밍과 성급의 기회비용

- 강화 없는 1성 여왕을 1~12물결 내내 유지하면 5/5/5/6/6/6/7/7/7/8/8/8 = **78G**. 3성은 **126G**. 새 조정에서도 동일하다.
- 1성 머쉬룸킹 1기를 12물결 유지하고 각 물결 전투가 24/36/48초라면 **72/108/144G**. 1단계 강화 시 **120/180/240G**. 이는 고정 전투시간 가정이며 보스 약화 후 실제 시간을 측정한 승률 시뮬레이션이 아니다.
- 같은 1성 여왕 두 기는 첫 세 물결에 합계 10G, 합성한 2성 한 기는 7G. 머쉬룸킹도 두 기 6G/12초 → 합성한 한 기 4G/12초. 합성은 공격 위력 ×2.35와 빈칸을 얻는 대신 수입 개체를 줄인다.
- 여왕 45G 상한에 이미 도달했다면 더 강화해도 배당 한계수입은 **0**이다. 강화창·능력창 모두 합계 상한을 알려야 한다.
- 신데렐라의 25G와 여왕의 30G 필살기 수입은 강화/성급과 무관하며 별빛 60을 소비한다. 위력은 성장하지만 경제 스킬만 연속 사용하는 동안 빙결·약화·보스 처형 기회를 잃는다.
- 보스 체력 20% 하향은 시간 수입을 줄일 수 있으나 물결 배당·합성 환급의 발생 조건은 바꾸지 않는다. 머쉬룸킹의 기본 수확을 무조건 올리지 않고 투자 이후의 추가 수입만 보강한 이유다.

## 강화와 설명의 일치

위력 배율은 1.00 → 1.28 → 1.56 → 1.84 → 2.12 → 2.40이다.
직전 단계 대비 증가율은 **28.00 / 21.88 / 17.95 / 15.22 / 13.21%**로 감소한다.
따라서 '매번 현재 공격력 +28%'로 읽힐 수 있는 표시를 없애고, **1성 기본 위력 현재 → 다음**을 직접 표시한다.
경제/오라/별빛/감속/노출은 별도 행으로 실제 현재→다음 값을 표시한다. 같은 종류의 배치 동료 전원에 적용되며
성급·유물·일시 버프가 비교 표시에 포함되지 않음을 명시한다. 선택한 경제 동료의 상세창은 현재 성급/강화/물결 수입을 따로 보여 준다.

공격 특화의 기본 강화량·공격 주기는 바꾸지 않았다. 지원형은 기존 단계당 오라 +3%p, 명탐정 +2%p,
은토끼 명중 별빛 +0.1, 시간의지배자 감속 +3%p를 유지한다. 기본 위력 증가도 함께 받는다.

## 보스 조정

- 모든 지역·무한 물결 보스 HP를 `round(previousBossHp × 0.8)`로 하향. 일반 적 수·HP·속도·보상·패턴은 유지.
- 달빛 정원 보스 HP: 4물결 **6,776 → 5,421**, 8물결 **21,846 → 17,477**, 12물결 **70,434 → 56,347**.
- 루나: 보스 직접 피해 **×1.35**, 보스 마무리 구간 **35% → 40%**. 일반 적은 35% 유지. 기본 공격/필살기 모두 적용.
- 명탐정: 보스 직접 피해 **×1.25**, 기본 노출 **18% → 보스 30%**(단계당 +2%p). 팀 전체가 보스 약화의 이익을 받는다.
- 둘 다 기본 목표를 보스로 설정하되 사거리를 무시하지 않는다. 보스가 없으면 기존 강점에 맞는 대상을 선택한다. 플레이어가 지정한 목표 우선순위는 저장/복원에서 보존한다.
- 명탐정 필살기 60% 약화는 정확히 10초다. 기본 공격이 이를 4초로 줄이거나 계속 갱신하던 문제를 수정했다. 이 버그 수정으로 장시간 실제 약화량은 단순 상향 비교와 다를 수 있다.
- 기존 VERSION 2 저장도 유지. revision 없는 저장의 진행 중/대기 중 보스만 한 번 축소하며 HP 비율·시전 중 피해 기준을 보존한다. 새 revision을 저장해 중복 감소를 차단한다.
