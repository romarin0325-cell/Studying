# Defense 진행 방식과 기능 의도

[문서 시작점](README.md) · [수치 자료](BALANCE.md) · [동료 능력](CHARACTERS.md)

기준: `7635238`의 `merge/content.js`, `merge/engine.js`, `merge/main.js`. **구현 규칙**은 코드에서 확인한 동작이고, 아래 **기능 의도**는 기존 설계 자료와 실제 동작을 연결한 해석이다.

## 한 원정의 흐름

1. 홈에서 지역을 고르고, 30명 중 서로 다른 동료 6명과 유물 최대 3개를 편성한다. 유물 24개는 처음부터 사용할 수 있다.
2. 5×5 보드에 편성 동료 중 독립 추첨한 1성 세 개체가 놓인다. 체력 20, 골드 45, 별빛 90, 무료 소환 3회로 시작한다. 초기 배치와 무료 소환은 별개다.
3. 적이 보드 외곽 길을 따라 결계로 이동한다. 동료는 사거리와 공격 형태에 맞춰 자동 공격한다. 플레이어는 소환·이동·합성·회수·대상 우선순위·동행 강화·필살기를 선택한다.
4. 같은 동료·같은 성급을 드래그해 합성한다. 루미는 같은 성급의 다른 동료와도 합성하며 상대의 종류를 남긴다. 최대 6성이다. 탭은 정보 확인이고 이동/합성은 드래그로만 실행한다.
5. 대기 적과 생존 적이 모두 없어지면 골드와 별빛을 정산하고, 축복 6종 중 서로 다른 3개를 보여 하나를 고르게 한다. 선택 중에는 전투 시간이 진행되지 않는다.
6. 다음 물결까지 1.4초의 준비 시간이 있다. 4·8·12물결에는 지역별 보스가 등장한다. 결계 체력 0은 패배다.
7. 12물결 후에도 축복을 선택해야 승리한다. 승리 후 끝없는 수호를 선택하면 같은 원정의 13물결부터 이어간다.

모든 소환은 편성 6명 중 각각 1/6 확률의 복원 추출이다. 같은 동료가 연속으로 나오며 합성 쌍이 보장되지 않는다. `bag`은 저장 호환용 필드로 남아 있지만 추첨에 사용하지 않는다.

## 기능별 의도와 선택의 비용

| 기능 | 구현 규칙 | 기능 의도와 플레이 판단 |
| --- | --- | --- |
| 6명 편성 | 출발 후 소환은 이 6명으로 제한 | 공격·제어·지원·경제를 어떤 비율로 가져갈지 먼저 결정 |
| 무작위 소환 | 무료 3회 뒤 10G부터 유료 회차마다 +2G, 상한 없음 | 현재 보드를 살리는 소환과 미래 성장에 쓸 골드를 비교 |
| 합성 | 두 개체를 하나의 높은 성급으로 바꾼다 | 단일 화력을 얻는 대신 공격 자리·오라·경제 개체를 줄이는 선택 |
| 이동·교환 | 빈칸은 이동, 합성 불가 동료는 교환 | 실제 길·사거리·공격 도형·인접 관계에 맞춰 배치 조정 |
| 동행 강화 | 동료 종류별 최대 5단계, 같은 종류의 모든 개체에 적용 | 소환 운에만 의존하지 않는 성장. 경제·지원 주 역할도 강화 |
| 공용 별빛 | 6명의 필살기가 같은 0~100 게이지를 소비 | 지금 제어·폭딜을 쓸지 다음 위기를 위해 남길지 선택 |
| 유물 | 출발 전 최대 3개 | 합성·화상·감속·고립·인접·경제 등 원정의 조합 방향 설정 |
| 축복 | 매 물결 3택1 | 당장 골드/회복, 다음 물결 화력, 원정 전체 성장 사이의 짧은 선택 |
| 경제 동료 | 둠의 재료 환급, 여왕의 정산, 머쉬룸킹의 시간 수확 | 서로 다른 시간 축에서 골드를 얻되 전투 자리의 기회비용 발생 |
| 중립 배치 표시 | 모든 빈칸의 표시는 같다 | 정답 배치를 알려 주기보다 실제 사거리와 오라를 보고 발견 |
| 조작 연습 | 별도 원정 상태에서 실제 소환·드래그·필살기 실행 | 기록·현재 원정에 영향을 주지 않고 입력을 익힘 |
| 효과 줄이기 | 범위·보스 경고는 유지하고 선택적인 움직임/섬광을 줄임 | 정보 전달과 화면 부담을 분리 |

동료 선택의 기준은 원작 강함 순서가 아니라 이 게임 안의 역할이다. 예를 들어 눈토끼의 감속은 아발란체메이드의 추가 피해 조건을 만들고, 자스민의 성광은 체리프린스의 결전 조건을 만든다. 하모니어스는 같은 종류를 여러 개 두는 대신 서로 다른 종류의 인접을 보상한다.

## 진행과 저장의 경계

프로필에는 편성·지역·클리어 기록·설정이 남는다. 동행 강화, 골드, 별빛, 성급, 축복은 이번 원정의 상태다. 장기간 누적하는 영구 전투 능력으로 해석하지 않는다.

진행 상태는 `astra.confluence.run.v1`, 프로필은 `astra.confluence.profile.v1`에 저장한다. 현재 실행 스키마는 VERSION 2이고 밸런스 revision은 3이다. VERSION 1 원정은 현재 규칙으로 추정 변환하지 않으며, VERSION 2의 이전 revision은 엔진의 명시적 복원 경로를 거친다. 창이 비활성화되면 저장·정지하고, 저장이 제한되면 안내와 메모리 실행을 제공한다.

## 변경 결과를 판단할 때

소환 운, 25칸 한도, 인접 지원, 성급 성장, 준비시간과 이동 중 표적을 함께 봐야 한다. 기본 공격력만으로 순위를 정하면 제어·경제·지원의 가치를 놓친다. 수치 변경 시 [BALANCE.md](BALANCE.md)의 비교 조건과 해당 기능의 수정 위치를 사용한다.
