# 천상의 세 시련 — 제작·검증 기록

## 작업 계약

사용자 요청: 최신 Git 반영 후 보스 3종(뇌신 토르·창조신 아스테아·투신 아레스), 지역 추가, 유물 4종, 동료 6종(둠·산타·자스민·별똥별소년·시간의마술사·체리프린스), 트라우마 변신, 경제 역할 이전, 더 빠르고 재미있는 진행, 준비 상태 PR.

사용자는 아스트라6 max 추론으로 직접 작업하고 다른 모델로 라우팅하지 말 것을 요청했다. 이 문구는 사용자 작업 조건의 기록이며 실행 모델을 독립적으로 인증한다는 뜻은 아니다. 작업·검토를 다른 에이전트로 위임하지 않는다. 이미지 제작은 기존과 같은 내장 이미지 도구를 사용한다.

2026-10-01 확인: 'SD 4종'을 한도로 해석하지 않고 **필요한 신규·변신·보스 에셋 모두 제작**하도록 사용자 답변을 받았다. 동료 6명+트라우마 7개 4방향 시트, 보스 3종, 신규 래스터 타격·필살기·유물·지역 그림을 포함한다.

기준 Git: `origin/main`의 `1c5e3c8`에서 시작. 최종 PR 전 다시 최신 상태를 확인한다. 기존 effects.webp의 캐릭터별 에셋 표현을 유지한다. 이전에 거절된 일반 공격 범위 윤곽선/잔상 실험을 재도입하지 않는다.

## 플레이 역할

| 동료 | 기본 공격·선택의 이유 | 필살기 |
| --- | --- | --- |
| 둠 | 가는 그림자 관통검, 합성 재료가 되면 등급·훈련에 비례한 환급 | 암거래: 적들을 타격하고 즉시 금화 수익 |
| 산타 | 선물 포격, 네 번째 타격은 가까운 동료의 공격 대기를 앞당김 | 성야의 선물: 동료 1명 2성 합류 및 공격 가속 |
| 자스민 | 성광 누적. 3중첩 대상에 강한 빛 폭발 | 여신강림: 적의 빛 중첩을 완성하고 성역 강화 |
| 별똥별소년 | 빠른 유성탄, 연속 명중으로 강적 압박 | 최대 체력이 가장 높은 생존 적 **한 명**을 고정하고 유성 낙하 |
| 시간의마술사 | 관통 시곗바늘, 주기적으로 인접 동료의 공격 대기 단축 | 트라우마로 실제 시트·능력 변경, 일정 시간 강화된 방어 무시 관통 |
| 체리프린스 | 붉은 검광, 화상 대상과 단일 강적에 강함 | 최대 체력이 가장 높은 생존 적 **한 명**을 고정하고 왕자의 일격 |

신데렐라는 합성 환급·필살기 금화 효과를 모두 잃고 기본 피해/공격 주기 및 순수 공격 필살기를 강화한다. 기존 신데렐라 그림과 성별(남성)은 유지한다.

단일 표적 필살기는 적의 **현재 HP가 아닌 maxHp**로 정한다. 시전 시 UID를 고정하고, 준비-비행-명중 연출과 피해 타이밍을 같은 데이터로 구동한다. 도중 표적이 죽으면 다른 적을 몰래 공격하지 않고 해당 위치에서 소멸한다. 준비/표적/비행체/명중은 새 래스터 에셋을 사용한다. 일반 SVG 기하 도형을 필살기 에셋으로 대체하지 않는다.

## 제작 기준

- 공통 구조는 `HEAD_PROFILE.json`, 화풍은 기존 고정 시트, 정체성은 `Downloads/캐릭터` 원본과 `컨셉.txt`를 참조한다. 최근 생성물을 다음 생성의 스타일 기준으로 연쇄 사용하지 않는다.
- 머리는 두개부와 얼굴이다. 귀·모자·후광·무기·머리카락 부피를 포함하지 않는다. 수동 좌표는 추정임을 표시한다.
- 4방향에 하나의 축척과 발 기준선을 적용한다. 그림 외곽으로 자동 fit하지 않으며 잘리는 소품은 생성본에서 수정한다.
- 실제 알파, 불투명한 흰 재료, 중립 자세, 같은 손, 원본 의상·성별, 작은 화면에서 얼굴 인지를 검사한다.
- 신규 필살기는 표적 주변에 대비를 집중하고 보드 전체의 흰 섬광·면 채움은 사용하지 않는다. 간소화 모드에서도 표적과 명중 시점을 유지한다.
- 전처리·압축은 빌드 전에 수행하고 런타임은 패킹된 WebP를 읽는다. source/output SHA, 프롬프트, 채택/교정 사유를 기록한다.

## 플레이 변화와 검증된 수치

초기 별빛 75→90, 첫 적 진입 대기 1.5→0.65초, 첫 물결 적 간격 1.4→1.05초, 기본 적 체력 88→76, 이동 속도 +10%, 축복 선택 뒤 휴식 2.5→1.4초, 물결 기본 수입 20→24G로 조정했다. 후반 성장률 1.34와 보스 체력 계수는 유지했다. 새 지역 체력 배율은 2.35/2.70/3.05이며 이전 지역의 2.05 뒤에 이어진다.

비교는 원래 기본 편성, 같은 여섯 seed, 같은 0.5초 행동 정책으로 수행했다. 수치는 **게임 시간 중앙값**이며 보상 읽기·판단 시간은 0이다.

| 달빛 정원 / 기본 편성 | 이전 | 변경 |
| --- | --- | --- |
| 첫 타격 | 1.8초 | 0.9초 |
| 첫 처치 | 3.4초 | 2.4초 |
| 첫 물결 보상 | 14.8초 | 11.8초 |
| 첫 보스 등장 | 63.0초 | 46.6초 |

신규 6명 편성은 정원에서 6/6 클리어, 중앙 315.4초였다. 유물 없는 신규 6명만으로 후반 세 지역은 2/6, 0/6, 0/6이었으며, 지크·눈토끼·루미·자스민·별똥별소년·둠 혼합 편성은 6/6, 6/6, 6/6이었다. 따라서 신규 인원 자체가 기존 편성을 대체하는 상위 호환은 아니다. 제어·광역·경제를 섞는 편성이 후반에 유리하다는 관찰이며, 소수 seed/한 정책의 결과를 일반 승률로 부르지 않는다. 원자료와 정책: [pacing.json](../docs/art/expansion/review/pacing.json), `tools/simulate-celestial.mjs`.

진입 학습의 근거로 [George Fan의 GDC 2012 발표 슬라이드](https://media.gdcvault.com/gdc2012/slides/Design%20Track/Fan_George_How%20I%20Got.pdf)의 직접 해보게 하기, 한 번에 설명을 쏟지 않기, 행동을 보고 기능을 이해하게 하기 원칙을 참고했다. 여기의 게임별 수치와 승률은 해당 발표에서 가져온 것이 아니라 이 게임의 측정·조정 결과다. 기존 탭/드래그 연습과 랜덤 소환을 유지하면서 첫 보상/첫 필살기 접근 시간을 줄였다.

## 추가 시스템의 정확한 계약

- 첫막의 종: 매 물결 첫 7초, 공속 +45%. 다음 물결에 다시 활성화한다.
- 왕자의 인장: 살아 있는 적 중 최대 체력 1위 **한 명**에게 +25% 피해. 동률이면 먼저 생성된 UID 하나다.
- 선물 리본: 유료 소환 매 4번째는 2성. 초기/무료/산타 필살기는 유료 횟수에 포함하지 않는다.
- 깨진 회중시계: 아군 필살기의 지속 강화/변신 +2초. 적에게 거는 기절/감속을 늘리지 않는다.
- 토르: 현재 동료가 있는 칸을 우선한 3칸 예고 → 그 칸의 동료를 1.8초 봉인하고 1명당 별빛 5 감소. 이동으로 회피한다.
- 아레스: 2.6초 준비 중 최대 HP 6%를 깎으면 저지/2초 기절. 실패하면 5초간 이동 +40%, 일반 피해 25% 감소. 방어 무시는 감소를 무시한다.
- 아스테아: 같은 저지 조건. 실패하면 최대 HP 12% 보호막과 6% HP의 소환체 2명을 만든다. 보호막에 준 피해도 다음 준비 저지량에 포함한다.
- 트라우마: 모든 배치된 시간의마술사가 10초(유물 12초) 변신한다. 그동안 새로 소환/합성한 같은 캐릭터도 해당 전장 버프를 공유한다. 공격 위력 +110%, 공속 +35%, 일반 공격 방어 무시. 버프가 끝나도 이미 발사된 변신 공격은 발사 때의 형태/위력을 유지한다.
- 왕자의 일격/유성: 시전 시 최고 maxHp 생존 적의 UID를 고정한다. 같은 값은 먼저 생성된 UID를 택한다. 1.05/1.2 **게임 초** 뒤 34/32배 단일 피해를 준다. 왕자의 일격은 방어 무시이며 명중 시 화상/성광 3중첩이면 +40%. 대상이 죽거나 이탈하면 소멸하고 다른 적에 재지정하지 않는다. 시전 컷인의 기존 짧은 시간 연출 때문에 일반 모드의 실제 벽시계 시간은 조금 길 수 있다.
