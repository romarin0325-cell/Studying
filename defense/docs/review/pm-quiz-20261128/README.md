## 작업 분담

- GPT 6.2 Sol(high) 4개 작업이 197문항을 50개씩 작성(`brief.md`, `report-1~4.txt`). Claude가 197문항 전체를 읽고 계산 문항을 모두 다시 풀었다.
- **GPT 일본어 평가 (소유자 요청)**: IPA 시험 문체(「〜し，〜する。」 병렬, 명사 종결 보기, 「適切なものはどれか」)를 일관되게 지켰고, 실무 어휘(付議する·洗い出す·見極める·善良な管理者の注意をもって事務を処理する)와 법률 표현도 정확했다. 직역 투나 어색한 조사는 찾지 못했다. 고친 것은 표기 2종(作業パッケージ→ワークパッケージ, 仕掛作業→仕掛かり作業)뿐. 약점은 문체가 아니라 출제 감각이었다(T057-q2처럼 문제문이 답을 흘림, 정답 위치를 지키느라 숫자 보기 순서를 섞음).
