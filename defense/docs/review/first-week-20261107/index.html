첫 세션: 대현자 루미의 튜토리얼

어두운 화면에 실제 버튼 하나만 열리고 루미가 한 줄로 말한다. 전투는 안내 동안 기다린다(효과·소리는 계속). 출격 → 소환 → 합성(끌기 안내) → 필살기 → 자동 → 첫 승리 → 첫 만남 10회 → 자동 편성 → 새싹 일주일.

순차 해금

처음 로비에는 출격·새싹·임무와 파트너만. 정원은 하단 메뉴에 자물쇠만 남기고(칸 유지), 열리면 루미가 소식을 한 번 전한다.

새싹 일주일

접속한 날마다 한 칸(누적). 2일차 꿈의결정 2,000, 7일차 UR 직접 선택. 그날의 할 일은 그날 기능을 한 번 써 보게 한다.

격주 이벤트(서약 ↔ 쌍성)

모험 탭 4칸, 이벤트는 맨 뒤 고정 자리. 선택한 드래프트 글자가 잘리던 문제를 함께 고쳤다. 새 시즌에는 로비에서 팝업 한 번.

유물 10회 퀴즈

맞히면 UR 2배는 없고 10% 확률로 행운의 보너스 10회.
