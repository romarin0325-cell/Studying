## 비교 도구

저장소 루트에서 실행한다.

```text
node defense/scripts/review-vfx-pilot.mjs
```

생성된 `defense/test-results/vfx-pilot/index.html`을 브라우저에서 연다. 한 파일에 필요한 게임 그림과 렌더러를 담는다. `--out`으로 출력 위치를 지정할 수 있다. 기존판은 `dd18202`에 있는 렌더러와 효과음 코드를 사용한다. 해당 Git 개체가 로컬에 있어야 한다. 같은 전투 규칙을 공유하는 기준을 비교할 때는 `--baseline <ref>`를 쓴다.

동료·장면을 고르면 주요 타격이나 지원 시작 장면에서 열린다. **처음부터**는 전체 장면을 재생하고, 주요 순간 버튼이나 프레임 이동으로 같은 시점을 맞출 수 있다. 휴대폰에서는 **기존 / 개선 / 나란히**로 표시 방식을 바꾼다. **비교 설정**에 판정 안내, 컷인, 연출 줄이기, 전투 배속, 효과음이 있다. 판정 안내의 점선은 실제 범위, 점은 실제 명중점, 발치 고리는 현재 가속 수혜자를 뜻한다.

두 화면은 하나의 전투 엔진이 만든 상태와 이벤트를 공유한다. 준비된 배치와 상태에서 실제 피해·이동·소환·지원이 계산된다. 잠금 이후 상태 변경 장면은 고정된 시험 조건을 주입한다. 두 화면은 같은 전투 배속과 컷인 슬로모션을 적용한다. 누적 피해·처치·별빛 표시는 두 화면의 공통 전투 기록이다.

## 관련 검증

```text
node --test defense/tests/vfx-pilot.test.mjs
```

잠금과 취소, 타격 시의 강화, 실제 반경·명중 목록, 가속 적용과 강한 효과 우선을 확인한다. 390×844 확인에서는 위험 예고·적 HP·프레임 조작과 설정을 본다. 휴대폰 프레임 시간과 음향의 체감은 기기에서 별도로 확인한다.
