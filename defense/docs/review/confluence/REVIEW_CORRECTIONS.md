# PR #546 후속 검수 수정

## Before 좌표

`build_defense_head_review.mjs`의 이전 계산은 현재 두상 좌표에 과거 발 위치와 배율을 적용했다. 이제 이전 스냅샷의 두상·발·배율·기준점만 사용한다. 두상 기록이 없는 초기 스냅샷은 이전 이미지에 직접 표시해 보관했던 추정 좌표와 해당 이미지 SHA-256을 별도 입력으로 요구한다. 기록 누락이나 이미지 해시 불일치 시 실패한다. 현재 이미지의 좌표를 조용히 차용하지 않는다.

이번 초기 스냅샷과 이전 수동 주석을 대조한 최대 좌표 차이는 0.033px였다. 이 특정 그림의 결론이 크게 달라지지는 않았지만, 일반적으로 서로 다른 두상 좌표를 혼합하는 계산은 잘못됐다. 비교 PNG·HTML·측정 JSON을 다시 생성했다. 원본에 두상 기록이 없는 경우의 주석 출처도 명시했다.

## 숨 쉬는 씨앗

기존 설명은 독 부여 전반을 뜻했지만 추가 중첩이 일반 공격에만 적용됐다. 일반 공격·합성·필살기의 각 독 부여에 +1을 적용하도록 공통 처리로 바꾸고, 설명에도 세 경로를 명시했다. 기존 일반 공격의 40중첩 상한과 경로별 지속시간은 유지했다. 독의 시간 경과 피해에는 새 중첩을 추가하지 않는다.

회귀 테스트는 씨앗 보유/미보유 각각에서 실제 일반 공격 투사체 적중, 일반 공격 상한, 기존 독이 있는 적에 대한 합성, 필살기 적용을 확인한다. 비교 도구는 과거 좌표 변환, 해시가 연결된 초기 스냅샷 주석, 누락·잘못된 기록의 거부를 검사한다.

## 전처리와 통합 배포본

21명의 선택된 원본 PNG 합계는 37,646,958 bytes, 출시용 WebP 아틀라스 합계는 3,867,678 bytes다. 파일 용량 기준 약 89.7% 줄었다. 캐릭터는 오프라인 배경 처리·방향 분리·기준점 정렬·크기 조정 후 1024×1024 WebP 아틀라스로 저장한다. WebP 설정은 quality 95, alphaQuality 100이다. 게임 실행 중 배경 제거·재인코딩은 하지 않는다.

출시 이미지 24개 합계는 5,007,782 bytes다. 통합 HTML은 이 이미지들을 Base64로 내장하며 압축된 코드·스타일과 글꼴 데이터도 포함한다. Base64 표현은 원래 이미지 바이트보다 약 1/3 커지므로 이미지 파일 합계와 HTML 용량은 다르다. `prepare:defense-art`는 이미 전처리된 파일의 해시·투명도를 검사하고 검사 결과를 재사용하는 단계이며, 재압축 명령이 아니다.
