## 아트

사용자가 지적한 밤토끼·루미·머쉬룸킹과 지크·번개의 현자의 머리 크기 차이를 기준으로 21명을 다시 비교했다. 귀·모자·뿔·헤어스타일의 부피를 제외한 두개부 추정 좌표에서 공통 배율을 계산했다. 얼굴 그림을 비균등하게 찌그러뜨리지 않았고, 성급·키 등급에 따른 별도의 머리 확대는 없다. 네 방향은 같은 배율을 공유한다.

두개부 좌표는 가려진 정수리와 턱을 복원한 수동 추정이다. 측정 정답 또는 사용자의 최종 비율 승인으로 취급하지 않는다. 특히 머쉬룸킹의 높은 옷깃은 턱선을 가린다. 기존 신체 길이는 서로 다르며 머리 정규화가 몸 길이 교정까지 의미하지는 않는다. [절차와 출처](../../art/HEAD_CONSISTENCY_RESEARCH.md)를 참고한다.

추가 확대 검수에서 루미·세이렌·에인션트드래곤의 중간 분리선이 아래 방향 그림의 일부를 위 방향에 남기는 것을 발견했다. 원본의 알파가 비는 행에서 경계를 다시 잡고, 아래쪽 발 좌표를 같은 만큼 옮겨 본체 크기·위치를 보존했다. 삭제나 자동 축소로 해결하지 않았다.

## 실제 UI 플레이 관찰

390×844 화면에서 초기 지크 합성, 상점의 확정 동료 구매, 스킬 사용, 저장 후 재개, 보스 유물 선택, 동행 강화를 실제 입력으로 확인했다. 전투를 방치한 구간에서는 내구도가 줄었으며, 이 플레이는 숙련 사용자 밸런스 실험이 아니다.

후반에는 2성 루미를 상점에서 구매했다. 기존 1성 루미와 1성 지크로 2성 지크를 만들고, 구매한 2성 루미로 3성 지크를 만든 다음 기존 3성 지크와 합쳐 4성으로 올렸다. 지크의 동행 강화를 3단계까지 구매하고 마지막 물결에서 스킬을 사용했다. 상태 주입이나 자원 추가 없이 12번째 물결 종료 화면을 확인했다.

관찰한 결과는 내구도 11, 처치 301, 합성 5회, 필살기 3회다. 이는 첫 지역 한 차례의 기능·진행 확인이며 장기간의 재미, 전체 편성 균형, 모든 지역 클리어를 보증하지 않는다.

## 기술 검증 범위

- 현재 루트 검증: 선택 규칙 fixture. Card·Shooter의 런타임 묶음은 실행하지 않음.
- 현재 전용 Defense 검증: 변경된 11개 테스트, 문법·콘텐츠·출시 이미지 검사, 대표 세로 화면, 25명 배치, 단일 HTML 생성과 네트워크 자원 요청 차단 상태의 합성·스킬·저장·재개.
- 현 작업 중 별도로 확인한 경험 흐름: 21인 편성, 실제 UI 합성·스킬·상점·설정.
- 현 작업 중 별도로 확인한 복원력: Chromium·WebKit의 이미지 실패/무응답, 저장 차단, 일부 구형 API 부재. 무응답 이미지는 요청을 계속 막아 둔 채 대체 이미지·DOM·배치 상태를 기록하며 스크린샷으로 결과를 주장하지 않음.
- 새 최소 검증 정책을 반영하기 전, 보존된 이전 엔진 테스트를 포함한 164개 테스트도 통과했다. 이 수치를 새 게임의 164개 독립 테스트로 표현하지 않음.

25명과 높은 체력의 적 18개를 둔 렌더링 부하 fixture에서는 약 60 FPS, 프레임 p95 약 16.8ms를 관찰했다. 이 fixture는 자원과 체력을 주입한 자동 테스트이며 위 실제 플레이와 다르다. 실제 Android/iOS, 발열·메모리, `file://` 직접 실행은 검증하지 않았다.
