# 18차 검수 캡처 (2026-10-26)

Chromium, 390×844 오프라인 단일 HTML. 이펙트 전후 비교는 [pass18-vfx 재생기](../pass18-vfx/index.html)(같은 엔진 이벤트, 이전 main 렌더러와 이번 렌더러), 화면은 `scripts/review-pass18-ui.mjs`, 이펙트 정지 화면은 `scripts/capture-pass18-vfx.mjs`로 다시 만든다.

- 화면: Bright 전투(자동 ON 알약), 두 테마의 일시정지(원정 포기 줄), 신규 동료 공지(등급순), 새벽의 별길 개방, NEW 연출(얼굴 중심 정렬·Bright 이름띠), 서재.
- 이펙트: 지크 회전 베기, 베히모스 평타, 마왕 평타·데스핸드(밤·Bright), 코쿤 비단 고리, 미라클윙·어비스윙 명중, 기적의우화, 별바다의 궤도 장판.
- `ui-contrast-report.json`: 글자색과 실제 바탕 픽셀의 대비가 3:1 미만인 요소. 남은 항목은 시트 뒤에 흐리게 깔린 배경 화면이거나 하단 탭 아래로 스크롤된 줄이다. 흰 글자의 주 버튼(아쿠아)은 승인된 Bright 디자인이라 바꾸지 않았다.
- 확인하지 않은 것: 실기기 FPS, iOS Safari, 여러 동료가 동시에 공격하는 장면, 메모리얼 8편의 감상 화면.
