# 메인 스테이지 구조 (2026-11-16)

코드: `src/content.js`(`PARTS`, `CHAPTERS`, `levelHp`, `levelOf`, `levelStage`), 세이브 변환 `src/profile.js`의 `migrateStages`.
측정 도구: `scripts/progression-sim.mjs`(신규 플레이어 진행), `scripts/stage-sim.mjs`, `scripts/requested-stage-sim.mjs`.

## 1. 구조

| 부 | 장 | 스테이지 |
|---|---|---|
| 제1부 달빛의 별길 | 1장 별빛 산책(입문) · 2장 달빛 정원 · 3장 별무리 숲 · 4장 은하 사원 · 5장 시간의 탑 · 6장 창조의 끝 | 1–54 |
| 제2부 새벽의 별길 | 7장 새벽 정원 · 8장 이슬 숲 · 9장 노을 사원 · 10장 되감긴 탑 · 11장 창조의 시작 · 12장 첫 햇살의 언덕 | 55–108 |

- 한 장은 9스테이지이고, 아홉 보스를 한 바퀴 돈다(스테이지 n의 보스는 `BOSS_ORDER[(n-1)%9]`).
- 스테이지를 늘리려면 `PARTS`의 마지막 부에 장 이름 하나를 더한다(9스테이지). 새 부를 더하면 그 부는 앞 부를 다 깨야 열린다. 스테이지 수, 부·장 탭, 진행 막대, 잠금 표시, 2부 개방 문구, 테스트 빌드의 전부 클리어는 이 목록에서 계산된다.
- 45스테이지마다 오던 "새 부" 경험은 그대로다. 1부 마지막 스테이지(54)를 처음 깨면 새벽의 별길, 새벽 온실, 신규 동료가 함께 열린다(`PART_STAGES`, `LATE_UNLOCK_STAGE`).
- 새 부에는 새벽 배경 같은 그림이 따로 필요하다. 지금 렌더러는 2부 이상을 모두 새벽으로 그린다.

## 2. 레벨: 입문 장이 들어와도 기존 설계가 그대로 남는 방법

입문 장(1–9)을 앞에 넣었으므로 기존 스테이지 n은 이제 n+9다. 기존 수치는 모두 "기존 스테이지 번호"로 설계됐으므로 그 번호를 **레벨**로 부른다: `levelOf(stage)=stage-9`(입문 장은 0), `levelStage(level)=level+9`.

| 무엇 | 기준 | 지금 값 |
|---|---|---|
| 기능 해금(정원·도전·서재·유물·부탁) | 스테이지(첫 세션 속도) | 2·3·4·5·6 그대로. 파견 소식 9 추가 |
| 파견 슬롯 | 스테이지 | 9·18·27·36 그대로 |
| 어려움·심연 도전 | 레벨 36·72 | 스테이지 45·81 |
| 샘·씨앗 화단, 별가루 화단 | 레벨 15·30·60 | 스테이지 24·39·69 |
| 새벽 온실 치명타 화단 | 1부 끝 | 스테이지 54 |
| 쌍성 원정 길 | 레벨 42·70·90 | 스테이지 51·79·99 |
| 도전 웨이브 체력(`TIERS.from/to`) | 레벨 | 숫자 그대로 |
| 첫 클리어 꿈의결정, 클리어 별가루, 별똥별, 파견 보상의 스테이지 가산 | 레벨 | 입문 장은 레벨 0 값(첫 클리어 160, 별가루 40) |
| 새싹 일주일 6·7일째 과제 | 레벨 9·12 | 스테이지 18·21 클리어 |

입문 장 보상은 레벨 0 값이라 후반 경제는 이전과 같다. 입문 장 9개가 더 주는 것은 첫 클리어 1,440·퍼펙트 최대 900 꿈의결정과 별가루 360이다.

## 4. 측정: 신규 플레이어 첫 세션 (`progression-sim.mjs`, 8명, 스테이지당 3회까지)

플레이어 모델: 첫 만남 10회, 1,000마다 10회 소환, 매일 무료 소환(동료·유물), 중복 강화, 자동 편성·자동 장착, 별가루는 가장 싼 화단에, 새싹 일주일 1일째 보상. 1일째 한 자리에서 계속 진행한다.

| | 이전 (기존 1–18) | 지금 (새 자동 편성 포함) |
|---|---|---|
| 기본 오토(자리 이동 없음) | 기존 9 도달 3/8, 5–9에서 막힘 | 1–17 첫 시도 100%, 18 첫 시도 88%, 21까지 8/8 (전투 약 60분). 첫 벽은 27(레벨 18 아스테아, 첫 시도 0%) |
| 합리 오토(자리 이동) | 기존 9 도달 5/8, 13–15에서 막힘 | 1–21 첫 시도 100% (전투 약 55분). 22·26·27에서 첫 시도 50% 안팎 |

- 입문 장 1–9는 두 모델 모두 첫 시도 100%이고 전투 약 18분이다.
- 같은 곡선에서 자동 편성을 바꾸기 전에는 기본 오토가 18에서 첫 시도 50%, 벽이 21–23이었다. 바뀐 자동 편성(FIRST_WEEK.md)이 첫 세션을 더 늘렸다.
- 더 빨리 벽을 두고 싶으면 `content.js`의 `EASE`(휘는 정도, 지금 1.7)를 낮추거나 `EASE_JOIN`(직선과 만나는 레벨, 지금 18)을 앞당긴다.
- 후반: `requested-stage-sim`(2026-10-28 기록과 같은 육성 조건)으로 스테이지 91(기존 82)이 24/40(60%), 기록의 59.5%와 같다. 새로 생긴 100–108은 같은 기울기를 9단계 더 잇는다(103: 16/40, 99·108의 아스테아: 0/40, 기존 90과 같은 성격의 벽).
