# 밸런스 랩

`dist/StarGardenBalanceLab.html`을 직접 열거나 `npm run serve:defense` 후 http://127.0.0.1:4178/balance 로 접속한다. `npm run build:defense:lab`은 랩만, `npm run build:defense`는 게임 두 테마와 랩을 함께 빌드한다.

일반 공격·필살기·디버프·실제 모션·확정 패치 내역을 비교한다. 공격 형태·필살기 유형·등급·효과·이름으로 필터링하고 성급·훈련·표적 수·외부 상태를 조정한다. 기본 공격력과 현재 공격력을 구분하며, 필살기는 통상/조건 피해·순증 피해·별빛 100당 순증으로 정렬한다. 개별 공격력 배율·공격 주기·소모량 초안은 별도 저장하고 JSON으로 교환한다.

## 현재 엔진과 확정 패치

[2026-10-27 확정 패치](archive/2026-10-27-BALANCE_FINAL.md)를 게임에 반영했다. 랩은 `src/lab/model.js`에서 같은 실제 엔진을 사용한다. 이전 제안의 언더독 ×1.15, 라바 ×0.8, 코쿤 ×0.4, 애쉬 18→20배 보정, 메이드 추가 소모 감소, 산타 타이머 제한은 제거했다. 확정 숫자를 다시 곱하거나 빼지 않는다. ‘패치 내역’은 현재 코드의 상수를 읽는다.

현재 아마겟돈은 공격력 22배, 큐어마스터 공격력은 21이고 필살기는 퍼스트키스다. 조커 색상에서 다섯 색과 카오스를 선택한다. 카오스 일반 공격은 기존 수치의 상태 5종을 부여하고 필살기는 별빛 100·전체 공격력 3배다. 대표 조건은 조커를 카오스로, 토피애플을 사과 접근으로 설정한다. 프리즘 조건은 실제 1레벨 유물을 장착해 후속 타격 +90%를 비교한다.

## 측정 조건

기본은 1기, 상단 중앙 칸, 간격 24의 정지 표적, 시드 20261026, 치명타 없음, 20초다. 0.05초 간격으로 진행하고 화상·독·장판·후속 공격은 실제 발생분만 센다. 외부 독은 현재 동료 공격력·20중첩·잔여 12초의 기준 출처다. 기본 환경은 웨이브 2·등장 다음 웨이브, 햇빛 0, 골드 200, 유성 별빛 120이다.

일반 공격을 멈춘 별도 측정에서 필살기 1회의 직격·지연타·지속 피해를 합산한다. 일반 공격 증폭이나 거울 축적은 이 수치에 포함하지 않고, 일반 공격을 유지한 전투와 미시전 전투의 차이를 순증으로 표시한다. 별빛 100당 순증은 순증÷소모량×100이다. 소모량 초안은 효율의 분모에만 적용한다. 실제 시전은 엔진의 소모량, 별똥별소년 전량 사용, 카오스 비용을 따른다.

위치·편성 조건은 실제 보조 동료를 배치한다. 보조 동료는 자체 일반 공격을 멈추고 오라·편성·강제 추가 공격만 참여한다. 아우로라 2기 전체 DPS로 개인 DPS를 부풀리지 않는다. 지크의 접근은 공격력 +40%, 코어 체력 50% 미만은 필살기 2배로 독립이다. 웨이브·토끼 종류·번개 연결·인접 오라·조화·가짜 신데렐라·마술사 인접·골드도 선택한다.

‘사과 접근’은 설치 후 표적 무리를 첫 사과의 접촉 적과 함께 옮겨 실제 폭발을 재현한다. 폭발은 반경 200 안의 적에게 폭발 순간 최고 성급 토피애플의 현재 공격력 18배를 준다. 무작위 위치까지의 실전 대기 시간은 나타내지 않는다. 접근을 끄면 고정 표적에서는 사과가 기다려 피해가 0일 수 있다. 폭풍의현자는 즉사 제외를 위해 보스 표적으로 측정한다. 제어·보호·소환·경제·합성의 팀 가치를 단독 피해 순위로 환산하지 않는다.
