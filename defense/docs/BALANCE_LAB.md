# 밸런스 랩

`dist/StarGardenBalanceLab.html`을 직접 열거나 개발 서버의 `/balance`로 접속한다. `node defense/scripts/build-lab.mjs`는 랩만 빌드한다.

일반 공격·필살기·디버프·모션을 비교한다. 목록은 `HEROES` 전체와 미라클 변신 형태를 사용한다. 공격 형태·필살기 유형·등급·효과·이름으로 걸러 보고, 상세를 펼쳐 특성·필살기·전투력과 조정안을 확인한다. 전투력은 해당 동료의 강화와 장미 화단을 게임의 `combatPower`로 계산하며, 변신 형태는 원래 동료의 전투력이다.

## 측정 조건

기본은 1성 동료 1기, 정지 표적 5기, 웨이브 2, 20초와 고정 시드다. 게임의 `battleMeta`, `critStats`, 전투 엔진을 사용한다. 강화·장미 화단·새벽 정원의 치명 확률과 치명 피해 화단을 조정할 수 있다. 새벽 화단은 개방된 상태로 계산한다. 치명타는 기본으로 꺼 둔다(동료마다 주사위 운이 달라 같은 조건 비교가 흐려진다). `치명타`를 켜면 게임과 같은 기본 5%·150%와 화단 수치로 굴린다. 켠 상태의 유한 시간 결과는 기대 DPS가 아니다.

훈련·성급·표적 수·상태와 위치·편성을 선택한다. 보조 동료는 자체 일반 공격을 멈추고 오라·편성·강제 추가 공격에만 참여한다. 프리즘은 실제 1레벨 유물이다. 다른 유물, 유물 수집 공격력, 축복과 맹세는 이 실험에 적용하지 않는다. 난이도는 메인 전투 기본값이며, 별도 고정 표적을 사용하므로 도전 난이도의 실제 적 구성과 체력을 재현하지 않는다.

엔진을 0.05초 간격으로 진행하고 화상·독·장판·후속 공격은 실제 발생분만 센다. 외부 독은 동료 공격력을 사용하는 20중첩·12초의 실험 조건이다. 일반 공격을 멈춘 별도 측정에서 필살기 1회의 직격·지연타·지속 피해를 합산한다. 평타 증폭과 거울 축적은 이 값에 포함하지 않는다. 순증은 같은 시간의 시전 전투와 미시전 전투의 총 피해 차이다. 별빛 100당 순증은 순증을 소모량으로 나눠 계산한다. 조정안의 소모량은 효율 분모에만 적용되며 실제 시전 비용은 바뀌지 않는다.

사과 접근은 설치 후 표적 무리를 사과 접촉 위치로 옮긴다. 무작위 위치까지의 실전 대기 시간은 측정하지 않는다. 폭풍의현자는 즉사를 제외하기 위해 보스 표적으로 측정한다. 제어·보호·소환·경제·합성의 팀 가치를 피해 순위로 환산하지 않는다. 조정안은 별도 로컬 저장소에만 저장한다.

모션은 게임의 전투 렌더러와 효과 모듈, 필살기 컷인 스타일 및 원화를 사용한다. 실험용 정지 표적과 단일 배치는 실제 전투의 모든 상황을 재현하지 않는다.

2026-10-27 확정 패치는 [보관 문서](archive/2026-10-27-BALANCE_FINAL.md)이며 현재 수치의 기준표가 아니다. 현재 특성과 필살기 문구 및 미리보기 수치는 게임 데이터와 엔진을 따른다.
