# 밸런스 랩

`dist/StarGardenBalanceLab.html`을 브라우저로 직접 열거나 `npm run serve:defense` 후 http://127.0.0.1:4178/balance 로 접속합니다. `npm run build:defense:lab`은 랩만, `npm run build:defense`는 게임 두 테마와 랩을 빌드합니다.

일반공격, 필살기, 디버프 공급원, 실제 모션 재생, 제안 패치 비교 화면이 있습니다. 모든 화면은 기본공격력을 표시합니다. 공격 형태·필살기 유형·등급·효과·이름으로 거르고 성급·훈련·표적 수·외부 상태를 조정합니다. 필살기 표에는 통상/조건 필살기 피해·순증 피해가 있으며, 정렬 선택과 열 제목 클릭으로 각각 정렬합니다. 각 동료의 펼침 영역에서 공격력 배율·공격 주기·소모량 초안을 저장하고 JSON으로 교환할 수 있습니다. 게임 데이터와 플레이 세이브는 바꾸지 않습니다.

실측은 `src/lab/model.js`에서 실제 엔진을 사용합니다. 1기, 상단 중앙 칸, 간격 24의 정지 표적, 시드 20261026, 치명타 없음, 기본 20초입니다. 화상·독·장판·후속 공격은 실제 발생분만 셉니다. 필살기는 한 번 사용한 총 피해에서 미사용 총 피해를 뺀 순증과 별빛 100당 순증으로 비교합니다. 자동 평타를 중단한 별도 시전으로 지연타·지속 피해까지 포함한 필살기 피해를 측정하고, 평타 증폭·거울 축적은 실제 전투 순증으로 구분합니다. 외부 독은 현재 동료 위력·20중첩·잔여 12초의 기준 출처입니다. 화면의 계산 설명에 조건·고정 표적 한계·즉사 제외를 명시했습니다.

패치 수치 시나리오는 언더독 ×1.15, 라바 ×0.8, 코쿤 ×0.4, 애쉬 필살기 18→20, 메이드 소모 85→80, 산타 공속 지속 8→6초를 포함합니다. 애쉬는 실제 직격 결과에 20/18 보정을 적용하고 메이드 소모 변경은 효율의 분모만 바꿉니다. 프리즘은 유물의 연쇄 +70%인지 아우로라 반사 75%인지 모호해 별도로 설명합니다. 조커의 신규 배율과 수집·초기화 규칙, 자체 무적 방식, 파도의 소라 판정은 미정이므로 임의 수치로 구현하지 않았습니다.

예상: 코쿤 −60%는 우화 전 화력 손실이 크므로 우화 대기 구간을 주의해서 봐야 합니다. 언더독은 노멀 덱 특성과 곱해져 편성 강점이 더 커집니다. 애쉬 직접 피해는 11.1% 오르지만 희생 손실은 남고, 메이드 피해/별빛은 6.25% 오릅니다. 산타는 공속 버프 시간만 25% 줄며 소환은 같습니다. 오라 계열은 이미 최댓값 규칙이므로 중복 허용 변경은 별도 조합 예산 검토가 필요합니다. 큐어마스터 상시 자체 무적은 오라 유지와 애쉬 희생 회피를 함께 강화합니다. 조커는 시작 색 포함·동색 재추첨 제외 기준 5색 완성까지 평균 8.33번 색 전환이 필요합니다.

상태이상 외 조건은 적 코어 접근(마지막 경로에 표적과 검사 동료 배치), 코어 체력 50% 미만, 아우로라 2기, 노멀 전용 편성, 번개 연결 4기, 다른 토끼 2종, 인접 위력·공속 오라, 조화 인접 4종, 가짜 신데렐라, 마술사 인접 4기를 지원합니다. 등장 후 웨이브·조커 색·골드·유성 별빛도 선택합니다. 동료별 대표 조건은 해당 동료의 대표적인 비상태이상 조건만 켭니다. 루나의 저체력 등 적 상태 조건은 따로 선택합니다. 통상 열은 이런 선택을 기본값으로 되돌려 비교합니다.

편성용 보조 동료는 자체 평타를 멈춥니다. 아우로라 2기를 두어도 2기 전체 DPS로 부풀리지 않으며, 시간의마술사가 강제로 발사시키는 추가 공격은 그대로 계산합니다. 지크의 위치 조건과 코어 생명력 조건은 서로 독립입니다. 신데렐라·산타의 공격 횟수 주기 효과는 기존부터 자동으로 계산하며, 루미의 5성 변형은 성급 설정으로 재현됩니다. 조화의 수혜자 팀 평타·거울에 공급할 외부 팀 피해·희생 자원의 장기 손실은 여전히 단독 비교의 범위 밖입니다.
