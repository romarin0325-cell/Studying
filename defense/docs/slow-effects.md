# 감속 효과의 중첩과 만료

감속은 적의 `slowEffects`에 `{source, amount, until}`로 저장한다. `until`은
게임 전투 시간 `state.time` 기준 만료 시각이다. 일시정지나 2배속도 같은 게임
시간 기준으로 처리하며, 기기의 실제 시각을 사용하지 않는다.

- 일반 공격과 지속 장판은 캐릭터별 `attack:<hero>` 효과를 2.4초로 갱신한다.
- 필살기는 별도 `skill:<hero>` 효과를 설명에 맞는 시간으로 부여한다.
- 같은 출처만 갱신한다. 다른 출처의 감속률이나 만료 시각은 바꾸지 않는다.
- 활성 효과 중 가장 강한 감속률을 적용한다. 강한 효과가 끝나면 아직 남은
  약한 효과로 복귀하며, 모두 끝나면 감속률과 남은 시간을 0으로 만든다.
- `slow`와 `slowTime`은 이동·빙결 연계·유물·상태 표시를 위한 파생 값이다.
  `slowTime`은 현재 가장 강한 효과의 남은 시간이다. 강도가 같은 효과가
  여러 개면 그중 가장 늦게 끝나는 시간을 표시한다.

빙궁의 칙령은 50% / 6초다. 눈토끼의 일반 공격은 그 만료 시각을 줄이지
않고, 마녀의 일반 공격은 50%를 연장하지 않는다. 6초 뒤에도 마녀의
일반 감속이 남아 있으면 40%가 적용된다. 눈토끼·아발란체메이드·폭풍의현자·
은하고래의 감속 필살기도 같은 규칙을 적용한다.

기존 저장에는 출처가 없으므로 현재 남은 감속을 `legacy` 효과 하나로
보존한다. 새 일반 공격으로 이 효과의 만료 시각을 갱신하지 않는다.
새 저장은 각각의 출처와 만료 시각을 그대로 보존하며, 복원할 때 출처,
감속률, 만료 시각과 중복 출처를 검증한다.

`defense/tests/unit/slow-effects.test.mjs`는 두 보고 사례, 일반 감속 간의
교대, 여러 필살기의 교대, 기존 감속 필살기 네 종류, 저장 재개와 이전
저장 호환성, 잘못된 효과 데이터 거부를 실제 공격·필살기·전투 틱으로 검증한다.
