# 동료 16명 확장 (2026-11-22)

카드 게임의 정체성은 `card/game/data.js`에서 가져오되, 디펜스 게임의 5×5 배치·합성·웨이브 구조로 다시 설계했다. 카드 전용 상태인 암흑·약화·부식·침묵·유혹은 새 상태를 추가하지 않고 기존 전투 상태인 성광·중독·화상·감속·기절·노출로 번역했다. 기존 상태의 저장 형식과 중첩·지속시간 규칙은 바꾸지 않는다.

## 일반 공격과 필살기 연출

`src/combat/expansion-vfx.js`는 기존 production 구조와 같이 **GPT 생성 투명 래스터 중심 심벌 + Canvas 2D 동작/합성**을 결합한다. 등급별 `effects-card-expansion-*.webp` 4×2 아틀라스의 위 행은 일반 공격, 아래 행은 필살기이며, `CombatFX`가 실제 `attack`·`impact`·`skill` 이벤트에서 이를 이동·회전·잔상·발광과 함께 그린다. 16명은 영혼불, 금장 군기, 심해의 눈, 봉인 부적, 연화 만다라, 아홉 여우불, 성역 날개, 질풍 발톱, 몽마 하트, 스컬 브레스, 실험 플라스크, 수정 단검, 별꼬리, 설탕구름, 미믹 상자, 침묵의 책으로 서로 다른 일반 공격 실루엣과 필살기 시퀀스를 갖는다. 합성 파동·기절 방호·수정 반격처럼 일반 공격이나 필살기 밖에서 발생하는 고유 이벤트도 같은 시각 언어로 연결한다. SVG는 사용하지 않으며, 래스터를 불러오지 못한 경우에만 절차형 Canvas 모티프가 안전 폴백으로 동작한다. 생성 원본·프롬프트·해시·패킹 기준은 [전투 VFX 출처 기록](art/expansion-vfx-20261123/PROVENANCE.md)에 고정했다.

전용 분기가 있는 동료에게는 기존 범용 필살기 문양을 다시 얹지 않는다. `tests/expansion-vfx.test.mjs`는 16명 모두를 실제 엔진에서 공격·착탄·시전한 뒤 전용 렌더 경로와 범용 문양 비중복을 검증한다. 정식 배포본은 `scripts/capture-expansion-vfx.mjs`로 390×844 야간/밝은 테마의 일반 공격·필살기 접촉 시트를 만든다.

## 수집과 소셜 콘텐츠

- 16명은 제1부 마지막 스테이지 클리어 뒤 기존 후반 동료와 같은 정규 소환 풀에 들어간다.
- 각 동료는 합류 대사, 로비 터치 3종, 친밀 대사, 인사 2종, 선호/일반 선물 대사, 부탁 3개와 부탁 후일담을 갖는다.
- 메모리얼 그림과 본문은 이번 확장에 포함하지 않는다. 도감과 호감도 화면에는 **메모리얼 준비 중**으로 표시하며, 기억 수집률의 분모에서도 제외한다. 호감도·선물·부탁 진행은 그대로 저장된다.

## 아트와 검수 경계

선택된 2×2 방향 아틀라스의 원본 PNG/WebP는 `assets/cast-v2/`에 보존한다. 게임은 동일 WebP에서 640×640 전투 텍스처와 240×240 초상화, 512×512 상세 전신을 빌드 시 생성한다. 원본 경로·SHA-256·형식 검사는 [확장 아트 출처 기록](art/expansion-20261122/PROVENANCE.md)에 고정했다. 사용자 선택본 통합과 정식 F 실장 검수 완료는 서로 다른 상태이며, 후자는 기록대로 보류한다.
