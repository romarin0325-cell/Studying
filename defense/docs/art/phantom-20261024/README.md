# 팬텀 디자인 복원과 전체 초상화 검수 · 2026-10-24

## 원화와 현재 버전의 차이

사용자 원화 `Downloads/캐릭터/팬텀.png`, `컨셉.txt`, `시나리오.txt`와 이전 SD `assets/merge/units/phantom.webp`를 직접 확인했다. 원화는 짧은 검보라 머리, 라벤더색 눈, 별무늬 보라색 후드 잠옷과 긴바지, 맨발, 품에 안은 갈색 곰인형이다. 뒤의 거대한 악몽 곰과 왕관은 배경이며 착용 장식이 아니다.

직전 cast-v2는 얼굴과 채색은 세트에 맞지만 의상을 남색 장식 코트·은색 테두리·반바지·스타킹·부츠로 바꿨다. 당시 생성 지시에도 이 잘못된 해석이 들어 있었다. 이전 이미지를 복원해 붙이지 않고 현재 얼굴·선·채색을 기준으로 잠옷과 긴바지, 맨발을 새로 그렸다. 옛 cast-v2 PNG/WebP와 이전 SD는 보존한다.

## 생성 이력과 재현 가능한 제작 자료

`candidate-v1/`은 처음 만든 의상 교정 후보의 실제 생성 원본·프롬프트·참조·좌표·패킹 기록이다. 이 후보에는 기존 구조 가이드를 실제 생성 입력으로 넣지 않았다. 사용자 지적 후 이를 최종 적용하지 않고, 기존 공통 프롬프트와 **실제 팬텀 3D 가이드**, 동결 세이렌 화풍 참조, 사용자 원화, 의상 후보를 순서대로 입력해 후속 생성했다. 루트의 파일들이 이 최종 `pajamas-guided-v2` 기록이다. 기존 후보의 입력 기록을 소급 수정하지 않는다.

- `generation.png`: 내장 이미지 생성 도구가 반환한 1254×1254 RGBA 원본. 투명 배경 생성. 행 사이 빈 구간을 확인해 y=660에서 나누며, 정중앙 y=627에서 잘라 발을 손상시키지 않는다.
- `prompt.txt`, `inputs.json`: 실제 최종 프롬프트, 참조 순서·역할과 입력 파일 해시. 도구가 별도 모델 버전 식별자를 반환하지 않아 버전 번호를 추정하지 않는다.
- `landmarks.json`: 수동 두개골·턱·발 기준점. 머리카락·후드·곰인형을 머리 크기에 포함하지 않는다. 뒷머리의 두개골은 가려져 있어 추정이며 정밀 3D 실측이 아니다.
- `packing.json`: 네 방향 공통 등방 배율 0.637793, 공통 발 기준점 (256,480), 패킹 결과 해시와 측정 오차. 정면 두개골 타원 약 159.45×150.52px. 방향별 크기를 별도로 늘이거나 찌그러뜨리지 않았다.
- `face-review.json`: 머리 면적 정규화와 별개로, 새 그림의 눈 중심과 실제 구조 가이드의 눈 표식을 직접 대조한 기록이다. 512px 기준 눈 간격 약 62.3px 대 66.0px로 약 5.6% 차이가 있다. 고개 각도·표정과 수동 점 위치 오차가 있으므로 완벽한 동치라고 부르지 않는다.
- `previous-v2.json`: 수정 전 메타데이터. 과거 이미지에 현재 기준점을 섞어 Before 영역을 그리지 않는다.
- 재생성: 저장소 루트에서 `node defense/scripts/art/pack-phantom.mjs`. 생성 원본의 저알파 고립 픽셀만 기계적으로 정리하고, 얼굴·의상을 픽셀 도구로 다시 그리지 않는다.

수동 추정의 경계 불확실성은 원본 기준 정면·측면 ±18px, 뒷머리 ±26px, 발 ±5px로 기록했다. 패킹 후 정면 추정 오차는 약 ±11.5px다. 그림 위에 정수 좌표가 있다고 해부학적 크기가 정확하다는 뜻은 아니다. 육안 비교를 함께 사용한다.

## 배포와 초상화 정렬

최종 원본은 `assets/cast-v2/phantom-pajamas-guided.png`와 q95 WebP(145,016B)다. 전투 내장본은 원본에서 별도로 만든 640×640 q90 WebP(53,624B)이며 원본 WebP보다 약 63.0% 작다. 실제 해시·해상도는 배포 매니페스트에 기록한다. 작은 전장 크기 확인과 별개로 FPS 향상을 주장하지 않는다. 초상화와 전신은 원본에서 직접 만든 고정 UI 파생본을 사용한다.

`src/portrait-layout.js`는 **시각적 UI 정렬만** 처리한다. 최신 main의 토피애플·하모니어스·시간의마술사 x−7px, 둠·루미 y−8px 보정을 보존한다. 새 팬텀만 y+8px로 자르는 중심을 내려 얼굴을 약간 위로 옮겼다. 기준은 512px 프레임이며 54px 슬롯에서 약 1.5~1.7px의 미세 이동이다. 다른 캐릭터를 일괄 재중앙화하거나 배율을 바꾸지 않았다.

기존 작은 초상화와 소환 결과 카드의 경로가 달랐다. 전자는 이미 미세 보정을 사용했지만 후자는 해부학적 중심만 사용했다. 이제 준비된 초상화와 전신에서 얼굴을 자르는 소환 카드가 같은 `portraitFrame()`을 사용한다. 메타데이터의 원래 두개골 기준점과 크기는 유지한다.

검토 범위는 39명 전원이며 편성, 편성 후보/훈련/파견 선택 목록, 도감/파트너 선택, 필살기 버튼, 원형 필살기 설명, 전투 유닛 정보, 전투 기록, 소환 기록, 시즌 수호자, 파견 진행 슬롯, 오라 표시, 천장 선택, 신규 동료 안내, 루미 도움말, 소환 결과 카드의 사용처를 확인한다. 전신 일러스트·메모리얼 장면은 얼굴 아이콘과 다른 용도로 구분한다.

정식 일반판·Bright 빌드와 디펜스 전용 123개 테스트가 통과했다. 방향 검사도 통과했다. Chromium 390×844, DPR 2의 두 테마에서 실제 편성·도감·소환·전투 정보 화면과 적 좌/우 공격을 확인했다. 22개 캡처에서 페이지 오류와 외부 에셋 요청은 0건이었다. 아래 그림은 그 검수 자료이며 실제 기기 FPS 측정을 뜻하지 않는다.
