## 생성

- 도구: GPT 이미지(Codex CLI 내장 image_gen, `codex exec -i <참조>`, 추론 노력 low). 모델 버전 문자열은 도구가 알려 주지 않는다.
- 시트 세 종류, 각각 후보 3장(a·b·c):
  - `kitL`(빛 6칸, 검은 바탕): 참조 1은 1차 키트의 스타일 판(`../ur-vfx-20261106/kit-style-ref.png`), 참조 2는 `motif-light.webp`(자스민 엠블럼, 시간의마술사 시계 고리와 바늘).
  - `kitO`(물체 6칸, 투명 배경, 흑백 음영): 참조는 `motif-object.webp`(여왕 장미 왕관과 금화, 트라우마 유리구두). 세 장 모두 실제 알파 채널이고 색이 섞인 픽셀은 0개였다.
  - `kitC`(빛 4칸, 2×2, 검은 바탕): 참조 1은 같은 스타일 판, 참조 2는 `motif-cosmos.webp`(은하고래와 시간의지배자 엠블럼).
- 프롬프트: `kitL.prompt.txt`, `kitO.prompt.txt`, `kitC.prompt.txt`. 후보 원본은 픽셀이 같은 무손실 WebP로 보관했다(`gpt-kit*-?.webp`, 투명 픽셀 RGB까지 보존).

## 칸 선택과 패킹

`node defense/scripts/art/pack-pick-sheet.mjs defense/docs/art/ur-vfx2-20261106/kit2-pack.json defense/docs/art/ur-vfx2-20261106/kit2-packing.json`

- 모드 `kit`: 빛 칸은 흰색 + 밝기 알파, 물체 칸은 회색 + 원래 알파로 한 장에 담는다.
- 물체 칸은 `solo`: 가장 큰 덩어리만 남겨 생성기가 옆에 뿌린 작은 반짝이를 지운다(그대로 두면 꽃잎이 회전 중심에서 벗어난다).
- 선택:
  - 마법진 c(빛나는 꼭짓점이 작게도 읽힘), 날개 a, 깃털 a, 시계판 b(로마 숫자 배치가 정확), 시계바늘 a(굵어서 돌아도 또렷함, 아래 정렬), 빛기둥 b.
  - 유리구두 a, 장미 c(꽃잎 사이 음영이 깊어 진홍에서 잘 읽힘), 꽃잎 a, 덩굴 c(아래 정렬), 금화 c, 왕관 a.
  - 고래 b(윤곽이 가장 선명), 은하 a(밝은 핵, 분명한 팔), 톱니 b(시간의지배자 엠블럼과 같은 장식), 모래시계 b(날씬한 틀).
- 시계바늘의 회전축(둥근 축 중심)은 칸 높이의 0.836, 바늘 끝까지 길이는 칸의 0.785다(`HAND_PIVOT`, `HAND_REACH`). 빛기둥은 칸 폭의 0.27을 차지한다(`pillar()`).
- 배포본은 `node defense/scripts/art/add-optimized.mjs`로 새 항목만 추가했다(기존 압축본은 다시 압축하지 않는다).

## 확인

- 어두운 바탕과 밝은 바탕에서 칸 경계, 잘림, 잡티를 봤다. 경계 경고(시계판, 덩굴, 모래시계)는 장식 끝이 자르기 선에 닿은 것으로, 잘린 곳은 없다.
- `docs/review/ur-vfx-20261106/index.html`(2차 묶음)에서 실제 렌더러로 전후를 비교했다.
- 확인하지 못한 것: 실제 휴대폰 화면·FPS, 소리, 실제 컷인 그림과의 조합.
