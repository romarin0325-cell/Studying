# 루나·둠 편성 초상화

동료 편성에서 루나의 후드와 둠의 얼굴이 크게 읽히는 정도를 줄였다. 같은 등급 UR 15명을 놓고 두 대상과 나머지 13명의 평균·중앙값을 비교했다. 수치와 수동 기준점은 [audit.json](audit.json), 크기·배경·가이드를 전환하는 도구는 [review.html](review.html)에 있다. 실제 전후 화면의 비교 기준은 main `fac6fd5b`이다.

| 초상화 | 수정 전 크롭 중심·폭 | 적용 크롭 중심·폭 | 표시 배율 |
| --- | --- | --- | --- |
| 루나 | (242, 220) · 250px | (243, 207) · 272px | −8.1% |
| 둠 | (253, 199) · 250px | (252, 196) · 258px | −3.1% |

원본 정면 512px 프레임에서 새 정사각형 영역을 잘라 240px 초상화를 준비한다. 적용점은 [portrait-layout.js](../../../src/portrait-layout.js)다. 이 공통 크롭을 편성·목록·쌍성·소환의 얼굴 UI에 사용한다.

| 측정 | UR 13명 평균 | 루나 전 → 후 | 둠 전 → 후 |
| --- | ---: | ---: | ---: |
| 원본 두개골 추정 폭 × 높이 | 160.8 × 149.3px | 158.6 × 151.4px | 159.6 × 150.4px |
| 원본 장식 포함 머리 외곽 | 270.8 × 207.1px | 281 × 217px | 211 × 207px |
| 240px 칸의 머리 점유율 | 54.7% | 64.8% → 57.6% | 51.3% → 48.1% |
| 동공 사이 | 61.6px | 63.6 → 58.5px | 70.5 → 68.3px |
| 눈 축에 수직인 눈~턱 | 44.9px | 43.6 → 40.0px | 60.0 → 58.1px |
| 얼굴 기준 세로 중심 | 167.3px | 149.7 → 158.8px | 166.0 → 167.4px |
| 머리 윤곽 세로 중심 | 107.2px | 100.6 → 111.2px | 102.8 → 106.1px |

루나는 두개골 추정과 눈~턱 길이가 기준에 가깝고, 후드 포함 실루엣의 면적이 원본에서 약 21% 크다. 272px 크롭은 화면에서 차지하는 면적을 평균 쪽으로 줄이면서 잘려 보이던 후드 꼭대기에 여백을 준다. 머리 영역 보존율은 94.8%에서 99.8%로 높아졌고 얼굴 기준은 같은 칸에서 약 9px 내려왔다.

둠의 전체 머리 외곽은 평균보다 좁다. 드러난 이마·턱선과 긴 눈~턱, 밝은 바탕의 어두운 헤어가 크게 읽히는 주요 요소다. 동공 간격은 보정 후 지크의 68.1px에 가깝다. 세로 얼굴 길이와 어두운 헤어의 인상은 캐릭터의 형태로 남긴다.

머리 윤곽은 원본 앞면에서 모자·헤어·머리 장식을 포함한 수동 영역의 알파로 쟀다. 목·어깨 아래, 늘어진 머리, 무기·날개는 측정에서 뺐다. 두개골은 제작 기록의 추정이며 얼굴 점은 실제 배포 초상화에 별도로 표시했다. 눈과 턱 위치의 판독 오차는 약 3~4px이다. 머리 점유율과 명암 면적은 그림의 체감을 설명하는 보조 지표다. 실제 테두리·배지·후보 투명도는 화면 캡처에서 대조했다.

## 검증

- 에셋·빌드 선택 검증 10개 통과. 두 초상화를 새로 준비했고 다른 파생본 160개와 정적 이미지 기록 191개를 재사용했다. 준비된 초상화 두 장의 합계는 1,134B 줄었다.
- 일반판·Bright·쌍성 테스트의 실제 HTML을 Chromium 390×844, DPR 2에서 열었다. 같은 편성의 전후 32캡처에서 JS 오류, 외부 요청, 가로 넘침, 이미지 누락은 0건이었다.
- 비교 도구는 1280·390·320px에서 전후·UR 전체·원본·실제 화면과 38~240px 크기 옵션을 검사했다.
