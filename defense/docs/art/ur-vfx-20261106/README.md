## 생성

- 도구: GPT 이미지(Codex CLI 내장 image_gen, `codex exec -i <참조>`). 모델 버전 문자열은 도구가 알려 주지 않는다.
- 키트: 시트 두 장(`kit1` 6칸, `kit2` 6칸)을 각각 후보 2장(a·b) 생성. 참조 1은 기존 이펙트 언어를 펼친 판(`kit-style-ref.png`: 루나 베기, 혹한의마녀 얼음, 체리프린스 꽃잎 마무리, 루나·혹한의마녀 문양). 프롬프트: `kit1.prompt.txt`, `kit2.prompt.txt`(흑백 밝기 지도로 그리라는 지시).
- 디저트: 검은 배경 후보 2장씩(`gpt-d1-a/b`, `gpt-d2-a/b`)을 먼저 받았으나, 검은 배경을 지우면 밝은 배경에서 어두운 테두리가 남았다. 사용자 지적 뒤 이미지 도구의 투명 배경 옵션(`transparent_background: true`, 실제 알파 채널 확인)으로 다시 후보 2장씩(`gpt-d1-t1/t2`, `gpt-d2-t1/t2`) 받았다. `d2-t2`는 하얀 안개 사각형이 끼어 버렸다. 프롬프트: `d1-transparent.prompt.txt`, `d2-transparent.prompt.txt`. 참조: `dessert-style-ref.png`(하모니어스 기존 이펙트)와 하모니어스 전신.

## 칸 선택과 패킹

`node defense/scripts/art/pack-pick-sheet.mjs <spec> <report>`가 후보 시트에서 칸을 골라 한 장으로 묶는다. 선택은 `kit-pack.json`·`sweets-pack.json`, 자르기 좌표는 `kit-packing.json`·`sweets-packing.json`.

- 키트: 베기 줄 a, 초승달 b(결정면이 있어 작게 그려도 읽힘), 고리 b(깨끗한 원), 안개 b(가운데가 빈 고리), 파편 b, 섬광 b(작은 크기에서 또렷한 네 갈래), 꽃잎 b, 가시 묶음 a, 가시 a, 보름달 a, 서리 a(길 위에서 낮은 알파로도 보이는 밀도), 파편 폭발 b.
- 디저트: 투명 배경 `t1` 시트 하나에서 6종을 모두 가져와 빛 방향·채도를 맞췄다. 스탠드·딸기·리본·솜사탕·마카롱은 `d2-t1`, 별가루는 빛이라 검은 배경 `d2-a`.
- 알파 248 이상은 불투명, 3 이하는 비움(생성기의 미세한 잡티 제거).
