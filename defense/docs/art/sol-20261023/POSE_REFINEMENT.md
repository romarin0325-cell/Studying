# 베놈 · 앤트로피의 최종 대기 포즈

사용자의 마지막 요청은 두 캐릭터의 특징을 지키면서, 여러 명이 놓이는 전장에서 과도하게 시선을 끄는 제스처를 줄이는 것이었다. 기존 GPT 여왕·세이렌의 차분한 대기 문법을 참조해, 새 캐릭터의 그림체와 표정은 유지하고 포즈를 조정했다. Claude 시트를 생성 입력으로 넣지 않았다.

- **베놈:** 고개와 시선을 더 수평으로 두고 오른팔을 몸 가까이 내렸다. 왼손의 검은 백합 지팡이는 가까이 세웠다. 창백한 얼굴, 슬픈 녹색 눈, 피부의 가지 무늬, 검정/녹색 머리와 드레스, 봉오리와 가지의 관은 유지했다.
- **앤트로피:** 왼손의 작은 구체를 허리/가슴 아래로 내리고 팔꿈치를 몸에 가까이 뒀다. 가려진 눈, 무표정에 가까운 보라색 눈과 작은 입, 흰 머리와 레이스, 궤도형 후광을 유지했다.

최종 파일은 `venom_idle.png/webp`, `antropy_idle.png/webp`와 각각의 방향 PNG다. 앞서 만든 `venom.png/webp`, `antropy.png/webp`도 이전 포즈로 보존했다. 비교 도구의 **Sol 포즈**에서 전환한다. 기본 선택은 새 대기 포즈다. 각 버전의 생성 원본과 측정 기록도 덮어쓰지 않았다.

| 최종 대기 시트 | 정면 두개부 추정 / 512셀 | 턱~접지: 정면 / 후면 / 좌 / 우 |
|---|---|---|
| 베놈 | 159.5 × 150.5px | 197.2 / 197.2 / 186.3 / 185.3px |
| 앤트로피 | 158.5 × 151.4px | 184.9 / 184.9 / 177.7 / 177.7px |

측정은 수동 추정이며 원본 정면/측면 약 ±12px, 가려진 후면 약 ±16px의 불확실성이 있다. 고개·턱·서 있는 자세의 투영 차이가 남는다. 방향별 별도 배율이나 가로/세로 변형으로 숫자를 맞추지 않았다. 이전 포즈에서 얼굴/머리의 크기와 인상이 완벽하게 픽셀 단위로 유지됐다고 주장하지 않으며, 비교 자료를 통해 실제 변경을 볼 수 있다.

원본의 행 분리도 다시 확인했다. 생성 시트가 항상 높이의 절반에서 정확히 나뉘지는 않는다. 베놈 새 시트는 y=619, 앤트로피는 y=640의 빈 행에서 분리했다. 행 경계에 다른 방향의 관·후광이 끼어 들어가거나 그것을 발로 오인하지 않도록 경계의 알파와 실물 그림을 확인했다. 패킹 뒤 그림 잘림 0, 접지 오차 1px 미만, 규격·해시·투명도와 방향 PNG/아틀라스 일치가 통과했다.

`records/pose-generation.json`, 실제 `venom-idle.prompt.txt`/`antropy-idle.prompt.txt`, `pose-asset-manifest.json`과 `pose-validation.json`에 입력·출력·기준점이 있다. 실제 전투에 설치해 이동/공격 모션을 검증한 결과는 아니다.
