# 지크 · A안 어깨에 받친 대검 · 2026-10-29

사용자가 선택한 A안의 편하게 어깨에 대검을 받친 구도를 실제 정면·후면·왼쪽·오른쪽으로 완성해 설치한다. 기준 main은 `152b502fa79161e1e343e6541e0b7fd30fbaaf3b`(골드드래곤 PR #647 병합)이다. 변경 범위는 지크 SD와 초상화·전신 파생본이다. 전투 수치·로직·공격/필살기 이펙트·메모리얼을 바꾸지 않는다.

## 자세와 원래 디자인

검을 받치는 곳은 해부학적 **오른쪽 어깨**, 손잡이를 잡은 손은 **오른손**이다. 왼팔은 편하게 내린다. 왼쪽 측면에서는 빈 왼팔이 가까이, 무기 오른팔이 멀리 있으며 오른쪽 측면에서는 무기 오른팔이 가까이 보인다. 후면에서도 오른손을 유지한다. 좌우를 단순 반전해 손을 바꾸지 않았다.

원화의 검을 확대한 `references/original-weapon.png`로 검은 각진 가드와 붉은 중앙 광택을 확인했다. 앞선 샘플 평가와 첫 프롬프트에서 이 요소를 새 보석으로 오인한 점은 정정한다. 원화에는 원래 붉은 중앙 면이 있으며 최종 그림에서도 보존했다. 가슴의 빛과 가드 장식은 서로 다른 요소다.

## 실제 생성 이력

내장 `image_gen`을 사용했으며 세부 백엔드 버전은 반환되지 않았다. 다른 AI로 라우팅하지 않았다.

1. `generation-v1.png`: 기존 승인 지크·사용자가 고른 A 포즈·실제 오른손 3D 가이드·원화·동결 세이렌 화풍을 넣어 네 방향을 생성. 몸이 아직 길어 후속 교정했다.
2. `generation-v2.png`: 얼굴/구도는 유지하고 턱 아래 몸통과 다리를 더 짧게 다시 그림. 공통 두개골 배율로 패킹했을 때 왼쪽 측면 칼끝이 셀 밖으로 나가 채택하지 않았다.
3. `generation.png`: 동일한 자세에서 검날 길이만 소폭 줄여 끝까지 들어오는 최종 원본. 원본1254×1254 RGBA와 앞선 두 결과를 그대로 보관한다.

`prompt-atlas-v1/2/3.txt`, `inputs-atlas-v1/2/3.json`은 각각 실제 생성 전 저장한 프롬프트와 입력 순서·SHA-256이다. 잘못된 초기 지시를 최종 해석으로 소급 바꾸지 않는다. `source-record.json`은 초기 소스/구조 코드 출처이며, `installation.json`은 실제 설치 경로와 선택을 기록한다.

## 구조 가이드와 제작 기준

`make-shoulder-guide-v3.mjs`는 기존 절차적 마네킹 생성기에서 몸·공통 머리·카메라를 유지하고 오른팔/대검만 변경한 실제3D 구조 가이드 생성기다. `references/shoulder-guide-v3.png/.json`을 모델에 실제로 넣었다. 오른팔은 청록, 왼팔은 분홍이며 하나의 자세를 회전한다. 완성 지크의3D 리그를 만든 결과는 아니다.

기존 승인 아틀라스는 `references/previous-atlas.png`, 선택된 A 샘플은 `references/selected-a.png`, 원화·무기 확대와 동결 화풍 참조도 각각 보존했다. 기존 `assets/cast-v2/zeke.png/.webp`와 이전 배포 압축본을 덮어쓰거나 삭제하지 않는다.

## 머리와 비율의 검수

머리는 두개골과 얼굴이며 뻗친 머리·대검·어깨 갑옷은 제외한다. 네 방향에 **전신 공통 등방 배율0.7595545253**을 적용하고 발 기준점만 (256,480)으로 이동한다. 머리나 다리의 별도 확대, 가로·세로 왜곡, 방향별 배율, 검을 포함한 전체 외곽 자동 맞춤을 하지 않았다.

| 항목 | 기존 | 최종 |
|---|---:|---:|
| 정면 두개골 추정 |157.84×152.05px |157.99×151.91px |
| 턱 아래 길이 |209.97px |205.84px |
| 나머지 방향 턱 아래 |기존 기록 참조 |202.04 /202.80 /202.80px |
| 공통 발 기준 |(256,480) |(256,480) |
| 알파32 이상 그림 클리핑 |0 |0 |

같은 면적으로 정규화한 결과는 배율 공식의 결과이므로 독립적인 해부학 동치 증거로 삼지 않는다. 별도로 기존 얼굴과 눈 간격·눈~턱 거리를 수동 대조하고 같은512px 프레임,64/96px, 밝고 어두운 바닥에서 비교한다. `face-review.json`에는 이 수동 기준점과 추정 오차를 기록한다. 피부 노출 면적이나 머리카락의 폭으로 얼굴을 재평가하지 않는다.

`landmarks.json`, `packing.json`은 방향별 원본 두개골·턱·발, 공통 배율, 알파 정리와 클리핑 결과다. `previous-metadata.json`은 실제 과거 그림의 기준점이다. 현재 좌표를 과거 이미지에 섞어 Before를 그리지 않는다. 원본 기준 정면/측면±18px, 후면±26px, 발±5px는 수동 경계 추정이며 통계적 신뢰구간이 아니다.

## 배포와 재현

보존 PNG는1,137,059B, q95 WebP는285,326B다. 전장 배포본은 원본에서 만든640×640 q90 WebP108,172B로 약62.1% 작다. 초상화240px·전신512px도 보존 원본에서 직접 준비하며, 다른157개 UI 파생본은 재사용했다. 해부학적 초상화 중심만 (255,198)로 갱신하고 크기250은 유지한다.

- 패킹 재현: `node defense/docs/art/zeke-shoulder-20261029/pack.mjs .`
- 이 아틀라스만 배포 준비: `node defense/docs/art/zeke-shoulder-20261029/prepare-deployment.mjs`
- 초상화/전신 준비: `node defense/scripts/optimize-images.mjs --derived-only`
- 독립 비교 도구: `node defense/docs/art/zeke-shoulder-20261029/build-review.mjs <출력 review.html>`
- 실제 브라우저 확인: `node defense/docs/art/zeke-shoulder-20261029/verify-browser.mjs <출력 review.html>`

비교 도구는 수정 전후·네 방향·방향 순환·64/96px·두 바닥·실제 준비된 초상화·기존 동료 나란히 보기를 제공한다. 방향 순환은 네 대기 그림의 비교이며 새 보행 애니메이션이 아니다. 정식 일반/Bright/밸런스 랩 HTML과 로컬 전체 해금 빌드를 함께 준비한다.

## 확인 범위와 한계

기존 방향 검사와 설치/원본/초상화 계약, 디펜스 전용 선택 검증을 사용한다. 실제 오프라인 일반판·Bright390×844에서 홈·동료·상세·편성·상하좌우 공격 후 대기·유닛 정보를 확인한다. 정지 표적은 방향 검수를 위한 사전 저장 fixture이고 실전 난이도 측정이 아니다. 검수 캡처·오류·해시는 `evidence/`와 `verification.json`에 보존한다.

완성 그림은4장의2D 에셋이다. 모든 머리 가닥·검의 균열 문양·가림 관계가 완전히 같은3D 모델의 회전이라고 보장하지 않는다. 실제 휴대폰의 FPS나 새로운 애니메이션 품질을 측정한 것은 아니다.
