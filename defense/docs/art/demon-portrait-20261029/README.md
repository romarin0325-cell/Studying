# 마왕 초상화 상하 정렬 · 2026-10-29

기존 열린 PR #645의 원래 head `6e6dc59f1022cc7c9c68c6cbfec1b869d7d04a20`에서 확인한 마왕 초상화의 높은 배치를 보정한다. 기존 20차 패치 위에 추가하며 캐릭터 일러스트나 전투 배율을 다시 만들지 않는다.

## 확인한 문제와 변경

마왕·세이렌·별똥별소년 등은 동료 목록에서 같은 240×240 초상화를 같은 크기로 표시했다. 마왕만 별도로 축소되는 CSS는 없었다. 다만 마왕 그림의 눈과 턱이 초상화 안에서 위에 있어 목깃·리본이 더 많이 보였고 작은 얼굴처럼 느껴질 수 있었다. 노출 피부의 경계는 위치 확인의 참고이며 두개골 크기의 실측값으로 취급하지 않는다.

`portrait-layout.js`의 마왕 UI 보정을 `[0,-16]`으로 정했다. 512px 원본 정면 프레임에서 자르는 중심 y를 220→204로 올리면, 결과 초상화 속 얼굴은 아래로 이동한다. 자르기 영역은 `(130,95,250,250)`에서 `(130,79,250,250)`으로 바뀐다. 크롭 크기와 배율은 같다.

동료 목록의 약 95~98px 아이콘에서는 얼굴이 약 6.1~6.3px 아래로 이동한다. 작은 편성 슬롯에서는 그보다 적게 이동한다. `[0,-8]`, `[0,-12]`, `[0,-16]` 시안을 같은 배율로 비교하고 마지막 값을 골랐다.

캐릭터의 원래 해부학적 초상화 좌표 `(255,220,250)`, 정면·후면·좌우 원본, 640px 전투용 아틀라스, 전신 이미지와 `foot=.9375 / scale=1`은 그대로다. 마왕의 UI 초상화 하나만 원본에서 다시 준비하고 다른 파생본 155개를 재사용했다. 일반판·Bright·밸런스 랩은 정상 빌드 진입점으로 갱신했다.

공유 `portraitFrame()`을 사용하므로 동료 목록·파트너 목록·편성·기록·전투/필살기 초상화와 소환 결과의 얼굴 크롭에 같은 보정이 적용된다. 동료 전체나 필드 스프라이트를 키우지 않는다.

## 검증

기존 에셋 테스트에서 마왕만 검토된 세로 이동 16px를 허용하고 다른 동료의 8px 제한은 유지했다. 추가 단언은 마왕의 y가 정확히 16px 감소하고 크기와 x가 같으며, 준비되는 자르기 영역이 위 좌표와 일치하는지 확인한다. 설치본의 해부학적 좌표·원본 해시·전투 배율 검증도 유지한다.

`verification.json`에 기존/수정 후 Chromium 390×844 두 테마에서 확인한 이미지 크기, 표시 위치, 실제 HTML 내장 이미지 해시와 다른 에셋의 보존 여부를 기록한다. 비교 화면은 실제 PR의 일반판/Bright 통합 HTML에서 캡처했다. 물리 기기나 FPS 검증을 의미하지 않는다.
