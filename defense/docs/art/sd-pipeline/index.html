원화부터 검수본까지,
같은 기준을 끝까지.

새 대화에서도 저장소의 스킬·실행기·검수 규칙으로 이어지는 제작 공정입니다. 머리와 몸, 네 방향, 표정과 화풍을 함께 확인합니다. 아래 화면은 작업의 순서·실제 마네킹·실행한 프롬프트·선택본을 보여 주며 자동 미학 승인을 하지 않습니다.

실행 절차이번 설치 기록

1 · A→G, 생략할 수 없는 순서

원화·새 그림·기준점·최종 픽셀·검수 화면·정책·실행 코드가 바뀌면 이후 판정의 지문도 바뀝니다. 이전 합격을 새 그림에 복사하지 않습니다. 미검토·주의·실패가 있으면 G 출력은 막힙니다.

2 · 실제9종 구조 마스터와 동결 화풍

같은 해부학적 머리, 다른 작은 몸. 정면160×150·측면깊이144·바닥(256,480), 턱 아래176/188/200px가 구조 목표입니다. 마네킹은 완성 캐릭터 리그가 아니며 이미지 모델의 준수를 보장하지 않습니다.

3 · 누적17항목을 같이 검수

장식/머리 부피를 실제 두개골과 구별하고, 눈~턱·볼·머리 대비 몸·외곽선과 전체 인상을 같은 배율로 봅니다. 아래 항목은 실행 정책에서 읽습니다.

4 · 실제 실행한 프롬프트와 입력 역할

이 설치본의 실행 기록입니다. 새 캐릭터 제작에는 원화 관찰/명세를 새로 작성하고 `sd:brief:defense`로 새 입력·job을 준비합니다.

5 · 이번 설치본, 이전 그림과 비교

같은512px 셀·바닥선, 인접5px 간격. 장비 외곽 자동 맞춤이나 얼굴별 자동 확대를 하지 않습니다. 체리프린스는 측면 눈높이 주의를 남긴 사용자 선택본입니다.
