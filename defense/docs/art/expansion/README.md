# 천상의 세 시련: 재현 가능한 아트 검수

## 머리가 의미하는 것

머리는 **해부학적 두개부와 얼굴**이다. 정수리의 두개골부터 턱까지, 좌우 두개부/볼의 폭을 비교한다. 토끼 귀, 뿔, 버섯 모자, 후광, 머리카락의 외곽·묶은 머리·장식은 별개다. 머리카락에 가려진 정수리는 수동 추정이며 자동 검출값으로 표현하지 않는다. 볼/턱이 드러난 위치와 얼굴 중심을 함께 확인한다.

`LANDMARKS.json`의 좌표는 선택 원본 SHA에 묶인다. 공통 정면 목표 160×150px의 면적으로 **한 캐릭터의 네 방향에 단 하나의 균일 축척**을 계산한다. X/Y를 따로 늘리지 않는다. 전신 바운딩 박스로 fit하거나, 귀가 긴 캐릭터를 줄이거나, 모자가 큰 캐릭터를 줄이지 않는다. 발은 각 512px 셀의 (256,480)에 둔다. 키 분류는 참고 메타데이터이며 머리 크기에 재차 곱하지 않는다.

정면 수치는 정규화로 얻은 값이므로 독립적인 품질 인증이 아니다. 산출값이 맞더라도 턱 아래 몸이 길면 원화를 다시 그려야 한다. 이번에는 둠·산타·별똥별소년·시간의마술사·트라우마의 몸 비율을 이미지 편집으로 다시 만들었고 토르·아레스도 압축된 SD 몸으로 교정했다. 큰 머리나 외곽 리사이즈로 보상하지 않았다.

## 실제 비교 결과

동일 셀 크기/발 기준으로 기존 21명과 신규 6명·트라우마를 정면/후면/좌/우, 어두운/밝은 배경, 64px/96px에서 비교했다. 인게임 25칸 밀집 전장도 별도로 렌더링했다. 기존 21개 시트와 기존 일반 공격 effects.webp는 기준 Git과 SHA가 모두 동일하다: [보존 증거](review/provenance.json).

| 신규 형태 | 정면 두개부 추정 W×H | 턱 아래 몸길이 |
| --- | --- | --- |
| 둠 | 154.2×155.6 | 165.7 |
| 산타 | 161.1×149.0 | 182.4 |
| 자스민 | 156.8×153.0 | 205.8 |
| 별똥별소년 | 160.9×149.2 | 176.3 |
| 시간의마술사 | 157.9×152.0 | 210.0 |
| 트라우마 | 155.3×154.6 | 191.0 |
| 체리프린스 | 157.3×152.5 | 180.7 |

단위는 512px 원점 셀 기준 px다. 기존 21명의 정면 두개부는 별도 승인 예외인 신데렐라를 제외하면 폭 156.6–168.0, 높이 142.8–153.2다. 밤토끼 164.4×146.0, 루미 168.0×142.8, 머쉬룸킹 167.3×143.5이며 귀/모자는 포함하지 않았다. 기존과 신규의 얼굴이 작은 전장에서 서로 다른 축척처럼 보이는 뚜렷한 이탈은 이번 육안 비교에서 발견하지 못했다. 눈매·머리 실루엣의 차이는 정체성으로 유지했다.

**수동 추정의 한계와 남겨 둔 검토 항목:** 가려진 경계는 원본에서 약 8–12px의 불확실성이 있다. 둠 좌/우 추정 폭 149.2/139.1, 체리프린스 142.2/152.5는 약 7%의 방향 차이를 보인다. 트라우마 우측 154.6은 측면 참고 폭 144보다 7.4% 크다. 공통 프로필의 6% 방향 검토선에 걸리는 항목으로 명시한다. 얼굴·턱·두개부와 회전 각도를 160px 및 작은 화면에서 재검토했으며, 좌표를 합격값으로 고치거나 방향별로 축척을 달리하지 않았다. 이 값들은 머리카락까지 잰 외곽 치수가 아니며, 수학적으로 완전히 동일한 머리를 보증한다는 뜻도 아니다. 기존 21명의 후면/측면은 육안 비교이며 새 해부 좌표를 측정한 것으로 표시하지 않는다.

검토자는 [인터랙티브 비교표](review/index.html)에서 방향·크기·배경·추정선을 전환할 수 있다. 별도의 승인 요청이나 자동 합격 표시가 아니다.

## 정체성 계약

- 둠: 남성, 검은 가르마 머리·어두운 눈·보라 귀족 코트·오른손 검.
- 산타: 젊은 남성, 은색 곱슬머리·붉은 눈·빨간 모자/외투/목도리·반바지·등의 선물 자루. 모자 장식의 앞/뒤 위치를 유지한다.
- 자스민: 여성, 옅은 라벤더 머리·파란 눈·금관·흰금 의상·왼손 지팡이.
- 별똥별소년: 남성, 은색 삐친 머리와 노란 앞머리·파란 눈·청색/남색/금색 의상.
- 시간의마술사: 남성, 갈색 머리·초록 눈·자주색 의상·오른손 분홍 수정 지팡이.
- 트라우마: 같은 남성의 변신. 갈색 트윈테일·초록 눈·분홍 리본·검정/분홍 드레스·유리 구두. 가슴을 여성형으로 바꾸지 않는다.
- 체리프린스: 남성, 은색 웨이브·분홍 눈·흰금 제복·분홍 짧은 망토·왼쪽 검집.
- 토르: **여성**, 금발 불꽃 트윈테일·파란 눈·검정/금 갑옷·망치. 아레스: 남성, 검붉은 머리·붉은 코트·검. 아스테아: 여성, 금발·붉은 눈·흰 날개/의상·금빛 후광.

## 전처리와 자르기

신규 캐릭터·보스·유물은 원본의 실제 알파를 사용한다. `alphaMode: native`는 마젠타 제거를 건너뛴다. 기존 마젠타 배경 원본의 정책은 보존한다. 원본의 칠해진 부분이 alpha 253인 경우 기록된 임계값 250 이상만 255로 복구한다. 흰색 밝기나 분홍색 자체를 투명도 기준으로 삼지 않는다.

캐릭터 시트는 1024² WebP, 셀은 512²다. 신규 7개 PNG 9,206,086 bytes를 1,461,334 bytes WebP로 전처리했다(84.1% 감소). 원본 PNG는 개발 입력으로 보관하고 게임에는 WebP만 포함한다. 원본·출력 해시와 프롬프트는 `GENERATION_LOG.json`, `AUX_GENERATION_LOG.json`, units/manifest.json, `ATLAS_PACKING.json`을 함께 확인한다.

효과는 검정 바탕의 4×3 비트맵을 screen 합성한다. 필살기 생성본은 세 행이 완벽히 같은 높이가 아니므로 **실제 행 간 여백**을 기준으로 분할한다. 셀 안의 효과 전체를 균일 비율로 맞추고 최소 16px 검정 여백을 둔다. 유물에는 최소 26px 알파 여백을 둔다. 인접 칸 그림이 섞이지 않는 회귀 검사가 있다. 이것은 캐릭터 전신 fit과 다르며, 머리 정규화에는 적용하지 않는다.

## 다음 작업에서의 절차

1. `Downloads/캐릭터`의 원본과 설정으로 성별·눈·머리·옷·손잡이·부속물 계약을 먼저 적는다.
2. 기존 고정 그림체 시트, 구조/비율 기준, 캐릭터 정체성 참고를 나누어 이미지 도구에 준다. 최근 생성본을 연달아 스타일 기준으로 삼지 않는다.
3. 네 방향 중립 자세를 한 시트로 제작한다. 진짜 좌/우 방향이며 반전 복제하지 않는다. 몸이 길면 턱 아래 몸을 다시 그리는 편집을 한다.
4. 원본을 눈으로 본 뒤 해부 좌표와 SHA를 기록한다. 실루엣 bounds는 잘림 검출에만 사용한다. 머리·몸의 내부 비율은 리사이즈로 수선하지 않는다.
5. 패킹한 그림을 기존 전체와 같은 발 기준·같은 크기로 비교한다. 정면만 통과시키지 않는다. 실제 알파, 불투명 의상, 소품, 좌우 손잡이, 64px에서 얼굴 인지까지 확인한다.
6. 런타임에 포함하고 25칸/보스/경고/HP/일반 및 줄인 효과 모드에서 본다. 같은 그림을 잘못된 칸으로 자르거나 잘못된 인물로 표시하는 문제도 별도 확인한다.

```powershell
node defense/tools/pack-celestial-units.mjs SOURCE_DIRECTORY
node defense/tools/pack-celestial-atlases.mjs SOURCE_DIRECTORY
node defense/tools/build-celestial-review.mjs
node scripts/export_defense_directions.mjs OUTPUT_DIRECTORY
npm run prepare:defense-art
npm run verify:plan
npm run verify -- --only defense
node defense/tools/check-celestial-browser.mjs
```

선택된 원본의 내용이 바뀌면 기존 좌표를 재사용하지 않는다. 검토용 PNG/갤러리는 빌드에 포함하지 않는다. 실제 기기의 터치·발열·메모리·Safari 성능과 플레이 재미는 데스크톱 Chromium 검사로 인증하지 않는다.

- [Scenario의 캐릭터 일관성 가이드](https://help.scenario.com/articles/4280773511-train-a-consistent-character-model): 고정 정체성과 가변 방향·표정의 분리, 동일 조건 비교 원칙을 참고했다. Scenario 학습이나 ControlNet을 실행했다고 주장하지 않는다.
- [Riot의 Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/): 큰 기술의 시각적 우선순위, 투사체 자체의 진행 방향, 실제 판정과 표현 일치, 정체성을 보존하는 변신을 참고했다. 이번 신규 단일 표적은 전장 전체가 아니라 표적 주위에 대비를 집중한다.

외부 게임 그림/소스는 복사하지 않았다. 그림은 사용자 캐릭터 참고와 내장 이미지 생성/편집으로 제작했다.
