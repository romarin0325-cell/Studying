# 별빛 정원 캐스트 비교

저장소 루트에서 `node defense/docs/art/cast-comparison/build.mjs`를 실행한다. `defense/test-results/cast-comparison/index.html`을 브라우저로 열면 된다. 명령 뒤에 출력 HTML 경로를 하나 지정할 수 있다. 만들어진 HTML에는 이미지와 UI가 포함되어 있어 오프라인으로 열린다.

- **전체 캐스트**에서 모든 동료와 변신을 같은 크기로 본다. 방향, 배경, 등급, 검색, 전신과 초상화를 전환한다.
- **5×5 배치**에서 동료를 골라 칸에 놓는다. 보드의 한 칸을 선택한 뒤 다른 칸을 누르면 이동하거나 자리를 바꾼다. 전장의 셀 간격과 대기 스프라이트 배율을 사용한다.
- **상하좌우**에서 배치한 동료 또는 전체 캐스트의 네 방향을 한 줄씩 펼친다. 정면 대비 측면 윤곽 높이 차이로 정렬할 수 있다.

캐릭터 목록은 빌드 시점의 `HEROES`와 `TRANSFORM_ART`에서 가져온다. 전신은 게임 내장 아틀라스, 초상화는 준비된 게임 파일을 사용한다. 트라우마처럼 전용 UI 초상화가 없는 변신은 전신을 비교할 수 있다. 배치와 표시 설정은 주소에 남는다.

윤곽 높이는 512px 원본 셀의 알파 40 이상 픽셀을 잰다. 머리카락, 모자, 장비를 포함하므로 방향별 차이가 큰 그림을 찾는 용도로 쓴다. 해부학적 머리·키 판정에는 가려진 두개골, 턱, 발과 실제 실루엣을 함께 본다.
