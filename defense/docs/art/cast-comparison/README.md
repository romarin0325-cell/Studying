# 별빛 정원 캐스트 비교

저장소 루트에서 `node defense/docs/art/cast-comparison/build.mjs`를 실행한다. `defense/test-results/cast-comparison/index.html`을 브라우저로 열면 된다. 명령 뒤에 출력 HTML 경로를 하나 지정할 수 있다. 만들어진 HTML에는 이미지와 UI가 포함되어 있어 오프라인으로 열린다.

- **전체 캐스트**에서 모든 동료와 변신을 같은 크기로 본다. 방향, 배경, 등급, 검색, 전신과 초상화를 전환한다.
- **5×5 배치**에서 동료를 골라 칸에 놓는다. 보드의 한 칸을 선택한 뒤 다른 칸을 누르면 이동하거나 자리를 바꾼다. 전장의 셀 간격과 대기 스프라이트 배율을 사용한다.
- **상하좌우**에서 배치한 동료 또는 전체 캐스트의 네 방향을 한 줄씩 펼친다. 정면 대비 측면 윤곽 높이 차이로 정렬할 수 있다.
- **배율 판정**에서 좌우에 공통 배율을 가상 적용한다. `상하좌우`의 동료별 버튼으로 바로 열 수 있다. 머리 높이, 턱~발, 겉윤곽을 맞춘 시안과 직접 입력한 배율을 비교한다. 네 방향의 발선과 중심선을 함께 두고, 셀 경계를 넘으면 잘림을 표시한다.

캐릭터 목록은 빌드 시점의 `HEROES`와 `TRANSFORM_ART`에서 가져온다. 전신은 게임 내장 아틀라스, 초상화는 준비된 게임 파일을 사용한다. 트라우마처럼 전용 UI 초상화가 없는 변신은 전신을 비교할 수 있다. 배치와 표시 설정은 주소에 남는다.

윤곽 높이는 512px 원본 셀의 알파 40 이상 픽셀을 잰다. 머리카락, 모자, 장비를 포함하므로 방향별 차이가 큰 그림을 찾는 용도로 쓴다. 해부학적 머리·키 판정에는 가려진 두개골, 턱, 발과 실제 실루엣을 함께 본다.

## 배율 판정 기준

정면을 목표로 둔다. 두개골 높이와 꼭대기, 턱~발을 비교하고, 측면 두개골 폭은 공통 SD 기준인 정면 폭의 90%와 비교한다. 눈·어깨·골반이 다시 표시된 동료는 해당 기준점도 쓴다. [수동 기준점](visible-landmarks.json)은 측면 편차가 컸던 9종의 현재 원본 해시와 연결되어 있다. 보존 기준점 역시 같은 원본 해시일 때 읽는다. 가려진 뒤쪽 눈과 턱은 판정에서 제외한다.

좌우의 각 기준점이 ±8px 안에 들어오는 확대 배율 구간의 교집합을 구한다. 512px 원본에서 8px는 64px 표시에서 1px다. 겉윤곽까지 포함한 구간은 따로 계산하며, 두 계산 모두 발 기준과 셀 경계를 적용한다. 후면은 원본 배율로 별도 대조한다. 한 구간에서 함께 맞지 않으면 어떤 항목이 다른 배율을 요구하는지 수치와 그림으로 확인한다.

배율은 검토 화면에만 적용된다. 통과는 기록된 2D 기준점에서의 후보 판정이다. 수동 추정점의 오차, 자세, 장식과 장비의 가림 관계는 네 방향에서 직접 대조한다. 예를 들어 세이렌은 겉윤곽만 맞출 때 좌우 약 115.6%가 필요하고, 두개골 높이만 맞출 때는 약 104.6%가 필요하다.
