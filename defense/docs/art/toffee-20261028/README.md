# 토피애플 · 날렵한 실루엣 적용 · 2026-10-28

사용자가 로컬 비교에서 선택한 `lean-candidate-v1-20261028`을 최신 main `ca55cb08aec555b9f1b46b87677175fda9384f07`에 적용한다. 같은 후보를 다시 생성하거나 비율을 재해석하지 않았다. SD 네 방향과 그로부터 만든 초상화·전신만 변경하며, 메모리얼·공격/필살기 이펙트·밸런스는 이 변경의 대상이 아니다.

## 제작과 원화 보존

기존 SD는 둥글고 넓은 양갈래, 풍성한 소매, 옆으로 퍼진 하의가 겹쳐 코르셋과 허리선을 가렸다. 새 후보는 머리카락 끝과 소매·하의 외곽을 정돈하고 허리와 발목이 더 잘 읽히게 했다. 원화의 적갈색/버건디 머리와 구리빛 끝, 검은 리본, 비대칭 나비·하트/안전핀 장식, 붉은 광택 의상과 검정 코르셋, 벨트·금속 장식, 비대칭 스타킹, 오른손의 사탕 사과를 보존한다. 원화의 무거운 윗눈매와 비뚠 웃음을 참고했다.

기존 공통 프롬프트, 동결된 세이렌 화풍 참조, 실제 토피애플용 여성형·보통 키 3D 구조 가이드, 사용자 원화, 이전 승인본을 내장 `image_gen`의 실제 입력으로 사용했다. 생성 도구가 상세 모델 버전을 반환하지 않아 버전 이름을 추정하지 않는다.

- `generation.png`: 실제 반환된 1254×1254 RGBA 생성 원본.
- `prompt.txt`, `common-prompt.txt`, `inputs.json`: 실제 프롬프트와 생성 전 입력 순서·역할·SHA-256. 원래의 미적용 후보 제작 기록을 소급 수정하지 않는다.
- `references/original.jpg`, `references/mannequin.png`: 사용자 원화와 실제 사용한 구조 가이드. 동결 화풍은 `../sol-cast-v2/structure-masters/style-siren.webp`, 이전 승인본은 `../../../assets/cast-v2/toffee_apple.png`에 보존한다.
- `landmarks.json`, `segmentation.json`, `packing.json`: 수동 두개골·턱·발 좌표, 알파 정리와 연결 성분 분리, 네 방향 공통 등방 배율·발 기준선·클리핑 검사. 두개골에 머리카락·리본·핀을 포함하지 않는다.
- `before-metadata.json`: 실제 교체 전 이미지의 과거 좌표와 해시. 현재 좌표를 과거 이미지에 대입하지 않는다.
- `deployment.json`: 사용자의 적용 선택, 설치 경로·해시, 배포 압축본, 참조 보관 경로.

## 비율에서 실제로 달라진 점

512px 셀의 정면 두개골 추정은 기존 약 161.5×148.6px, 후보 약 160.9×149.2px다. 같은 면적으로 정규화한 것이므로 숫자 자체를 해부학적 동치의 독립 증거로 부르지 않는다. 기존 동료와 같은 표시 크기로 얼굴을 따로 확인했다.

머리카락·장식을 포함한 정면 상부 외곽 폭은 327→298px(약 8.9% 감소)이다. 이것은 머리카락 실루엣이며 두개골 측정값이 아니다. 턱 아래 길이는 179→188px로 약 5% 길어졌다. 이 체형 차이도 후보의 일부이며, 보통 키 구조 가이드의 188px 목표에 가까워졌다. 방향별 배율 변경이나 가로·세로 왜곡은 없다.

가려진 두개골·턱은 수동 추정이다. 원본 기준 정면·측면 ±18px, 후면 ±26px, 발 ±5px의 경계 불확실성을 기록했다. 통계적 신뢰구간이나 리깅된 3D 캐릭터의 완벽한 회전 연속성을 뜻하지 않는다.

## 배포와 UI

`assets/cast-v2/toffee-apple-lean.png`(727,808B)와 q95 WebP(206,170B)는 사용자가 본 후보와 SHA-256이 같다. 이전 `toffee_apple.png/.webp`와 기존 압축본은 보존한다. 전투용은 새 원본에서 한 번 축소한 640×640 q90 WebP(76,520B)로, 원본 WebP보다 약 62.9% 작다. FPS 향상 수치로 해석하지 않는다.

해부학적 초상화 중심을 (251,217)로 갱신하고 크기 250과 기존 시각적 x−7px 미세 보정을 유지한다. 준비된 240px 초상화와 512px 전신은 원본에서 다시 만들며, 다른 UI 파생본 154개는 재사용한다. 정식 일반판과 Bright 통합 HTML에 동일한 후보가 들어간다.
