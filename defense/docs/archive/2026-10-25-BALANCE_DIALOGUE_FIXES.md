# 감속·치명타 가격·베히모스 소환과 대사 수정 (2026-10-25)

## 감속 강화 배율

어비스윙 공격에서 `25% × 성급 제어 × 강화 특수`를 공통 감속 처리에 넘겼는데, 공통 처리도 강화 특수를 곱하고 있었다. 호출부에서는 `25% × 성급 제어`만 넘겨 강화 배율을 한 번 적용한다. 예를 들어 1성·강화 +10(특수 1.2)은 실제 감속과 설명 모두 30%이며, 3성은 36%다. 기존 80% 상한은 유지한다. 전투 요약에도 현재 성급/강화의 감속률을 표시한다.

## 치명타 화단 가격 연결

이전 구현은 30레벨에서 곧바로 절반 가격으로 전환해 `20,424 → 9,533`으로 역전됐다. 20% 확률까지 30단계·총 140,904 별가루는 유지한다. 30~41레벨의 12개 가격 구간을 **로그 가격의 smoothstep 보간**으로 이어, 이전 구간의 가격과 기존 할인 꼬리 곡선을 연결했다. 이후에는 원래 의도한 `이전 대응 가격 / 2`와 정확히 같다. 효과는 계속 단계당 +0.5%p다.

| 현재 화단 레벨 → 다음 레벨 | 다음 비용 | 기존 할인 꼬리 가격 |
|---|---:|---:|
| 28 → 29 | 17,259 | - |
| 29 → 30 | 20,424 | - |
| 30 → 31 | 23,075 | 9,533 |
| 31 → 32 | 26,364 | 11,440 |
| 35 → 36 | 37,234 | 23,721 |
| 40 → 41 | 60,082 | 59,025 |
| 41 → 42 | 70,830 | 70,830 |
| 42 → 43 | 84,996 | 84,996 |

따라서 후반의 +1%p는 두 단계의 합계로도 이전 할인 곡선과 같다. 예를 들어 41→43은 155,826이다. 연결 구간만 추가 비용이 생기며 기존 투자 레벨/별가루를 초기화하거나 소급 청구하지 않는다. 0~249레벨에서 가격 역전이 없는지와 연결 이후의 정확한 대응 가격을 검사했다.

## 베히모스

사용자의 "베놈처럼 45 클리어 후 정규 소환"을 같은 획득 규칙으로 해석했다. 베히모스를 정규 UR 풀에 넣고 `LATE_COMPANIONS`의 45 클리어 조건을 유지한다. 시즌 전용 목록에서 빼 원래 여섯 수호자의 순환으로 돌아간다. 2026년 10~12월은 기존과 같고, 2027년 1월은 시간의지배자다. 시즌 소환의 일반 UR 부분에서도 다른 정규 UR과 같은 규칙을 따른다.

임시였던 45 클리어 확정 지급은 종료한다. 이미 보유한 개체·중복·강화·호감도는 그대로 보존한다. 전투 수치나 오라 효과는 바꾸지 않았다. 정규 풀의 획득 후보가 되는 것과 첫 클리어 때 확정 지급되는 것을 구분해 안내/연출도 맞췄다.

## 사용자 문구

[첨부에서 추출한 적용 문구](2026-10-25-DIALOGUE_REQUEST.json)에 원본 첨부 해시와 대상별 수정안을 보존했다. 9명의 소환·터치·친밀·인사·선호/일반 선물 **71개**를 정확히 대조했다. 미지정 대사는 유지한다. 베놈의 선호 선물 데이터는 원래 사탕이었고, 꽃 대사였던 응답을 사탕 대사로 고쳤다.

메모리얼 9편의 제목/본문을 교체하고 둠의 "플레이어"는 조사까지 맞춰 "당신"으로, 레드드래곤의 "마, 마시쩡!!"은 "마, 맛있잖아?!"로 바꿨다. 그림은 교체하지 않았다. 11편 모두 기존 문단 수를 유지해 저장된 읽기 진도가 범위를 벗어나지 않게 했으며, 본문 해시를 함께 갱신했다. 새 본문의 문단 구분 외 단어·문장은 첨부와 일치한다.

루미의 오답 해설 PERSONA를 첨부 전문으로 교체했다. 호칭·높은 텐션·행동 지문·비유·정확성/불확실성 규칙·원어 병기·여섯 출력 제목을 모두 포함하고 과목명은 실행 시 `COURSE.subject`를 넣는다. 실제 요청의 `systemInstruction`에 이 전문이 들어가는지 fetch 모의 응답으로 검사했다. 실제 API 키나 유료 모델 호출은 사용하지 않았다.

기존 48자 제한보다 긴 사용자 대사도 줄이지 않고 표시한다. 로비 말풍선은 줄바꿈으로 확장되며, 390×844 두 테마에서 긴 대사와 새 메모리얼을 확인했다. 기존 아틀라스/메모리얼/초상화 바이트는 보존하고 캐릭터 목록 순서가 바뀐 준비 매니페스트만 기존 해시 검증 후 재정렬했다. 이미지 인코딩은 0회다.

## 확인 범위

관련 검사36개(감속·가격·저장·소환·문구/메모리얼·API 요청), 첨부 문구71개/새 본문9편의 독립 대조와 둠·레드드래곤/베놈 사탕 수정 확인을 통과했다. 감속은 실제 투사체가 적중한 결과를 기본/강화/성급/80%상한에서 검사했다. API는 실제 `systemInstruction` 전문과 과목명 치환을 모의 fetch에서 확인했다. 긴 본문에도 기존 읽기 문단 수와 본문 해시가 유효하다.

정식 어두운판·Bright와 전체 해금 테스트판 두 스킨을 빌드했다. [모바일 검수](../review/balance-dialogue/README.md)의8개 시나리오에서 긴 선물 대사, 소환 안내, 최장 본문/제목의 메모리얼과 끝까지 읽기 저장을 확인했다. 페이지 오류·외부 요청·이미지 실패·가로 넘침은0이다. 변경하지 않은 게임이나 장시간 전투 시뮬레이션, 실기기 FPS, 실제 유료 API 응답은 검사하지 않았다.
