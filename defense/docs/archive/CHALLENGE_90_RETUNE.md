# 주간·월간 난이도 재조정 (2026-10-24)

스토리가 90스테이지까지 늘었다. 주간 드래프트와 월간 보스전의 쉬움·어려움·심연을 그 길이에 맞춰 다시 맞췄다. 보상 식의 모양은 그대로 두고 배율만 바꿨다.

## 1. 정한 것

|---|---:|---:|---:|
| 해금 스테이지 | 3 | 36 | 72 |

옛 설계(해금 3/18/36, 앵커 12/26/42)를 스테이지 수에 비례해 두 배로 늘렸다. 체력 곡선의 시작은 4 / 28 / 56으로 두고, 끝값·후반 가산·월간 보스 계수만 목표에 맞게 움직였다. 평균 웨이브는 난이도가 올라갈수록 줄어들게 했다.

## 2. 플레이어 모델

온실 위력은 장미 45에서 멈춘다. 앵커 G의 영웅 위력 P(G)는, 그 덱이 메인 스테이지 G를 75% 깨는 가장 작은 배율이다. 로그 이분법은 `scripts/power-need.mjs`와 같다. 봄·씨앗은 `bedsFor(G)`이고 상한은 stage-sim과 같다. 치명타는 G≤45면 없고, 46–70은 13% / 180%, 71 이상은 20% / 200%이다. 도전은 그 P(G)와 치명타로 돌린다.

덱은 기존 5종에 후반 동료 3종을 더했다. 여덟 덱 모두 `validDeck`을 통과한다. 덱마다 시드 4개라 난이도당 32판이다. 비율의 표준오차는 약 8%p다. 목표와 10%p 안이면 더 맞추지 않았다. P(G)는 난이도와 무관해서 한 번 구해 재사용했다. 구현은 `scripts/challenge-sim.mjs`의 `--anchors`, `--target`, `--load-powers`다. `--growth`는 예전 온실 벤치 그대로다.

## 3. 모델 확인

옛 `TIERS`, 앵커 12/26/42, 덱 8종, 시드 4.

| | 쉬움 | 어려움 | 심연 |
|---|---|---|---|
| 주간 | 30/32 = 94% (17.9) | 29/32 = 91% (17.9) | 6/32 = 19% (16.8) |
| 월간 | 0/32 = 0% (12.2) | 1/32 = 3% (15.5) | 0/32 = 0% (14.3) |

2026-10-11 기록은 주간 60% / 47% / 25% (17.6 / 16.4 / 14.1), 월간 50% / 45% / 약 25–50% (15.7 / 15.3 / 15.4)다. 이번 모델은 주간 심연만 그 기록에 가깝다. P(G)가 온실 배율보다 커서 주간 쉬움·어려움은 훨씬 쉽다. 월간은 거의 깨지 않는다.

같은 엔진으로 옛 방법(온실, 덱 5종, 성장 12/26/42)을 다시 재면 주간 15/20 = 75% / 20% / 10% (17.8 / 15.9 / 13.3), 월간 0% / 0% / 0% (11.0 / 11.3 / 10.4)다. 그 사이 전투가 바뀌어 그날 표가 재현되지 않는다. 새 곡선은 지정한 P(G) 모델로 맞췄다.

## 4. 최종 난이도

처음 곡선(끝값 26/58/94, 후반 +120/200/340%, 월간 1.3/0.57/0.39)은 주간 97/53/13, 월간 0/0/0이었다. 끝값을 34/62/86, 후반을 +160/220/300%로 올리니 주간이 69/50/19가 됐다. 월간 계수는 0.20/0.20/0.23에서 목표가 맞았다.

주간 보스 배율은 그대로 뒀다. 1.15를 1.25로 올리면 어려움 완주가 50%에서 28%로 떨어졌다. 쉬움은 1.0을 1.2로 올려도 69%에서 66%로 거의 안 움직였다.

스테이지 3 플레이어(온실, 덱 5종, 시드 4, 주간 쉬움)는 4/20 = 20%를 완주하고 평균 15.7웨이브, 가장 짧은 판이 11웨이브다. 앞 웨이브는 넘긴다. `from` 4는 유지했다.

1–18웨이브의 체력 예산은 주간·월간 모두 쉬움 < 어려움 < 심연이다.

## 6. 보상

식은 그대로다.

- 주간: `round((100 + 25 × 웨이브 + 완주 100) × reward)`
- 월간: `round((100 + 35 × 격파 + 18격파 150) × reward)`

꿈의결정 하루 수입은 코드 기준으로 이렇게 더했다. 하루 1스테이지를 연다. 첫 클리어는 `160 + 10 × 스테이지`, 첫 퍼펙트는 100, 일일 임무는 60+30+30과 `dailyBonus` 30으로 150이다. 파견은 기본 덱 5명의 평균 전투력으로 `floor(기본 × 0.3)`을 슬롯 수(`min(4, floor(클리어 / 9))`)만큼 하루 한 번 받는다. 방치 보상은 별가루뿐이라 넣지 않았다. 인사 +40은 넣지 않았다. 주는 7일, 달은 30일이다.

## 7. 확인하지 않은 것

- 브라우저에서 모드 카드를 눌러 보지 않았다.
- `defense/dist`는 다시 만들지 않았다. `optimize-images.mjs`도 돌리지 않았다.
- 인사 +40을 수입에 넣으면 심연 배율만 3.4에서 3.3이 된다. `dawn-pacing.mjs`의 기본 속도는 하루 0.5스테이지다. 그 속도로 계산하면 어려움 2.4, 심연 3.3이다. 이번 배율은 요청한 하루 1스테이지 기준이다.
- 파견 영웅을 기본 덱의 최대 전투력으로 바꾸면 어려움만 2.4가 된다. 평균과 최소는 2.3이다.
- 시드 4개라 완주율은 약 8%p 흔들린다. 평균 웨이브가 17 근처에 붙는 것은 마지막 웨이브에서 갈리기 때문이다.
