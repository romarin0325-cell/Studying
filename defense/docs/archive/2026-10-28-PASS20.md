# 20차: 라그나로크·애쉬·루나·원형 평타 크기·필살기 이름·컷인 설정·유물 확률 (2026-10-28)

## 판단 기준

- 평타는 가디언·베히모스 수준으로 조용하게 둔다. 지크 평타는 그보다 조금만 존재감을 올리고, 광폭 화염검보다는 확실히 덜 화려하게 둔다.
- 원형 평타의 보이는 바깥 가장자리는 실제 판정 반경 안쪽(0.95~1.03배)에서 끝낸다. 적은 발 위치로 판정하므로, 반경을 넘는 그림은 맞지 않은 적까지 맞은 것처럼 보이게 한다.
- 화려한 그림은 필살기에만 쓴다. 보드 위 배지는 다른 배지와 같은 평면 기호로 둔다.

## 1. 로비 상세의 강화 수치 색

로비 동료 상세의 필살기·특성 문단(`.hd-skill`)에는 강화 수치 색 규칙이 없어 숫자가 기울임체로만 보였다. Bright에서는 고정된 밤 테마 민트색이 종이 위에서 묻혔다. 이제 모든 화면의 `em.scaled`가 테마 청록(`--teal`)·굵게로 같고, "색으로 표시된 수치" 안내 문구도 같은 색이라 범례로 읽힌다.

## 2. 이펙트

비교 페이지는 [review/pass20-vfx](../review/pass20-vfx/index.html)다. 같은 엔진 이벤트를 main 렌더러와 이번 렌더러로 나란히 재생하고, 판정 반경 점선과 필살기 컷인 띠(게임의 DOM 띠를 같은 크기·시간으로 흉내 냄)를 켜고 끌 수 있다. 새 그림은 GPT 이미지로 그렸고, 프롬프트·원본·자르기 기록은 [art/pass20-fx-20261028](../art/pass20-fx-20261028/)에 있다.

## 3. 이름과 대사

- 지크 필살기: 용의 맹세 → 라그나로크. 효과 문구는 그대로다.
- 큐어마스터 필살기: 퍼스트키스 → 레몬 배리어. 전체 기절·저주 해제와 4초 무적(보호)이라는 효과, 하트 속 레몬 문장, 레모네이드 콘셉트에 맞췄다.
- 여왕 합류 대사: "짐의 정원에 들이도록 하지"는 정원의 주인과 들이는 주체가 모호했다. "좋다, 그대의 정원에 짐의 장미를 피워 주지."로 정원은 플레이어의 것, 여왕은 장미를 피워 주는 쪽으로 정리했다. 같은 이유로 인사 "짐의 정원은 오늘도 피어 있다"도 "짐의 장미는 오늘도 피어 있다"로 바꿨다.

## 4. 규칙·설정·화면

- 아스테아: 살아 있는 아스테아 주변 180 이내의 적은 즉사하지 않는다(폭풍의현자 즉사 판정 자체를 굴리지 않는다). 범위 표시는 없다.
- 설정 → 필살기 컷인 켜기/끄기. 끄면 이름 띠와 UR 슬로모션이 나오지 않는다(위쪽 길의 적을 가리는 문제). 기존 저장은 켜짐으로 옮긴다.
- 테스트 빌드 도구: 주간 드래프트 초기화(진행 중인 주간 원정도 정리), 월간 보스전 초기화(이번 달 기록·확정 보상 삭제, 역대 기록 유지).
- 유물 소환 확률: 지금 단계부터 세 단계 뒤까지와 한계값을 사다리로 보여 준다. 지금 단계에서 다음 단계로 가는 선이 진행도만큼 채워진다. 확률 식은 그대로다.
- 드래프트 화면 상단 제목: "주간 드래프트"가 두 줄로 잘려 "드래프트"로 줄였다(본문 제목은 그대로).

## 확인하지 않은 것

실제 기기 성능, 동료가 5×5로 가득 찬 보드에서의 라그나로크, 여러 애쉬 환원이 겹치는 경우.
