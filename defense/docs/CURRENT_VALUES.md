# 현재 수치 (자동 생성)

> 이 파일은 `node defense/scripts/generated-reports.mjs`가 코드에서 만든다. 직접 고치지 말고, 숫자가 이 파일과 다른 문서는 그날의 기록으로 읽는다. 코드와 다르면 테스트가 실패한다.

## 규칙

- **필살기 피해:** 필살기는 시전 순간 동료 정보에 보이는 공격력(`combatStats().damage`)에 배율을 곱한다. 골드드래곤은 5초 차지가 끝난 발사 순간에 계산한다. 성급·훈련·강화·온실·수집 보너스에 더해 배치 오라, 켜져 있는 필살기 버프, 유물 공격력 보너스가 모두 들어간다. 같은 종류 안에서는 가장 센 것 하나(유물은 합산)이고 종류끼리는 곱한다. 그 시전이 거는 버프·노출은 그 시전의 피해에 들어가지 않는다.
- **받는 피해 증가 효과(노출, 확대경, 왕의 인장 등):** 위와 별개로 적에게 걸려 필살기와 일반 공격 모두에 적용된다.
- **메인 스테이지:** 90개. 제1부 「달빛의 별길」, 제2부 「새벽의 별길」 각 45개(5개 장 × 9). 적 체력은 두 부 모두 같은 기울기로 이어진다. 제2부는 스테이지 45를 클리어하면 열린다.
- **스테이지 45 첫 클리어:** 제2부와 새벽 온실이 열리고 베히모스·베놈 등 신규 동료가 정규 소환 풀에 합류한다. 동료를 확정 지급하지 않으며 기존 보유 개체는 유지한다.
- **퍼펙트 클리어:** 코어 체력을 잃지 않고 메인 스테이지를 클리어하면 퍼펙트. 스테이지마다 첫 퍼펙트에 꿈의결정 100.
- **일반 소환 UR(9명):** 지크, 루나, 자스민, 여왕, 루미, 체리프린스, 베놈, 베히모스, 골드드래곤. 픽업은 초기 정규 UR 6명을 매주 월요일(UTC+9) 순서대로 순환한다. 베놈·베히모스·골드드래곤은45클리어 후 일반 풀에 합류한다.
- **이달의 수호자(히든 6명, 시즌 소환에서만):** 시간의지배자 → 은하고래 → 둠 → 신데렐라 → 하모니어스 → 혹한의마녀 순서로 월마다 한 명. 월 번호는 (연도×12+월 인덱스) % 6이고 지금 2026년 10월은 신데렐라, 2027년 1월은 시간의지배자.
- **소환 확률:** C/R/SR/UR = 70% / 25% / 4.8% / 0.2%, 천장 200/200.

## 이번 성장 규칙

성급 보너스는 1성을 기준으로 `1 + 0.1 × (성급 - 1)`이다. 강화 5단계마다의 기존 특수 배율과는 곱하며, 감속률의 공통 상한은 80%다.

| 동료 | 현재 성장 |
|---|---|
| 눈토끼 훈련 | 기본 35%에서 훈련마다 +2%p. 0~5회는 35% / 37% / 39% / 41% / 43% / 45% (1성·강화 없음) |
| 눈토끼 필살기 | 빙결 2초와 감속 50%가 성급당 +10%. 감속 지속은 6초 유지 |
| 폭풍의현자 | 즉사율 1% + (성급 - 1) × 0.1%p + 강화 5단계 횟수 × 0.1%p. 훈련은 즉사율을 늘리지 않음 |
| 혹한의마녀 필살기 | 감속 50%와 겨울 6초가 성급당 +10%. 감속·노출·겨울 종료는 동일. 처치 시 후속 빙결 0.8초 고정 |
| 베히모스 훈련 | 반경 112.5 / 118.125 / 123.75 / 129.375 / 135 / 140.625. 시전 순간 값이 충격 3회와 저장에 유지됨 |

## 미라클 개체의 형태

네 형태는 슈퍼레어 미라클라바 한 수집 슬롯을 공유한다. 소환은 라바, 같은 성급의 형태 간 합성·루미 합성은 코쿤이다. 성급·훈련·강화는 공통이며 형태는 개체마다 저장한다. 미라클윙의 오라는 자신을 제외한 상하좌우에 적용하고 같은 종류는 가장 큰 값 하나만 쓴다. 1성 +20%p에 성급 지원 배율과 강화 특수 배율을 적용한다.
