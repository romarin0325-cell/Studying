## 출처와 만료 시각

저장 버전 `VERSION=2`와 `balanceRevision=3`은 유지하고, 상태 효과 배열이 존재함을 구분하는 `statusRevision=1`을 추가한다. 각 적은 다음 원자료를 가진다.

```js
statusEffects: [
  {type:'poison',source:'skill:phantom:42',owner:'phantom',amount:4,power:19,until:12},
  {type:'exposure',source:'skill:great_detective:43',owner:'great_detective',amount:.6,until:10},
  {type:'freeze',source:'skill:snow_rabbit:44',owner:'snow_rabbit',amount:1,until:3},
],
slowEffects: [{source:'zone:time_ruler:45',owner:'time_ruler',amount:.25,until:2.4}]
```

`until`은 저장 가능한 전투 절대시각이다. `owner`는 피해 기여를 귀속할 영웅 ID이고, `source`는 효과를 적용한 공격·필살기·장판을 구별한다. `attack`의 번호는 투사체 UID, `skill`의 번호는 해당 시전에서 발급한 UID, `zone`은 각 장판 UID, `merge`는 새 합성 유닛 UID이다. 보스 시전 중단은 `interrupt:<boss>:<enemy UID>`이며 영웅 소유자가 없다. 실제 적용 인스턴스가 다르면 같은 영웅도 독립 출처가 된다. 장판의 반복 주기만 자기 장판 출처를 갱신한다.

`poison`, `burn`, `burnOwner`, `exposed`, `divine`, `frostStacks`, 각 남은 시간은 배열에서 다시 계산하는 표시용 값이다. 만료된 화상의 수치와 소유자는 즉시 `0/null`로 지우므로 새 약한 화염이 끝난 강한 화상을 되살릴 수 없다. `stun`은 기절만, `freeze`는 빙결만, `controlTime=max(stun,freeze)`은 실제 이동 정지 시간을 나타낸다.

같은 프레임 안에서 효과가 끝나면 해당 종료 시각을 경계로 프레임을 나누어 DOT·피해 증가·정지·감속을 계산한다. 예를 들어 0.05초 프레임 중 강한 화상이 0.025초에서 끝나면 처음 0.025초만 강한 피해를 내고 나머지는 살아 있는 약한 화상을 사용한다. 보스의 광역 돌진은 다른 적의 종료 시각을 조회만 하며, 뒤에 처리될 적의 마지막 DOT 구간을 먼저 삭제하지 않는다. `1e-9`초 이하는 부동소수 오차를 위한 만료 허용값이다.

## 효과별 중첩 규칙

| 효과 | 실제 적용 | 보관·만료 원칙 |
| --- | --- | --- |
| 노출 | 살아 있는 수치 중 최댓값 | 강한 궁극기의 시각을 약한 평타나 다른 궁극기가 연장하거나 단축하지 않는다. 강한 노출이 끝나면 아직 살아 있는 약한 노출로 전환한다. |
| 감속 | 살아 있는 수치 중 최댓값, 최대80% | 공격·필살기·각 장판의 시각을 별도로 유지한다. 동률은 가장 늦은 종료 시각을 표시한다. |
| 화상 | 살아 있는 초당 피해 중 최댓값 | 선택된 출처의 소유자에게 실제 HP·실드 피해를 귀속한다. 동률에서는 더 오래 남는 출처를 선택한다. 약한 화상은 살아 있는 경우에만 나중에 전환될 수 있다. |
| 기절·빙결 | 각 종류의 가장 늦은 종료 시각, 실제 정지는 두 값의 최댓값 | 제어 시간은 합산하지 않는다. 짧은 기절은 긴 빙결을 덮지 않는다. 메이드 궁극기의 제어 대상 조건은 두 종류를 모두 읽는다. |
| 성광 | 최대3중첩, 중첩당 받는 피해+2%, 최대+6% | 각 적용은6초. 새 적용이 상한을 넘으면 더 늦게 끝나는 중첩을 남긴다. 여신강림도3중첩·6초이다. |
| 서리 | 세 번째 살아 있는 중첩에서 서리 파쇄 | 대기 중에는 최대2중첩을 보관한다. 각 적용이 독립 만료한다. 세 번째 타격은 기존 중첩을 소모하고1.2배 추가 피해와 별도 빙결을 적용한다. |
| 독 | 유효 출처의 위력 상위40스택만 실제 피해 적용 | 각 출처의 원래 스택·위력·시각을 보관한다. 초과 출처는 억제하며 자신의 종료 시각이 되기 전에만 다시 유효할 수 있다. |

독의 원자료 합계와 현재 적용 중첩 수는 다르다. 강한 짧은 독을 더했을 때 기존 장기 독 출처를 삭제하면, 강한 독이 끝난 뒤 원래 남아 있어야 할 궁극기 독까지 사라진다. 따라서 원자료를 지우지 않고 **현재 적용 스택만40**으로 제한한다. 현재 유효 출처를 `power 내림차순 → until 내림차순 → source 순`으로 선택한다. 이 방식은 약한 독 추가가 현재 독 DPS를 낮추지 않으며, 강한 짧은 평타도 장기 궁극기 출처의 잔여 시간을 없애지 않는다. 억제된 출처가 만료되면 함께 제거된다. 각 출처 자체도 최대40스택이고 유효 원자료 배열 길이에는 복원 검증 한도가 있다.

## 공통 독과 피해 공식

독의 기본 DPS는 다음과 같다.

```text
출처별 독 DPS = 이번 선택에서 활성화된 스택 × 출처의 스냅샷 공격력 × (3 / 11)
총 독 DPS = 선택된 모든 출처별 DPS 합계, 활성 스택 합계 ≤ 40
```

`11`은 현재 머쉬룸킹의 기본 공격력이다. 이 기준에서1성 기본 머쉬룸킹의 한 독 스택은 기존과 동일한 초당3 피해를 준다. 이전의 `meta.mushroom_king.power`만 읽는 전용 식을 없애고, 공격·장판·궁극기마다 실제 출처의 이미 계산된 공격력을 보관한다. 따라서 전투 성급, 지속 성장, 훈련, 유물 공격력, 개인 위력이 독에도 한 번 반영된다. 평타에서 부여한 독은 해당 투사체의 공격력, 장판 독은 해당 장판의 공격력, 필살기와 합성은 해당 시전/새 유닛의 `power`를 사용한다. 이미 계산한 공격력에 성장 배율을 다시 곱하지 않는다.

| 적용 경로 | 부여 스택 | 지속시간 |
| --- | --- | --- |
| 머쉬룸킹 평타 | 성급 | 7초 |
| 포자밭 주기 | 해당 장판 성급 | 7초, 그 장판 출처만 갱신 |
| 머쉬룸킹 합성 | 새 성급×2 | 8초, 루미를 양방향 재료로 사용해도 적용 |
| 머쉬룸킹 필살기 | 성급×8, 출처 상한40 | 12초 |
| 팬텀 필살기 | 성급×4 | 12초, 전체 생존 적 |

씨앗 유물(숨 쉬는 씨앗)은 2026-10-17부터 스택을 더하지 않고 모든 독 피해를 40% 늘린다(이전에는 독을 부여하는 각 적용에 1스택을 추가했다). 팬텀의 독은 직격과 노출을 먼저 처리한 뒤 적용한다. 머쉬룸킹 필살기의 기존 순서인 독 부여 후 직격은 유지한다. 독은 기존과 같이 방어 유형을 무시하는 `pure` DOT이며 일반 공격의 즉사 확률을 판정하지 않는다. 실드 흡수와 HP 감소를 합친 실제 피해만 `stats.byHero[owner]`에 더한다.

범용 받는 피해 증가와 공격자의 조건부 피해는 다음처럼 구별한다.

```text
범용 받는 피해 증가 = min(0.80, 가장 강한 노출 + 성광 중첩×0.02)
최종 피해 = 출처 위력 × 해당 공격의 조건부 배율 × (1 + 범용 받는 피해 증가)
           × 보스 대상 배율 × 공격자 유물 조건 배율 × 적의 방어 보정
```

80% 상한은 현재 명탐정의60% 노출, 보수적인 특수효과 성장, 성광6%가 함께 작동하면서도 이후 범용 증가가 무제한 증폭되지 않도록 정했다. 기본 조합은 `1+.60+.06=1.66배`이며 노출과 성광을 따로 곱한1.696배가 아니다. 정수2% 중첩은 성광을 팀 기여로 체감하게 하면서3중첩 조건의 기존 개인 추가 피해를 대체하지 않기 위한 값이다. 체리프린스의 `화상 또는 성광3중첩` 조건은 두 상태가 함께 있어도 한 번만1.6배를 적용한다. 재스민의 성광3중첩 조건1.65배, 감속 대상 유물1.25배 등 공격자의 서로 다른 효과는 별도 배율로 남긴다. 명탐정 궁극기의3배 직격은 새60% 노출을 설치하기 전에 해결한다.

## 모든 장판의 독립 중첩과 공격 주기

같은 캐릭터·같은 시전자·같은 좌표의 장판도 새 UID로 생성한다. 이전 장판의 위력·반경·종료 시각을 덮거나 갱신하지 않는다. 궤도 유물의 장판도 동일하게 독립 중첩한다. 전장의 장판은 통틀어75개이며76번째 생성 시 가장 먼저 생성된 장판 하나를 제거한다. 제거된 장판이 이미 부여한 효과는 그 출처의 남은 시간 동안만 유지한다.

- 일반 장판은0.5초마다 스냅샷 위력의22%, 궤도는15% 피해를 준다.
- 일반 지속시간3초와 뿌리 유물의1.5배는 유지한다.
- 화염의현자만 일반 장판 위력·반경·시간에1.3배를 적용한다. 반경은64×1.3=83.2, 시간은3×1.3=3.9초(뿌리 적용 시5.85초), 화상 DPS는 강화된 장판 위력의30%이다.
- 새 장판은 다음 전투 처리부터 주기 피해를 주며, 배치하기 위해 선택한 적에게 가상의 직격 피해를 주지 않는다.

실측은16개 고정 seed(1~16),1성 영웅1기,12번 칸, 일반 적 HP1e9·경로 위치1200·속도0, 유물·필살기·성장 없음에서 진행했다. 실제 `step(.05)`로35초를 돌리고 처음5초를 제외한30초의 실제 전투 피해를 평균했다. 팬텀의 원래 밀치기, 시간의지배자의 개인 배율, 첫 웨이브 은하고래 배율, 화염의현자의 무작위 지면은 그대로 작동한다. 이는 같은 조건의 엔진 비교이며 이동하는 다수 적이나 모든 조합의 절대 DPS를 뜻하지 않는다.

## 밤토끼와 별도1종 테스트

밤토끼 필살기의 표적 수는 `9 + 2 × 전장에 존재하는 눈토끼·은토끼의 서로 다른 종류 수`이다. 토끼 유닛 수가 아니므로 눈토끼 여러 기는+2, 눈·은토끼를 함께 두면+4이다. 밤토끼 자체나 다른 동료는 늘리지 않는다. 경로상 가장 앞선 적부터 선택하고 충분한 적이 없으면 생존 적만 맞힌다. `nightRabbitTargetCount(s)`를 전투와 표시에서 함께 사용할 수 있다.

엔진의 편성 검증과 기본 편성 대체값은 `TEAM_SIZE`를 사용한다. 기본 게임은5종 편성과 무작위3기 시작을 유지한다. 별도SOLO 빌드는1종 편성, 중앙12번 칸에 해당 영웅1기로 시작하며 추가 소환은 그 영웅을 재료로 제공한다. 그리드의 가로5칸, 이웃 관계, 전장 최대25칸은 편성 종류 수와 별개이다.

## 저장 마이그레이션과 검증

상태 revision이 없는 기존 저장은 남아 있는 노출·화상·제어·성광·서리를 각각 유한한 `legacy` 출처로 변환한다. 옛64중첩처럼40을 넘던 독은 실제 상한40으로 정규화하고, 과거 머쉬룸킹 전용 피해의 남은 시간·소유자·메타/유물 위력은 한 번 보존한다. 알 수 없는 과거 시전자 성급이나 공격력은 새로 추측하지 않는다. 옛 감속의 서로 다른 출처도 각각 남은 종료 시각을 보존한다. 만료된 옛 화상의 남아 있는 숫자는 즉시 지운다.

새 저장은 상태 배열을 필수로 요구한다. 알 수 없는 status revision, 유효하지 않은 효과 종류/출처/소유자, 중복된 종류+출처, 잘못된 UID, 음수·분수 스택, 출처별40초과 독, 활성 상한을 넘는 성광/서리 원자료,0이하 독 위력, 불가능한 미래 종료시각(현재+30초 초과), 감속80% 초과,2048개 초과 출처는 거부한다. 독 원자료 합계40초과는 상한 초과 오류가 아니며, 실제 적용 선택을 별도로40으로 제한한다.

장판은75개 상한, UID/출처/영웅, 성급, 지면 좌표, 양수 반경/시간, `0<life<=total<=30`, 주기 범위, 음수 피해와 잘못된 orbit 유형을 검사한다. 이미 사라진 시전자나 장판의 유효 DOT는 출처 UID가 과거 유효 ID 범위에 있으면 복원할 수 있다. 새 저장의 표시용 수치는 출처 배열에서 재계산한다. 반복 저장·복원으로 효과의 종료 시각이나 과거 보스 HP 마이그레이션이 다시 연장·적용되지 않는다.
