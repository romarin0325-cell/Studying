## 공격·필살기 판단표

비용은 별빛이다. 수치·범위·주기·조건·저장 규칙은 기존 그대로다. 그림 크기를 비용에 단순 비례시키지 않고, 적 전체 타격·상태 변화·아군 비용·설치 대기를 구별했다.

| 캐릭터 | 일반 공격: 역할 → 선택 | 필살기: 비용·역할 → 선택 |
|---|---|---|
| 토피애플 | 관통 → 짧은 덩어리 탄 대신 가는 사탕 코팅 광선. 시럽의 붉은 광택과 설탕 조각을 원래 사과·재킷에 연결했다. 살아 움직이는 대상과 같은 판정 축을 따른다. | **애플봄 95**, 설치·저축 후 적 전체 타격 → 읽기 좋은 기존 대기 폭탄은 유지한다. 잘못된 국소 피해 원을 없애고, 발동 때 사탕 껍질이 여섯 조각으로 갈라지며 모든 피격점에 짧은 파편을 남긴다. 설치 시점에 가짜 전체 명중을 만들지 않는다. |
| 조커 | 상태색을 바꾸는 범위 카드 → 아이보리·금 테두리·자홍 궤적. 밝은 보석빛으로 검정·하양까지 현재 상태색을 읽힌다. | **레인보우 룰렛 50**, 저비용 전체 공격·상태색 변경 → 다섯 색 카드가 펼쳐지고 짧은 카드 잔상이 실제 적 방향으로 흘러간다. 공용 화염 도장을 반복하지 않는다. |
| 해바라기 | 햇빛에 따라 단일/원형 폭발 → 꽃 장식·올리브 잎의 작은 햇빛 탄. 햇빛이 있을 때만 실제 30/60/90 반경을 가늘게 확인한다. | **솔라플레어 90**, 햇빛 소비 전체 공격 → 꽃 중심에서 태양 하나가 열리고 적마다 짧은 꽃빛 명중이 남는다. 적 수만큼 거대 태양을 반복하지 않는다. 햇빛 계기와 소비 정보는 유지한다. |
| 언더독 | 투석 → 각진 회색 돌·짧은 먼지 꼬리. 꼬리까지 회전해 마법처럼 보이지 않게 방향을 유지한다. | **빅쇼 80**, 적 전체 강타·아군 2초 기절 → 실제 SD의 짧은 몸 강타, 바닥 균열, 먼지와 날아가는 돌. 허공에서 나타나는 거대 손이나 적마다 반복되는 주먹은 쓰지 않는다. 아군 기절은 기존 상태 표시로 확인한다. 생성한 주먹 그림도 최종 연출에는 채택하지 않았다. |
| 큐어마스터 | 공격 후 장판 → 간호사 주사기·레모네이드 액체로 공격 출처를 읽힌다. 기존 장판의 실제 범위와 지속은 유지한다. | **레모네이드 50**, 기절·저주 해제·무적 → 레몬·분홍 하트·흰 날개의 보호 표식이 아군 옆과 발밑에 나타난다. 적 명중과 같은 화염을 쓰지 않는다. 보호가 유지되는 상태 표시는 그대로다. |
| 베놈 | 독·화상 단일 → 검은 백합 꽃잎을 품은 초록 독액. 검정 재질을 투명도와 함께 보존했다. | **플래이그 80**, 전체 타격·중독·지속 피해 증폭 → 차분한 검은 백합이 적 발밑에서 피어나고 작은 포자가 오른다. 화면 폭발 대신 오염이 퍼지는 인상, 남은 증폭 시간은 기존 상태 표시를 유지한다. |
| 애쉬 | 화상 범위 → 검은 심장·깃털·크림/주황 불씨. 원화의 손바닥 불꽃과 날개를 따른다. | **아마겟돈 70**, 동료 환원·밀집 지점 폭발 → 환원 동료가 그 자리에서 잿불로 사라지고, 실제 반경 180에 깃털을 두른 불의 핵이 열린다. 환원을 별빛·골드 획득처럼 계기로 빨려가는 금빛 연출로 만들지 않는다. |
| 앤트로피 | 범위 궤도탄 → 얇은 흰 교차 고리·작은 별. 보라색 면이 찬 첫 후보는 거부하고 빈 공간이 많은 별도 시트를 제작했다. | **노바레퀴엠 50**, 적 디버프 제거·전체 타격 → 후광의 궤도가 한 번 열리고 디버프가 흰 파편으로 흩어진다. 거대한 흰 화면·반복 불꽃·지속 피해 장판처럼 보이는 면을 없앴다. |

## 일관성과 설치

- SD는 `selection.json`에 있는 최종 WebP 8장을 해시까지 동일하게 설치했다. 베놈은 `venom_idle`, 앤트로피는 `antropy_idle`이며 게임 ID는 그대로 `venom`, `antropy`다. 앞/뒤/왼쪽/오른쪽 실제 32방향을 사용한다.
- 두개골과 얼굴로 머리를 정의한다. 귀·머리카락 부피·모자·꽃·후광·무기는 제외한다. 승인본의 균일 배율과 480px 바닥선을 보존하고, 기존 렌더 배율을 1로 유지했다. 초상화 크롭만 새 두개골 중심으로 옮겼다.
- 수동 기준점·방향별 두개골·턱·발·오차는 [selection.json](art/sol-20261023/selection.json)에 있다. 원본 좌표 오차 추정은 정면/측면 ±12px, 가려진 뒷머리 ±16px이며 해부학 검출기의 정답 좌표가 아니다.
- SD 8장 합계 1,807,910 bytes. 새 VFX는 1024×512 WebP 두 장 합계 423,672 bytes. PNG 원본을 배포하지 않고 WebP·손실 없는 alpha를 사용한다. 흰 의상·검정 꽃을 배경색으로 오인해 지우지 않는다.
- 새 아틀라스는 4열×2행. 윗줄은 공격 소재, 아랫줄은 필살기 후보 소재다. 후보를 모두 도장처럼 쓰지 않는다. 언더독 주먹은 미채택, 애플봄은 조각으로 분리해 그린다. 16px 투명 여백으로 인접 칸 혼입을 막는다.
- 실제 게임의 Art/빌더가 초상화·전신 크롭을 다시 만들고 70개 텍스처를 single HTML에 내장한다. 별도 이미지 다운로드·캐시 교체가 필요 없다. `ASSET_PROVENANCE.json`도 현재 파일로 갱신했다.

## 제작·확장 규칙

1. 이펙트를 만들기 전에 엔진에서 **투사체인지, 관통인지, 지연 설치인지, 대상 전체인지, 실제 국소 원인지, 아군 지원인지** 확인한다. 스킬 이름이나 기존 그림만 보고 결정하지 않는다.
2. 캐릭터의 실제 소품·재질·표정을 본 뒤 한 가지 중심 소재를 정한다. 모든 스킬을 같은 섬광+원+캐릭터색으로 처리하지 않는다. 밝기와 점유 면적은 정보의 중요도에 맞춘다.
3. 한 번의 준비·짧은 정점·빠른 잔향을 구성한다. 동료 얼굴과 HP·위험 칸보다 뒤에서 그릴 큰 소재와, 앞에서 그릴 작은 명중점을 구분한다. 실제 피해 시각을 바꾸려고 공격 주기를 수정하지 않는다.
4. 진짜 alpha 이미지에는 `source-over`를 써서 검은 깃털·백합을 보존한다. 화면 합성으로 검정이 사라지는 기존 검정 배경 아틀라스와 구별한다. 매 프레임 픽셀 재처리를 하지 않는다.
5. 패킹 뒤 투명 여백·흰 재질·검정 재질·실제 390px 장면을 본다. Sharp에서는 한 파이프라인의 두 번째 resize가 첫 번째를 대체하므로, 크기 조정 결과를 먼저 만들고 여백을 붙인다.
6. 원본 SD를 다시 생성해 비율을 바꾸지 않는다. 기존 승인본과 얼굴·의상·표정이 맞는지 먼저 본다. 새 효과가 더 화려해도 캐릭터 컨셉과 역할에 어긋나면 버린다.

내장 `image_gen`으로 제작했으며 다른 모델·외부 이미지 API를 사용하지 않았다. 실제 프롬프트는 `art/sol-20261023/effects-*.prompt.txt`, 원본/출력 해시와 셀 추출 좌표는 `effects-packing.json`에 있다. 원래 SD 제작 기록은 같은 폴더의 `ART_GUIDE.md`, `POSE_REFINEMENT.md`다.

참고한 판단 원칙은 [Riot의 Clarity in League](https://www.leagueoflegends.com/en-us/news/dev/clarity-in-league/)와 [공개 VFX 가이드](https://nexus.leagueoflegends.com/wp-content/uploads/2017/10/VFX_Styleguide_final_public_hidpjqwx7lqyx0pjj3ss.pdf)의 정보 우선순위·실루엣·방향·준비/정점/소멸 구분이다. 이 게임에서의 소재 선택과 구현은 위의 판단표에 기록했다.

## 재현과 증거

```powershell
node defense/scripts/review-sol-vfx.mjs
node defense/scripts/review-sol-browser.mjs
npm run verify -- --only defense
node defense/scripts/build.mjs --bright
```

비교 장면은 실제 엔진을 사용하되 검수용으로 적을 고정하고 애플봄은 1.35초 뒤 적 하나를 접근시킨다. 기존 Renderer/CombatFX 소스는 main의 파일에서 import 경로만 바꾸어 동결했다. 현재 전투 수치는 [gameplay-baseline.json](art/sol-20261023/gameplay-baseline.json)과 비교해 변경하지 않았음을 검사한다. 이미지·이벤트·브라우저 검수의 요약은 [검증 기록](review/sol-vfx/VALIDATION.md)에 남긴다.

이 검수는 Windows의 오프라인 Chromium 모바일 에뮬레이션이다. 실제 Android/iOS의 발열·배터리·장시간 성능이나 재미·상용 수준 달성을 객관적으로 인증하지 않는다. 타격감의 선호는 비교 도구와 실제 통합 빌드에서 최종 판단할 수 있게 했다.
