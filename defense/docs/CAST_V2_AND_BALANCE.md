# 승인 캐스트 V2와 성장 패치

2026-10-24. 기준은 최신 main `19e2121`이다. 그 사이 `defense_test/`가 정식 `defense/`로 승격되어 현재 별빛 정원 소스와 두 배포판에 적용한다.

## 적용한 수치

| 대상 | 현재 규칙 |
|---|---|
| 눈토끼 훈련 | 일반 공격의 기본 감속 40%에 훈련마다 **2%p** 가산. 5회는 50%(성급·강화 적용 전) |
| 눈토끼 필살기 | 빙결 2초와 감속 50%에 `1 + 0.1 × (성급 - 1)` 적용. 감속 지속시간은 6초. 기존 강화 특수 배율과 곱하고 감속은 80% 상한 |
| 폭풍의현자 | `즉사율 = 1% + (성급 - 1) × 0.1%p + floor(강화 / 5) × 0.1%p`. 예: 3성·강화 10은 **1.4%**. 보스·필살기·지속 피해·반복탄 제외, 같은 탄/적 한 번 판정 유지 |
| 번개의현자 | 같은 연결 묶음 2기 **+20%**, 3기 **+40%**, 4기 이상 **+60%**. 대각선 제외, 체인 비율·대상 수 유지 |
| 베히모스 | 대지분쇄 **반경** 150 → **112.5**, 25% 감소. 훈련마다 새 기본 반경의 5% 가산: 112.5 / 118.125 / 123.75 / 129.375 / 135 / 140.625. 피해 6배 × 3회·간격·비용 유지 |
| 혹한의마녀 | 필살기 감속 50%와 겨울 6초에 같은 성급 배율 `1 + 0.1 × (성급 - 1)` 적용. 강화 특수 배율과 곱함. 처치 시 후속 빙결은 0.8초 고정 |
| 애쉬 | 아마겟돈 **위력 18배**. 기존 동료 소멸·무적 보호·밀집 반경 180·비용 유지 |

베히모스의 요청은 반경 기준으로 해석했다. 0회 훈련 시 원의 면적은 이전의 56.25%다. 훈련은 누적 가산이며 매번 이전 반경에 1.05를 곱하지 않는다.

혹한의마녀는 하나의 `winterDuration()`에서 계산한 시간을 필살기 감속, 겨울 노출, 겨울 버프 모두에 전달한다. 일반 공격과 각 필살기의 감속은 출처별 종료시각을 유지한다. 눈토끼의 지원 공격이 마녀 필살기를 단축하지 않고, 마녀가 계속 공격해도 필살기 만료 후 일반 공격 감속으로 돌아온다. 더 강한 다른 감속이 따로 남았다면 그 효과가 적용된다.

현재 동료 정보·필살기 상세는 실제 계산된 효과·시전자 성급·피해·감속·지속시간·반경을 보여준다. 전장에 없는 필살기는 도감의 기본 설명을 보여준다. 폭풍 즉사율은 전투의 현재 성급과 강화가 반영되고, 도감의 강화 안내에는 +0.1%p를 명시한다.

## 이미지와 배포

- 대상은 동료 **39명 + 트라우마 변신 1종**, 4방향 **160개 뷰**다. 사용자가 보던 `Downloads/캐릭터/에셋/gpt/cast-v2-20261024`의 최종 선택 PNG와 q95 WebP를 해시 그대로 설치한다.
- 새 보관본은 `assets/cast-v2/`. 기존 `assets/merge/units/`와 다른 미디어는 덮어쓰지 않는다. 최종 PNG·WebP SHA-256, 선택 버전, 방향별 두개골 타원·턱·발·불확실성은 [설치 매니페스트](art/sol-cast-v2/manifest.json)에 남긴다.
- 머리는 해부학적 두개골·얼굴 기준이다. 귀·머리카락 부피·모자·무기·배경 고래를 머리로 계산하지 않는다. 공통 바닥 (256,480), 동일한 전신 균일 배율, 실제 4방향을 유지한다. 그림을 칸에 맞춰 다시 자동 축소하거나 좌우를 일괄 반전하지 않는다.
- 정면 두개골 중심에 맞춰 초상화 39개의 crop을 갱신했다. 트라우마 변신 crop도 같은 기준을 기록한다. 공통 250px crop은 실제 1024px 보관 아틀라스에서 생성한다.
- 기존 배포 정책을 사용한다. 전투는 **640×640 WebP q90 / alpha100**(방향별 320px), UI는 보관본에서 미리 생성한 초상화 240px·전신 512px다. 최종 PNG를 단일 HTML에 직접 넣지 않는다. 일반 빌드는 재인코딩 없이 검증한 압축본과 UI 파일을 읽는다.
- 일반판과 Bright 모두 동일 캐스트를 내장한다. 현재 공격·필살기 이펙트 그림과 연출 문법은 유지하고, 대지분쇄 연출에는 실제 충격 반경을 전달한다.

전체 원화·생성 프롬프트·3D 구조 가이드·이전 후보·동결 전후 비교 도구는 전달된 로컬 아카이브에 있다. Git에는 최종 설치본과 재사용할 [제작 지침](art/sol-cast-v2/ART_PIPELINE.md), 설치 기준점과 실제 통합 검증 자료를 남긴다.

## 검증과 한계

검증 결과와 화면은 [통합 검수](art/sol-cast-v2/REVIEW.md)에 기록한다. 자동 테스트는 실제 공격, 필살기, 시간 진행, 저장 복원과 반경 경계를 사용한다. 조합 감속의 독립 만료, 성급·강화의 즉사율 가산, 번개 연결 위력, 애쉬의 실제 피해, 베히모스의 시전 순간 반경·이벤트·저장값을 확인한다.

패치 전에 저장한 베히모스의 대기 중 충격에는 150 반경을 보존하고, 새 시전부터 새 반경을 적용한다. 새 반경은 시전 순간 저장하므로 뒤늦게 훈련해도 이미 나간 3연타가 커지지 않는다. 원래 저장된 독립 감속의 종료시각도 임의로 다시 시작하지 않는다.

수작업으로 추정한 가려진 두개골·후면 기준점은 정확한 3D 정답이 아니다. 그림의 완벽한 연속 회전이나 모든 취향에 대한 시각적 우열, 실제 Android/iOS 기기의 성능·발열·배터리는 인증하지 않는다. 모바일 화면 검수는 Windows Chromium의 390×844 환경에서 수행한다.
