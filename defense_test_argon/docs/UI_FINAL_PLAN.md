# 드림위버: 별빛 정원 — 최종 상용화 UI/UX 재설계 및 완성 계획 (`UI_FINAL_PLAN.md`)

## 1. 핵심 문제 진단과 설계 철학

기존 구현을 실제 휴대폰 해상도(390×844, 360×640, 412×915)에서 캡처·검수한 결과, 사용자의 지적대로 **「성취감과 동기를 부여해야 할 보상이 오히려 답답함과 시각적 피로를 유발하는 구조」**가 확인되었습니다.

### 1.1 기존 UI의 5대 문제점
1. **메모리얼 로비의 감상 파괴 (`11-memorial-lobby`)**
   - 호감도 10(약 2~3주간의 교감 보상)으로 해금한 720×1080 세로 일러스트를 메인 화면에 걸었을 때, SD 캐릭터 기준 위치(`top: 56px`)에 떠 있는 불투명한 흰색 말풍선과 좌상단 배너가 **캐릭터의 얼굴(눈·코·입)을 정면으로 가려버리는 치명적 문제**가 있었습니다.
2. **과잉 사각형 박스와 불필요한 내부 공식 노출 (`4-collection-relic`, `5-relic-detail`, `13-hero-detail`)**
   - 유물 상세 창에 개발자용 내부 설계 용어인 `[체감 Lv.1–5 | 둔화 Lv.5–10 | 상한 Lv.10~]` 3단 사각형 틀과 `체감 구간` 배지가 노출되어 있었습니다.
   - 유물 도감 상단에는 등급별 점수 내역과 공식(`유물 1개의 점수 = 등급 가중 × (레벨 + 2)`)을 적은 거대한 사각형 박스와 장착 슬롯 박스가 2중으로 자리 잡아, 정작 유물 목록은 첫 화면에 한 줄밖에 보이지 않았습니다.
   - 동료 상세 창에서도 정작 플레이어가 가장 먼저 보고 싶어 하는 **특성·필살기**가 위력 계산식 박스(`기본 위력 × 동료 강화 × 꿈의 온실 × 유물 수집 보너스...`) 아래로 밀려 스크롤해야만 보였습니다.
3. **소환 화면의 사각형 박스 적층과 스크롤 발생 (`6-summon`)**
   - 배너 아래에 `[오늘의 무료 소환]` 사각형 박스 + `[천장 0/200]` 사각형 박스 + `[1회 소환 / 10회 소환]` 버튼이 3단으로 쌓여, 한눈에 들어와야 할 소환 화면에서 하단 확률/기록 링크가 잘리고 시선이 분산되었습니다.
4. **별의 서재(학습 보상)의 성취감 부재 (`2-library`, `12-library-gallery`)**
   - 일주일 이상 오답을 복습하며 별을 밝혀 얻는 루미 일러스트 7종이 각각 고유한 비율(`4:3 가로형`, `9:16 톨 세로형`, `4:5 클래식 세로형`, `1:1 정사각형`)로 그려져 있음에도, 화면 맨 아래 스크롤 끝에 작은 동일 비율 사각형 4열 그리드로 잘려 들어가 있었습니다.
5. **분산된 교감·선물 경험과 분재형 컬렉션 피드백 부족**
   - 선물과 인연 이야기, 수집 진행도가 여러 창에 텍스트 위주로 흩어져 있어, 『재배소년』·『블루 아카이브』·『스텔라 소라』 같은 분재형·서브컬처 수집 게임 특유의 시각적 애착과 수집 만족감이 부족했습니다.

## 3. 전체 정보 구조(IA) 및 화면별 레이아웃 재설계

### 3.1 홈(로비) & 메모리얼 감상 시스템
- **일반 정원 모드 vs 메모리얼 모드**:
  - 호감도 10 달성 파트너는 로비에서 즉시 **「기억 전환(SD 정원 ↔ 메모리얼)」** 스왑 버튼으로 배경을 전환할 수 있습니다.
  - **메모리얼 모드 대사 배치**: 캐릭터 얼굴이 위치한 상단 중앙(`top: 10~45%`)을 완전히 비우고, 인사·터치 대사를 네임플레이트 바로 위의 **하단 시네마틱 자막 바**에 표시하여 일러스트 감상을 방해하지 않습니다.
- **감상 모드 (UI 숨김 · 상호작용 잠금)**:
  - 로비의 **「감상」** 버튼을 누르면 좌우 메뉴, 하단 독, 상단 배너가 부드럽게 페이드아웃되고 상호작용이 잠기며, 오직 파트너(또는 메모리얼 일러스트)와 대표 대사 한 줄만 남는 풀스크린 액자 감상 화면이 됩니다.
- **하단 정원 독(Dock)**:
  - `출격/이어하기` 주 버튼 + `출전 팀·편성` 스트립 + `꿈의 온실`·`별똥별 수집(별사탕 획득 확률 표시)` 카드를 한 화면 안에 스크롤 없이 배치합니다.

### 3.2 교감 · 선물 시스템 재설계 (별빛 다과회)
- 기존에 흩어져 있던 선물/교감 동선을 **「교감 · 선물하기」** 시트로 세련되게 통합합니다.
- **상단 동료 빠른 전환 스트립**: 시트를 닫지 않고도 보유 동료를 좌우로 탭해 전환하며 각 동료가 좋아하는 선물을 즉시 줄 수 있습니다.
- **불필요한 설명문 제거**: 하단에 사각형 박스로 적혀 있던 3줄짜리 선물 획득처 설명문을 없애고, 각 선물 타일 안에 한 줄 서브태그(`별똥별 수집`, `일일 임무 완료`, `파견 첫 귀환`)로 깔끔하게 녹여냅니다.

### 3.3 소환 화면 (Zero-Scroll 원스크린 쇼케이스)
- **무료 소환 통합**: 별도의 `[오늘의 무료 소환]` 사각형 바를 제거합니다. 일반 소환에서 오늘 무료 횟수가 남아 있으면 왼쪽 `1회 소환` 버튼 자체가 에메랄드·금빛 **「무료 1회 소환 (오늘 1회 무료)」** 버튼으로 표시되며, 사용 후 일반 `1회 소환 (💎 100)`으로 바뀝니다.
- **스텔라소라식 컴팩트 천장 버튼 & 영입 시트**:
  - 배너 하단의 큰 `[천장 0/200]` 사각형 박스를 제거하고, 배너 우상단에 **「★ 천장 N/200 · 확정 정보 ▸」** 알약 버튼(유물 배너는 **「✦ 유물 N단계 · 다음 단계 M회 ▸」** 알약 버튼)으로 통합합니다.
  - 버튼을 누르면 **천장 영입 안내 시트**가 열려 현재 천장 게이지, 200회 확정 대상 UR 동료 프리뷰, 전체 UR 라인업을 한눈에 확인할 수 있습니다.
- **결과**: 390×844 및 360×640 화면 모두에서 스크롤 없이 **배너 일러스트 + 확률 칩 + 1회/10회 소환 버튼 + 확률 안내/소환 기록 링크**가 한 화면에 완벽히 들어옵니다.

### 3.4 동료 & 유물 도감 (핵심 정보 우선 노출, 내부 공식 숨김)
- **유물 도감 상단 슬림화**:
  - 화면 절반을 차지하던 수집 보너스 점수 공식 박스를 제거하고, **장착 유물 3슬롯 + 우측 상단 「수집 보너스 +N% ⓘ」 버튼**으로 한 줄에 압축합니다.
  - `ⓘ` 버튼을 누를 때만 등급별 수집 점수와 계산 규칙을 시트/펼침으로 보여줍니다. 덕분에 유물 도감 진입 즉시 유물 카드 그리드 2~3줄이 한눈에 들어옵니다.
- **유물 상세 시트 정리**:
  - 사용자에게 불필요한 `[체감 Lv.1–5 | 둔화 Lv.5–10 | 상한 Lv.10~]` 사각형 트랙과 `체감 구간` 칩을 **완전히 제거**합니다.
  - 장착 효과(현재 레벨 → 다음 레벨 수치 변화)와 수집 보너스 기여, 강화/장착 버튼만 깔끔하게 남깁니다.
- **동료 상세 시트 위계 재정립**:
  - 스크롤 없이 첫 화면에서 **일러스트·역할 + 호감도/기억·선물 바로가기 + 특성 + 필살기 + 하단 강화/편성 독**이 바로 보이도록 배치합니다.
  - 기존의 긴 `위력 구성 표(기본 위력 × 강화 × 온실 × 유물...)`와 `수치 상세`는 하단의 **`<details>` (상세 능력치 · 위력 계산식 보기)** 하나로 통합해, 깊게 파고드는 플레이어가 원할 때만 펼쳐 볼 수 있게 합니다.
- **기억 화첩(일러스트 갤러리) 연결**:
  - 도감 상단에 **「기억 화첩 ♥ N/30」** 버튼을 추가하고, `함께한 기억` 목록을 단순 텍스트 줄에서 **초상 일러스트 카드 그리드**로 격상합니다.

### 3.5 루미의 별의 서재 & 맞춤 비율 액자 갤러리 + PM 강의·용어·문제 구조
- **별자리 탭 레이아웃 개편**:
  - 상단의 거대한 정사각 별자리 박스를 **컴팩트 파노라마 천체 관측 카드**(좌측 별자리 맵 + 우측 진행도·오늘의 별 안내)로 줄여, 첫 화면에서 바로 **오답 노트**와 **별자리 화랑 액자**가 함께 보이게 합니다.
- **7종 일러스트 고유 비율 맞춤 액자 (루미의 화랑)**:
  - 7장의 루미 일러스트 원본 해상도에 맞춘 전용 액자 비율을 적용합니다:
    1. `종이배자리` (`boat.webp`, **720×540 · 4:3 가로 와이드 액자**) — 상단 대표 와이드 액자로 배치
    2. `모자자리` (`hat.webp`, **608×1080 · 9:16 톨 세로 액자**)
    3. `문자리` (`door.webp`, **720×900 · 4:5 세로 액자**)
    4. `창문자리` (`window.webp`, **720×720 · 1:1 정사각 액자**)
    5. `편지자리` (`letter.webp`, **614×1080 · 9:16 톨 세로 액자**)
    6. `토끼자리` (`rabbit.webp`, **720×900 · 4:5 세로 액자**)
    7. `초승달자리` (`moon.webp`, **720×720 · 1:1 정사각 액자**)
  - `#1 종이배자리(4:3)`를 상단 와이드 액자로 두고, 그 아래 2열 전시 월(Masonry Wall)에 좌열(`#2 9:16` + `#4 1:1` + `#6 4:5`, 높이비 합 `4.026`)과 우열(`#3 4:5` + `#5 9:16` + `#7 1:1`, 높이비 합 `4.009`)을 배치하여 **단 1픽셀의 잘림(크롭)도 없이 두 열의 하단 끝선까지 정확히 맞아떨어지는 미술관급 화랑 레이아웃**을 구현합니다.
- **강의 1개당 문제 3개 · 용어 1개당 문제 2개 연결 (`src/course.js`, `src/quiz.js`)**:
  - `lectures/` 폴더의 PM 원고(`pm_lecture_data.json`, `pm_vocab_data.json`)에서 샘플 강의 6강(`L01`~`L06`)과 핵심 용어 10개(`T001`~`T010`)를 수록합니다.
  - **강의 1개 → 강의 문제 3개 연결**: 각 강의마다 기출 기반 개념 문제 3문항씩(총 18문항)을 연결하여, 강의를 읽고 **「강의 문제 풀기 (3문항)」**으로 3문제를 연속 연습할 수 있게 합니다.
  - **용어 1개 → 용어 문제 2개 연결**: 각 용어마다 뜻/개념 문제 1문항 + 기출 응용 문제 1문항(총 2문항씩, 10용어 × 2 = 20문항)을 연결하여, 각 용어 카드에서 **「용어 문제 풀기 (2문항)」**으로 2문제를 연속 연습할 수 있게 합니다.

## 5. 밸런스 최종 조정 (`src/combat/engine.js`, `src/data.js`)

1. **보스 체력 배율 미세 완화 (`BOSS_HEALTH_SCALE`: `0.65` → `0.60`)**
   - 4차 밸런스에서 평타 감속의 성급 배율을 제어 배율(+10%/성)로 낮춘 뒤 보스 웨이브 체력 손실이 커지고 후반 보스(아레스·벨제뷔트·아스테아) 승률이 23~33%까지 하락했던 현상을 보완합니다. 보스 체력 배율을 `0.60`으로 조정해 메인 스테이지와 주간 드래프트의 돌파 리듬을 쾌적하게 맞춥니다.
2. **평타 감속 기본치 소폭 보완 (`시간의지배자`·`팬텀` 기본 감속 `25%` → `30%`)**
   - 성급 배율 완화로 약해진 장판형 감속 동료(`time_ruler`, `phantom`)의 기본 감속을 `25%`에서 `30%`로 끌어올려 제어 역할을 분명히 합니다.
3. **별모래 시계(`hourglass`) 유물 가치 보강 (`별빛 40` → `별빛 50`)**
   - C등급 유물 예산(1.0) 대비 발동 가치가 낮았던 `별모래 시계`의 합성 시 추가 별빛 획득량을 `40`에서 `50`으로 상향하여 초반 필살기 회전율을 체감되게 높입니다.
