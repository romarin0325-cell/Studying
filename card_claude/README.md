# DREAMWEAVER · Claude Edition

`card/`의 DREAMWEAVER와 같은 규칙·데이터·저장 형식을 쓰면서, 화면 구성·아트·연출을 상용 모바일 카드 RPG 수준을 목표로 새로 만든 비교용 빌드입니다.

## 빌드와 실행

```sh
npm ci
node card_claude/build.mjs
```

결과물은 `card_claude/dist/DREAMWEAVER-Claude.html` 한 파일입니다. 서버·CDN 없이 `file://`로 실행되며 휴대폰 세로 화면을 기준으로 합니다.

| | `card/` | `card_claude/` |
| --- | --- | --- |
| 단일 HTML | 12.6 MB | 약 4.1 MB |
| 그중 내장 이미지·글꼴(base64) | 10.6 MB (PNG 3장, TTF) | 1.9 MB (WebP 18장, WOFF2) |

초상화 PNG와 음원은 기존처럼 HTML 옆에 두고, 설정에서 상대 경로나 폴더를 지정할 수 있습니다. 저장 키와 형식이 `card/`와 같아서 같은 브라우저에서 같은 위치에 두면 기록을 그대로 이어서 씁니다.

검증: `node card_claude/tests/smoke.mjs`

## 화면

- **타이틀**: 테마별 키아트와 테마별 로고(아스트라는 클래식 세리프, 마법소녀 · 드림스카이는 둥근 글자), 저장된 여정(모드 · 스테이지)을 보여주는 이어하기, 포춘쿠키 · 질문 · 미션 · 음악 독.
- **로비**: 테마별 실내 장면 위에 선봉을 앞세운 파티 카드, 다음 상대 메달과 6스테이지 단위 진행 경로, 미션 · 축복 바로가기, 전투 출전 버튼.
- **소환**(하단 탭 가운데): 학습 연계가 목적이므로 **도전 소환(단어 퀴즈)이 주인공**입니다. 가장 크게, 먼저, 올라가는 확률(예: 전설 10% → 20%)과 함께 보여주고, 일반 소환은 작은 1회 버튼만 둡니다. 일반 소환을 더 편하게 만드는 연속 소환은 넣지 않았습니다. 결과는 전체 화면 카드 뒤집기 연출로 보여주고, 에픽 이상은 광채가 납니다. 공개 뒤 다음 행동은 언제나 퀴즈로 이어집니다(도전 소환 뒤에는 '한 번 더 도전', 일반 소환 뒤에는 '도전 소환'). 드래프트 · 카오스 · 퍼즐 모드에서는 각 모드의 행동으로 바뀝니다.
- **편성**: 자동 편성, 다음 빈 자리 자동 선택, 배치된 자리 표시, 다시 눌러 해제, 맞교환, 등급 필터, 카드 상세.
- **도감**: 수집률, 등급 칩, 등급 프레임과 속성 배지. 상세 화면은 능력치 막대와 이전 · 다음 카드 넘기기(스와이프 포함)를 지원합니다.
- **전투**: 테마별 무대, 등급 프레임 카드, HP/MP 숫자, 파티 생존 표시, 내 차례 · 적 차례 표시, 공격 돌진과 피격 반동, 스킬 종류별 효과(참격 · 마법 · 회복 · 방어막 · 치명타), 치명타 · 회피 숫자 표시, MP 30 이상 스킬 컷인.
- **결과**: VICTORY · DEFEAT · STAGE CLEAR 배너, 티켓 보상 카운트업, 소멸 · 새로 해금된 카드, 보너스 퀴즈 제안을 한 패널에서 처리합니다.
- **설정**: 테마, 효과음(합성음, 리스닝 · TOEIC · 음악 창이 열려 있으면 소리 내지 않음), 소환 · 전투 연출 끄기, 기록 백업, 초상화 경로.

## 소스 구조

```text
card_claude/
  build.mjs           card/game 원본을 읽어 한 파일로 조립 (컨트롤러 3곳은 빌드 시 패치)
  src/shell.html      화면 마크업
  src/astra.js        화면 어댑터 (기존 RPG 메서드를 호출하고 화면만 소유)
  src/sfx.js          Web Audio 합성 효과음
  src/dream.css       디자인 시스템
  src/*.css           card/src에서 가져온 보조 대화상자 스타일 (무거운 배경·글꼴 참조 제거)
  assets/             준비된 WebP 아트, 주아 WOFF2, art-manifest.json
  tools/              오프라인 아트 · 글꼴 준비 스크립트 (빌드에는 쓰지 않음)
  tests/smoke.mjs     핵심 플레이 루프 검증
  ART.md              아트 출처 · 톤 검수 기록
```

빌드 시 패치하는 곳은 세 군데입니다. 원본 문장이 바뀌면 빌드가 실패해 알려줍니다.

1. 모드 목록 정의를 화면에 노출 (`RPG.modeDefinitions`)
2. 새 여정 시작: 덮어쓸 저장이 있을 때만 확인 1회
3. 덱 편집 버튼 요약은 문구만 갱신

게임 규칙, 확률, 보상, 수동 저장 방식은 바꾸지 않았습니다.
