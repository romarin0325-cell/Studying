# DREAMWEAVER · Claude Edition

`card/`의 DREAMWEAVER와 같은 규칙·데이터·저장 형식을 쓰면서, 화면 구성과 연출을 상용 2D 모바일 수집형 RPG 수준으로 새로 만든 비교용 빌드입니다. 디자인 원칙과 판단 근거는 [DESIGN.md](DESIGN.md)에 있습니다.

## 빌드와 실행

```sh
npm ci
node card_claude/build.mjs
```

결과물은 `card_claude/dist/DREAMWEAVER-Claude.html` 한 파일입니다. 서버·CDN 없이 `file://`로 실행되며 휴대폰 세로 화면을 기준으로 합니다.

| | `card/` | `card_claude/` |
| --- | --- | --- |
| 단일 HTML | 12.6 MB | 약 2.7 MB |
| 그중 내장 이미지·글꼴(base64) | 10.6 MB (PNG 3장, TTF) | 0.54 MB (Noto Sans KR 부분 글꼴 WOFF2 하나) |

초상화 PNG와 음원은 기존처럼 HTML 옆에 두고, 설정에서 상대 경로나 폴더를 지정할 수 있습니다. 저장 키와 형식이 `card/`와 같아서 같은 브라우저에서 같은 위치에 두면 기록을 그대로 이어서 씁니다.

검증: `node card_claude/tests/smoke.mjs`

## 화면

- **타이틀 · 로비**: 플레이어 파티의 대표 카드(가장 높은 등급) 일러스트를 화면 전체 배경으로 씁니다. 얼굴은 비워 두고 글자와 버튼은 아래쪽 스크림 위에 둡니다. 로비 아래 패널에 다음 상대, 6스테이지 단위 진행 경로, 파티 3장, 출격 버튼을 모았고 미션 · 축복은 오른쪽 레일에 있습니다. 첫 동료가 없을 때는 이번 카드풀의 전설을 예고처럼 보여줍니다.
- **소환**(하단 탭 가운데): 학습 연계가 목적이므로 **도전 소환(단어 퀴즈)이 주인공**입니다. 가장 크게, 먼저, 올라가는 확률(예: 전설 10% → 20%)과 함께 보여주고, 일반 소환은 작은 1회 버튼만 둡니다. 결과는 전체 화면 카드 뒤집기로 보여주고, 공개 뒤 다음 행동은 언제나 퀴즈로 이어집니다.
- **편성**: 하단 탭이 없는 하위 화면입니다(뒤로 · 완료, 완료는 게임의 덱 검사를 그대로 거칩니다). 카드 목록이 화면 대부분을 쓰는 4열 격자이고, 배치 번호는 왼쪽 아래, 보유 장수는 오른쪽 아래라 겹치지 않습니다. 탭하면 배치, 모서리 i 버튼이나 길게 누르기로 상세를 봅니다. 등급 필터는 드롭다운 하나입니다.
- **도감**: `이번 여정`(이번 런의 보유 카드와 장수)과 `도감`(계정 해금) 두 탭입니다. `도감`은 게임의 실제 해금 규칙으로 진행도를 보여줍니다: 보너스(도전 모드 클리어 · 출시일 공개), 히든(월간 미션), 시즌 스페셜(시즌 미션), 초월 보상(히든 보스 격파 10%). 잠긴 카드에는 얻는 방법이 적혀 있습니다.
- **카드 상세**: 높이가 고정된 시트입니다. 이전 · 다음 · 닫기는 위쪽 막대에 있어 일러스트를 가리지 않고, 내용이 길면 본문만 스크롤됩니다.
- **전투**: 두 카드가 화면 폭을 채우고, 상태 이상은 한 줄, 나머지 높이는 전투 기록에 줍니다. 효과는 SVG 선으로 그리고 공격하는 쪽에서 맞는 쪽으로 지나갑니다. 연출 크기는 스킬 티어가 아니라 실제로 일어난 일을 따릅니다(아래 표).
- **결과**: VICTORY · DEFEAT · STAGE CLEAR 머리띠, 티켓 보상, 해금된 카드와 소멸한 카드, 보너스 퀴즈 제안을 한 패널에서 처리합니다.
- **게임 대화상자**(퀴즈, TOEIC, 단어장, 미션, 카드풀 편집 등): 같은 토큰으로 다시 칠해 주 화면과 같은 표면 · 글자 · 버튼을 씁니다.

| 일어난 일 | 연출 |
| --- | --- |
| 물리 · 마법 피해 | 공격한 쪽에서 날아오는 참격 또는 마법 파열, 피해 숫자, 반동 |
| 최대 HP 30% 이상 피해, 치명타 | 굵은 참격 · 금색 파열, 화면 흔들림, CRITICAL 숫자 |
| 자폭 · 변신 · 전소모(필드 2개 이상 또는 디버프 3중첩 이상) · 지연 발동 | 카드 전체를 보여주는 컷인과 이유 한 줄 |
| 적 차징 | 경고 알림, 다음 턴까지 적 카드 붉은 맥동 |
| 적 차지 해방 · 보스 고정 패턴(예정된 턴, 위력 3배 이상) | 적 컷인 |
| 시너지 · 특성 · 아티팩트 · 필드 버프 | 짧은 알림 한 줄 |
| 회피 · 방어막 · 전투 불능 | MISS · GUARD · K.O. 표시 |

## 소스 구조

```text
card_claude/
  build.mjs           card/game 원본을 읽어 한 파일로 조립 (컨트롤러 3곳은 빌드 시 패치)
  src/shell.html      주 화면 마크업과 아이콘 세트
  src/tokens.css      테마 토큰 (드림스카이 · 마법소녀 · 아스트라)
  src/legacy.css      게임 대화상자 · 보조 화면 스킨 (토큰만 사용)
  src/ui.css          주 화면 디자인 시스템
  src/astra.js        화면 어댑터 (기존 RPG 메서드를 호출하고 화면만 소유)
  src/sfx.js          Web Audio 합성 효과음
  assets/             Noto Sans KR 부분 글꼴과 OFL 라이선스
  tools/              오프라인 글꼴 준비 스크립트 (빌드에는 쓰지 않음)
  tests/smoke.mjs     핵심 플레이 루프 검증
  DESIGN.md           디자인 원칙과 판단 기록
```

빌드 시 패치하는 곳은 세 군데입니다. 원본 문장이 바뀌면 빌드가 실패해 알려줍니다.

1. 모드 목록 정의를 화면에 노출 (`RPG.modeDefinitions`)
2. 새 여정 시작: 덮어쓸 저장이 있을 때만 확인 1회
3. 덱 편집 버튼 요약은 문구만 갱신

게임 규칙, 확률, 보상, 수동 저장 방식은 바꾸지 않았습니다.
