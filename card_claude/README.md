# DREAMWEAVER · Claude UI

`card/`의 DREAMWEAVER를 같은 규칙·데이터·저장 형식 그대로 두고, 메뉴와 화면 전체를 실제 플레이 동선 기준으로 다시 설계한 비교용 빌드입니다.

## 빌드와 실행

```sh
npm ci
node card_claude/build.mjs
```

결과물은 `card_claude/dist/DREAMWEAVER-Claude.html` 한 파일입니다(약 12 MiB, 서버·CDN 없이 `file://`로 실행). 초상화 PNG와 음원은 기존처럼 HTML 옆에 두고, 설정에서 상대 경로나 폴더를 지정할 수 있습니다. 저장 키와 형식은 `card/`와 같아서 같은 브라우저·같은 위치에서는 기록을 그대로 이어서 씁니다.

검증: `node card_claude/tests/smoke.mjs` (오프라인 부팅, 새 여정, 연속 소환, 편성, 전투, 결과, 덮어쓰기 확인, 360/390×667/데스크톱 로비 배치).

## 소스 구조

```text
card_claude/
  build.mjs         card/game 원본을 읽어 한 파일로 조립 (컨트롤러 3곳은 빌드 시 패치)
  src/shell.html    상단 바·하단 탭·타이틀·로비·편성·도감·학습·전투 마크업
  src/astra.js      화면 어댑터 (기존 RPG 메서드를 호출하고 화면만 소유)
  src/dream.css     새 디자인 시스템 (3:5 카드 프레임, 시트형 대화상자, 테마 토큰)
  src/*.css         card/src에서 가져와 이전 셸 규칙을 걷어낸 보조 대화상자 스타일
  tests/smoke.mjs   핵심 플레이 루프 검증
```

게임 데이터·규칙·테마 이미지·글꼴은 `card/`에서 읽고 복제하지 않습니다. 빌드 시 패치하는 곳은 세 군데이며, 원본 문장이 바뀌면 빌드가 실패해 알려줍니다.

1. 모드 목록 정의를 화면에 노출 (`RPG.modeDefinitions`)
2. 새 여정 시작: 덮어쓸 저장이 있을 때만 확인 1회 (기존: 저장이 없어도 2회)
3. 덱 편집 버튼 요약은 문구만 갱신 (버튼 구조를 덮어쓰지 않음)

## 설계 기준

가장 많이 반복되는 동선은 **소환 → 편성 → (축복) → 전투 → 결과 → 다시 소환·편성**입니다. 전투에서 쓰러진 카드는 소멸하므로 편성은 거의 매 전투마다 다시 합니다. 이 루프를 최소 탭으로, 한 화면 안에서 끝나게 하는 것을 우선했습니다.

| 화면 | 바뀐 점 |
| --- | --- |
| 공통 | 휴대폰 폭 한 열(데스크톱은 가운데 정렬). 상단 바: 화면 이름 · 소환 티켓 · 음악 · 전체화면 · 메뉴. 하단 탭: 로비 · 편성 · 도감 · 학습 · 미션(받을 보상이 있으면 점). 같은 화면 재진입 시 등장 애니메이션을 다시 재생하지 않음 |
| 타이틀 | 루미 키아트, 이어하기 버튼에 저장된 여정(모드 · 스테이지) 표시, 저장이 있을 때만 '새 여정 시작'. 포춘쿠키·질문·미션·음악은 아이콘 독 |
| 새 여정 | 엔드리스/도전 카드 2장 + 다음 여정 카드풀 설정. 모드는 이름·요약·목표·'패배 시 종료'·최고 기록·클리어 태그가 있는 목록, 고른 모드의 상세는 하단에 |
| 로비 | 다음 상대(초상화 포함)와 진행도, 3:5 파티 카드, 축복 버튼을 출전 버튼 옆에, 소환 3종(1회 · 최대 10회 연속 · 퀴즈 도전)과 확률 보기 |
| 소환 | 1회: 큰 카드 공개 + '한 번 더'. 연속: 결과 그리드와 등급 요약 |
| 편성 | 자동 편성, 배치 후 다음 빈 자리로 자동 이동, 카드에 배치된 자리 표시, 같은 카드를 다시 누르면 해제, 다른 자리 카드는 맞교환, 등급 필터, 카드마다 상세(ⓘ). 배치 변경 시 초상화를 다시 만들지 않아 깜빡임 없음 |
| 전투 | HP/MP 숫자, 파티 생존 표시, 피해·회복 숫자 표시와 짧은 피격 섬광(화면 흔들림 없음), MP 부족 스킬만 따로 표시 |
| 결과 | VICTORY/DEFEAT 패널: 얻은 티켓, 소멸한 카드, 새로 해금된 동료. 보너스 퀴즈 제안을 같은 패널의 버튼으로 (확인창 1단계 제거) |
| 기타 | 저장·불러오기·티켓 부족 같은 단순 알림은 토스트. 메뉴는 아이콘 목록 + 개인과외 이벤트 스위치. 미션 허브에 진행도·보상·수령 가능 표시. 카드 상세는 3:5 아트 옆에 능력치 표 |

저장 방식(수동 저장)과 게임 규칙, 확률, 보상은 바꾸지 않았습니다.
