# DREAMWEAVER · Argon Edition Design System

## 1. 디자인 목표: 상용 2D 서브컬처 모바일 RPG 수준의 미감과 밀도

기존 클로드 v2 빌드는 크로마키 잔상이 남은 AI 생성 배너·로고·`fx.webp` 이펙트와 과도한 `Jua` 폰트 사용으로 인해 전형적인 AI 슬롭 인상을 주었으며, 클로드 v3 빌드는 기능적 결함을 고치는 과정에서 배경 일러스트·장식 프레임·전용 카드 뒷면을 모두 삭제하여 테마 간 차이가 강조색(`--accent`)밖에 남지 않는 문제가 있었습니다.

**Argon Edition**은 오리지널 **Astra**의 날카롭고 세련된 아키텍처와 *블루 아카이브* · *스텔라 소라* 계열 2D 서브컬처 상용 게임의 명확한 계층 구조를 결합해 세 가지 테마 각각에 고유한 성소 배경·문장(Mark)·장식 벡터 프레임·카드 뒷면·표면 질감을 부여했습니다.

### 3종 테마 아이덴티티 (`src/tokens.css`)
- **드림스카이 (`dreamsky`)**: `dreamsky-sanctuary.svg` + `dreamsky-backdrop.svg` 푸른 하늘·구름·헤일로 링 성소 배경, `dreamsky-mark.svg` 초승달·별 문장, `dreamsky-frame.svg` 장식 프레임, `dreamsky-card.svg` 카드 뒷면, 청량한 화이트·시안 글래스 패널.
- **마법소녀 (`strawberry`)**: `magical-sanctuary.webp` + `magical-backdrop.svg` 핑크·크림 마법 성소 배경, `magical-mark.svg` 날개 하트·리본 문장, `magical-frame.svg` 로즈·크림 이중 프레임, `card-back-strawberry.webp` 카드 뒷면.
- **아스트라 (`astra`)**: `observatory.webp` 심야 천문대 배경, `astra-mark.svg` 천체 컴퍼스 문장, `astra-frame.svg` 골드·시안 세공 프레임, `astra-card.svg` 천체 카드 뒷면, 딥 네이비 프로스티드 글래스 패널.

## 2. 모바일 세로 화면(390×844) 핵심 UX 해결책

1. **상단 헤더(`#dw-top`) 폭 경쟁 및 버튼 잘림 제거**
   - 타이틀과 로비에서는 상단 도구를 간결하게 유지하고, 하위 화면 전환 시에만 필요한 도구를 노출하여 360~390px 모바일 화면에서도 우측 버튼 클리핑이 발생하지 않습니다.
2. **사전 덱 편집(`#modal-bonus-pool-editor`) & 인게임 파티 편성(`#screen-deck`) 4열 고밀도 카드 그리드**
   - 두 화면 모두 `repeat(4, minmax(0, 1fr))` 4열 그리드와 컴팩트 1줄 필터를 적용해 한 화면에서 최소 8~12장의 카드를 한눈에 비교·선택할 수 있습니다.
   - 카드 타일의 배치 번호/역할 배지(`.dw-card-slot`, 좌하단)와 보유 장수(`.dw-card-count`, 우하단)를 분리하여 절대 겹치지 않습니다.
3. **도감(`#screen-collection`) 이원화: `이번 여정` vs `도감(계정 해금)`**
   - 매 런 초기화되는 보유 목록에 무의미한 수집률을 표시하지 않고, `이번 여정` 탭에서는 현재 보유 카드를, `도감` 탭에서는 **보너스 해금 · 히든 해금 · 시즌 스페셜 · 보스 초월** 4개 영구 해금 트랙 진행도와 각 잠금 카드의 해금 조건을 안내합니다.
   - 등급 필터는 팝오버(`#grade-picker-open`)와 검색창 1줄로 압축해 화면 상단 점유율을 최소화했습니다.
4. **카드 상세 시트(`#modal-card`) 고정 높이 & 헤더 네비게이션**
   - 시트 높이를 `min(88dvh, 720px)`로 고정하고 내부 본문(`.modal-scroll`)만 스크롤되게 하여, 스킬 텍스트 길이가 다른 카드를 좌우로 넘겨도 프레임 크기가 전혀 흔들리지 않습니다(`heightDelta = 0`).
   - 이전/다음 화살표를 일러스트 위가 아닌 상단 바(`.dw-card-bar`)에 배치하여 3:5 카드 일러스트를 전혀 가리지 않습니다.
5. **전투 화면(`#screen-battle`) 로그 가독성 & 의미 기반 풀카드 컷인·방향성 벡터 VFX**
   - 전투 무대의 불필요한 상하 여백을 줄이고 `#battle-log`가 남은 세로 공간을 넉넉히 쓰도록 설계했습니다.
   - 좌측 아군과 우측 적의 위치에 맞춰 참격·관통 궤적이 실제 공격 방향으로 그려집니다.
   - 단순 3티어(30 MP) 여부가 아니라 **자폭(`suicide`), 변신(`transform`), 필드/디버프 전소모(`consume_field_all`, `consume_debuff_all`), 지연 발동(`isDelayed`), 적 보스 차징/필살 패턴** 등 실제 전투의 결정적 순간에만 컷인이 발동하며, 캐릭터 얼굴이 잘리지 않도록 **3:5 전체 카드 프레임**을 그대로 보여줍니다.
6. **포춘쿠키 알림 점(`.has-dot`) 동기화**
   - 포춘쿠키 사용 또는 모달 종료 시 `Astra.refreshDots()`가 즉시 실행되어 타이틀 및 학습 화면의 알림 점이 사라집니다.
