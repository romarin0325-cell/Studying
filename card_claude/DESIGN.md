# card_claude 디자인 기록

## 이전 판(v2)에서 버린 것

v2는 장면 배경, 효과 스프라이트, 테마별 로고, 결과 배너를 모두 생성 이미지로 만들었고 둥근 장식 글꼴을 썼습니다. 화면마다 따로 보면 화려했지만 함께 놓으면 결이 달랐고, 카드 일러스트와 경쟁했습니다. 요즘 2D 수집형 RPG(블루 아카이브, 스텔라 소라 등)는 반대로 갑니다: UI는 평평하고 조용하며 정확하고, 색과 감정은 캐릭터 일러스트가 맡습니다. 그래서 v3는 생성 이미지를 하나도 쓰지 않습니다.

## 원칙

1. **일러스트가 주인공**: 타이틀과 로비 배경은 플레이어가 가진 대표 카드의 일러스트입니다. 장식 배경을 따로 그리지 않습니다. 초상화 파일이 없으면 점 패턴의 조용한 바탕만 남고, 카드 뒷면을 크게 늘려 쓰지 않습니다.
2. **평평한 표면, 테마당 강조색 하나**: 흰(또는 남색) 면, 1px 선, 그림자 두 단계. 마법소녀(딸기우유)는 장미색, 드림스카이는 하늘색, 아스트라는 청록빛 파랑. 등급색은 모든 테마에서 같습니다. 그라데이션은 일러스트 위 가독성 스크림에만 씁니다.
3. **글꼴 하나**: Noto Sans KR(400–900 가변, SIL OFL 1.1)을 게임에서 쓰는 글자만 남겨 WOFF2로 넣었습니다(405 KB). 워드마크도 같은 글꼴의 굵은 기울임으로 만들어 어떤 테마에도 어울립니다.
4. **아이콘 한 벌**: 24 px 격자, 1.8 px 선, 둥근 끝으로 그린 SVG 기호를 모든 화면이 같이 씁니다. 그림 같은 아이콘이나 이모지를 섞지 않습니다.
5. **같은 화면은 같은 틀**: 모든 화면의 위 막대는 높이와 도구 위치가 같습니다. 편성처럼 무언가를 고르는 화면은 하단 탭 없이 뒤로 · 완료가 있는 하위 화면입니다. 게임 자체의 대화상자도 같은 토큰으로 칠합니다.
6. **연출은 의미를 따른다**: 3티어인데 보조인 기술도 있고, 2티어인데 전소모 핵심인 기술도 있습니다. 그래서 컷인과 흔들림은 티어가 아니라 실제 결과(큰 피해, 치명타, 자폭 · 변신 · 전소모 · 지연 발동, 적 차징과 필살 패턴)에 붙였습니다. 컷인은 얼굴 위치가 카드마다 달라 잘라내지 않고 카드 전체를 보여줍니다. 참격은 공격하는 쪽에서 시작합니다.

## 정보 구조에서 바꾼 것

- **수집률**: 런마다 인벤토리가 새로 시작하므로 '이번 런 보유 / 전체 카드'는 의미가 없습니다. 도감을 `이번 여정`과 `도감`(계정 해금)으로 나누고, 계정 쪽은 해금 경로별 진행도로 바꿨습니다.
- **카드 상세**: 시트 높이를 고정하고 넘기기 버튼을 위 막대로 옮겨, 카드마다 프레임이 흔들리거나 화살표가 일러스트를 가리지 않습니다.
- **배지 배치**: 배치 번호(왼쪽 아래), 보유 장수(오른쪽 아래), 속성(오른쪽 위), 상세(왼쪽 위)로 모서리를 하나씩 나눴습니다.
- **알림**: 짧은 확인 문구는 하단 토스트로 바꿔 위 막대 버튼을 가리지 않습니다. 포춘쿠키 · 미션 표시 점은 대화상자가 닫힐 때마다 다시 계산합니다.

## 다시 만들기

```sh
# subset-font@2가 설치된 임시 폴더에서 실행합니다.
CARD_CLAUDE=<repo>/card_claude node subset-font.mjs <NotoSansKR-VF.ttf 경로>
node card_claude/build.mjs
```
