# card_claude 아트 기록

모든 신규 이미지는 Gemini 이미지 모델 `gemini-3-pro-image`(Nano Banana Pro)로 만들고, `tools/prepare-art.mjs`로 휴대폰 크기 WebP로 변환했습니다. 원본 PNG(장당 2~3 MB)는 커밋하지 않습니다. 장마다 사용한 프롬프트, 원본과 결과물의 SHA-256은 `assets/art-manifest.json`에 있습니다. 카드·적 초상화는 새로 그리지 않았고 기존 로컬 PNG를 그대로 씁니다.

## 구성

| 파일 | 용도 | 크기 |
| --- | --- | --- |
| `{astra,strawberry,dreamsky}-title.webp` | 타이틀 키아트 | 720×1280 |
| `{…}-lobby.webp` | 로비 · 편성 · 도감 · 학습 배경(작업 화면은 베일로 흐리게) | 720×1280 |
| `{…}-summon.webp` | 소환 화면 | 720×1280 |
| `{…}-battle.webp` | 전투 무대(아래쪽은 기록·스킬용으로 어둡고 단순하게) | 720×1280 |
| `fx.webp` | 효과 아틀라스 4×2(참격·마법·회복·치명타·광선·마법진·방어막·타격) | 256 px 셀 |
| `logo-{astra,strawberry,dreamsky}.webp` | 테마별 DREAMWEAVER 로고(녹색 크로마키 제거) | 폭 880 |
| `banner-{victory,defeat,clear}.webp` | 결과 배너(크로마키 제거) | 폭 760 |
| `card-back-strawberry.webp` | 기존 마법소녀 카드 뒷면을 WebP로 축소 | 360×600 |
| `jua-subset.woff2` | 주아체를 게임에 쓰는 글자로 줄인 WOFF2 | 2,721자 |

효과 시트는 검은 배경에 그려진 원본을 밝기 기반 알파로 바꿨습니다. 그래서 blend mode 없이 밝은 테마와 어두운 테마, 대화상자 안팎 어디에서나 같은 모양으로 보입니다.

## 톤 · 글꼴 · 슬롭 검수

화면에 넣은 상태로 하나씩 보고 다음 기준으로 고르거나 고쳤습니다.

- **배경**: 기존 `magical-sanctuary.png`와 `observatory.png`를 팔레트 참고로만 주고 새 구도로 그렸습니다. 화면 위쪽은 로고, 아래쪽은 버튼이 앉을 자리라 조용하게 두라고 지시했고, 실제 화면에서 글자가 배경과 겹치지 않는지 확인했습니다. 드림스카이 타이틀 첫 결과는 하늘 윗부분이 평평한 띠로 끊겨 다시 만들었습니다.
- **로고**: 처음 만든 세리프 금박 로고는 아스트라의 관측소에는 맞지만, 마법소녀(딸기우유)의 리본 · 하트 장면과 둥근 주아체 UI 옆에서는 다른 게임의 로고처럼 보였습니다. 그래서 테마마다 로고를 따로 둡니다.
  - 마법소녀: 통통한 둥근 글자, 딸기우유 그라데이션, 자두색 외곽선, 날개 달린 하트 보석과 리본.
  - 드림스카이: 구름처럼 부푼 글자, 달 · 구름 장식.
  - 두 테마 모두 시안 두 개 중 화면에 넣어 보고 골랐습니다. 탈락한 시안은 붉은 쪽으로 치우친 손글씨와 지저분한 구름 소용돌이였습니다.
- **결과 배너**: 남색 외곽선과 흰색~금색 채움이라 밝은 테마와 어두운 테마 모두에서 읽힙니다.
- **효과**:
  - 회복·방어막 첫 결과는 흰 배경이라 다시 만들었습니다.
  - 효과는 0.55~0.8초 안에 끝나고, 화면 전체가 아니라 맞은 카드 위에서만 보입니다.
  - 만화풍 타격(`hit`)은 적의 공격에만, 육망성 마법진은 소환 공개의 어두운 무대에만 옅게 씁니다.
  - 소환 화면에서는 장면에 이미 그려진 마법진과 겹쳐 지저분해져서 덧씌운 마법진을 뺐습니다.
- **반짝임**: 등급 광채는 에픽 이상에만 씁니다. 레전드 프레임 포일은 5초에 한 번 지나가고, 타이틀·소환 화면의 떠다니는 빛 입자는 배경 한 겹으로 그립니다. 설정의 '소환 · 전투 연출' 끄기와 시스템의 동작 줄이기 설정을 따릅니다.
- **글꼴**:
  - 마법소녀 테마는 기존 주아체를 유지했습니다(2.1 MB TTF → 352 KB WOFF2).
  - 아스트라는 숫자와 워드마크에 세리프, 본문에 시스템 산세리프를 씁니다.
  - 드림스카이는 Segoe UI Variable을 씁니다.
  - 학습 본문은 모든 테마에서 읽기용 산세리프를 유지합니다.

## 다시 만들기

```sh
# 원본 PNG와 <id>.json(프롬프트·모델)이 있는 폴더를 넘깁니다.
node card_claude/tools/prepare-art.mjs <raw-dir>
node card_claude/build.mjs
```
