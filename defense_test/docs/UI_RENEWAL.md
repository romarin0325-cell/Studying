# 별빛 정원 UI 리뉴얼

작성일: 2026-10-08. 1부 구현 기록과 이후 계획이다.

## 방향: "밤의 정원" 고급화

- **색**: 깊은 남보라 밤하늘(`--bg`), 달빛 파랑(`--moon`), 별빛 금색(`--gold`). 기존 일러스트가 대부분 달밤 배경이라 이 방향을 골랐다.
- **질감**: 패널은 "밤 유리" 위에 얇은 금테(`--glass` + `--frame`). 행동 버튼은 금판(`.primary`), 보조 버튼은 남색 유리(`.secondary`).
- **움직임**: 화면 전환 시 등장, 버튼 누름 반짝임(`fx.js`), 주요 버튼의 빛줄기(`.shine`), 배경 별 반짝임. "연출 줄이기" 설정과 `prefers-reduced-motion`에서는 모두 꺼진다.
- **AI 슬롭으로 보였던 원인과 대응**: 모든 화면이 "남색 둥근 카드 + 노란 버튼" 한 틀이었고, 화면마다 주인공이 없었다. → 화면마다 무대(로비, 제단)와 주인공(파트너, 소환 대상)을 두고, 카드는 정보가 필요한 곳에만 쓴다.

## 1부에서 바꾼 것

| 영역 | 내용 |
|---|---|
| 디자인 체계 | `style.css` 토큰·셸·공용 부품 재작성. 상단 바는 홈·소환에서 무대 위에 투명하게 겹친다. 하단 내비는 메달 아이콘이고, 가운데 "모험"은 금색 구슬이다. |
| 홈 로비 | 파트너가 달빛 스포트라이트 위에 크게 선다. 캐릭터를 누르면 대사 말풍선과 하트가 나온다. 좌우 떠 있는 메뉴(임무·도감·인사·변경), 이달의 수호자 배지, 출격 금판, 출전 팀 띠, 방치 보상 카드. |
| 소환 | 나노바나나로 만든 "별의 제단" 배경 위에, 대상 동료가 빛 고리 앞에 떠 있다. 시즌·유물 배너는 색조가 바뀐다. |
| 소환 연출 | 최고 등급 색의 유성 낙하 → 섬광·충격파 → 카드가 뒷면으로 깔리고 순서대로 뒤집힌다. SR·UR은 뒤집기 전에 빛나고, 뒤집힌 뒤 빛기둥과 별가루가 튄다. 1회 소환은 전신 그림이 크게 나온다. 등급별 효과음이 있다. 화면을 누르거나 "모두 보기"를 누르면 바로 결과가 보인다. "N회 더" 버튼으로 이어서 소환한다. |
| 전투 유닛 정보 | 탭하면 얼굴·등급·역할·훈련 단계, 위력·공격 주기·사거리·방식, 특성 상태, 필살기 이름과 비용이 나온다. **필살기는 같은 동료 중 가장 높은 성급 개체가 쓴다**는 점도 함께 표시한다. "능력 자세히"를 펼치면 특성·필살기 전문과 지금 받는 효과(오라·버프)가 보인다. |
| 필살기 설명 | 필살기 버튼을 길게 누르면(0.48초) 쓰지 않고 설명 창이 열린다. 창에서 "바로 사용"도 할 수 있다. 창이 열려 있는 동안 전투는 멈춘다. |
| 설명문 | 30명의 특성·필살기 문장을 다시 썼다. 한 문장에 규칙 하나, 숫자는 분명하게 쓰고 엔진 동작과 일치시켰다. 동료 상세에는 위력·공격 주기·사거리·공격 방식 줄을 추가했다. |
| 로딩 | 별 문양과 ASTRA 로고가 있는 짧은 시작 화면. 최대 0.9초이며 입력을 막지 않는다. 자동화 브라우저에서는 생략한다. |
| 성능 | 시트가 열려 있으면 뒤 화면의 애니메이션을 멈춘다. 소환 연출 중에는 배경 블러를 끈다. |

## 2부에서 바꾼 것

| 영역 | 내용 |
|---|---|
| 이름 | **드림위버: 별빛 정원**. 루미의 칭호 "꿈을 짓는 마법사"가 본편 DREAMWEAVER와 같아, 외전임을 제목에 드러냈다. 상단 로고·시작 화면·전장 표기를 바꿨다. 저장 키는 기존 저장을 지키려고 그대로 둔다. |
| 정원 성장 | 모든 동료 공통 강화를 동료 상세에서 홈으로 옮겼다. 홈의 정원 배지에 레벨과 누적 보너스(+4% × (레벨−1))가 보이고, 누르면 다음 레벨 보너스와 비용이 있는 성장 창이 열린다. 동료 상세는 "정원 보너스 +N% 적용 중"만 보여 준다. |
| 별똥별 정원 | 방치 보상(시간당 별가루, 20시간 상한)은 그대로 두고, 시간이 지나면 로비 바닥에 별 조각(최대 9개)이 쌓여 보인다. 조각이나 "수집"을 누르면 별이 상단 별가루로 날아가고 파트너가 반응한다. |
| 일일 임무 | 원정 1회 완료·전투에서 합성 5회·별똥별 수집. 플레이하면 자연스럽게 깨지며 결정을 쓰게 만들지 않는다. 하루 1회 무료 일반 소환을 소환 화면 버튼으로 준다. 기존 저장의 소환·파견 임무는 이관된다. |
| 주간·월간 규칙 | 라운드 제한 시간을 없앴다. 월간은 "보스가 코어에 닿으면 종료"로 HUD·카드·결과에 표시한다. |
| 동료 상세 | 등급 색 무대(회전하는 빛살) 위에 캐릭터가 뜨고, 등급 이름·칭호·역할 칩을 보여 준다. |
| 결과 화면 | 승리 시 빛살과 금색 별 폭발, 보상 숫자가 올라가는 연출. 월간은 "보스 N체 격파"와 종료 이유를 보여 준다. |
| 길게 누르기 | 크롬에서 길게 누르면 글자가 선택되던 문제를 고쳤다(게임 화면 전체 선택·이미지 메뉴 차단, 누르는 동안 금색 테, 설명이 열릴 때 짧은 진동). |

## 지킨 것

- **인연 이야기 일러스트(30장)는 손대지 않았다.** 호감도 10의 보상이고, 미리 불러오지 않도록 테스트로 보호되는 자원이다. 소환·로비에서는 기존 전투 그림(SD)을 쓴다.
- 기존 테스트가 쓰는 버튼(`data-action`, `data-draw` 등)과 접근성 이름은 유지했다.
