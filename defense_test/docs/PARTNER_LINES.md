# 동료별 로비 대사 (2026-10-13)

출처: 각 동료의 인연 이야기, 시나리오 파일의 외모·보이스 톤 메모, 컨셉 메모. 데이터는 `src/lines.js`.

- **터치**: 파트너를 누를 때마다 일상 대사 3개를 차례로 보여 줍니다. 호감도 6부터는 친밀 대사 1개가 순서에 더해집니다.
- **인사**: 하루 한 번 인사 버튼을 누르면 인사 대사 2개 중 하나를 말합니다. 날짜에 따라 번갈아 나옵니다.
- **선물**: 좋아하는 선물을 받으면 전용 대사를 말합니다(`src/bond.js`).
