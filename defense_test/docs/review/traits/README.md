# 신규 특성 실제 화면 검토

2026-10-05. 독립 배포 파일 `defense_test/dist/StarGardenDefense.html`을 로컬 파일로 열고 실제 이어하기·동료 선택·필살기 버튼으로 검토한다. 저장 fixture는 브라우저를 켜기 전에 넣고, 실행 중 엔진 상태나 DOM을 바꾸지 않는다.

320×568과390×844에서 네 번개 연결, 두 아우로라, 등장 웨이브의 별똥별소년, 최고 성급 동률의 시간의지배자, 마지막 경로 구간의 지크를 함께 확인한다. 다른 fixture는 메이드·화염의 고정 목표 설명, 성장한 고래, 둠의25골드 비용을 확인한다. 폭풍 즉사는1%에 해당하는 결정적 난수 fixture의 실제 피해 처리로 캡처한다. 보스는 배제하고 일반 적의 보호막을 함께 소모한다.

정보창이 있는 작은 화면에서는 내용 영역을 스크롤해 설명과 회수·선택 해제 버튼에 접근한다. 모든 전투에서5개 필살기와 주 조작 버튼을 유지한다. 실제 Chromium과WebKit 검증은 추가로1280×900의 기본 전투 및 기존 수집·성장·파견·드래프트·저장·백업·결과 화면을 확인한다. [Chromium 경계/오류 기록](chromium-verification.json), [WebKit 기록](webkit-verification.json)을 함께 보관한다.

새 특성 오라의 모티프·수치·실패 기준은 [캐릭터 특성 보고서](../../CHARACTER_TRAITS.md), 기존30종 연출에서 과도한 후보는 [전체 효과 검토](../../EFFECT_REVIEW.md)에 기록한다. 화면 캡처는 물리 기기의 밝기·손가락 가림·발열·배터리를 대신하지 않는다.
