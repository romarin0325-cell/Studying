# 전투 성능 권고안 검토와 단발 측정

2026-10-05. 사용자가 현재 큰 프레임 드롭을 확인하지 않았다는 전제를 유지하고, 낮은 위험으로 불필요한 일을 줄이는 항목만 적용했다. 이 작업에서 비교 측정용 임시 스크립트를 사용했으며 상시 성능 측정·15분 루프·CI 벤치마크를 추가하지 않았다. CI에 있는 render/save 테스트는 가짜 시계로 스케줄과 저장 실패를 검사하는 짧은 기능 계약이다.

## 비교 조건과 재현 정보

- 기준 배포 파일: 최신 main `415e2b5c6d6bca69cf9c902b8943f754a0dd5058`의 Git blob. 변경 전 HTML을 현재 빌드로 대체하지 않고 고정된 Git blob에서 읽었다.
- 변경 후 소스: `753d6a06ee0bbb36e9938903ffd6ee9bde553ad5`. 같은 배포 입력을 가진 이후 문서 커밋에서도 HTML 내용은 같다. 별도 십자 광선과 동료 아래의 큰 공격 층까지 포함한 최종 배포 파일을 측정했다.
- Chromium 147.0.7727.15, headless, 뷰포트 390×844, 기기 배율 2. 엔진 seed `0x13579bdf`, 장식용 난수 seed `0x2468ace1`.
- 같은 직렬화 전투 fixture를 **브라우저 시작 전** 저장소에 넣고 실제 이어하기/스킬/일시정지 버튼을 사용했다. 실행 중 엔진을 바꾸거나 가짜 DOM으로 결과를 만들지 않았다.
- 네이티브 RAF 한 틱에 8.33ms 간격의 콜백 두 개를 전달해 120Hz 콜백 수급을 모사했다. 별도 드라이버는 매번 한 번만 예약해 콜백이 증식하지 않는다. 이는 실제 120Hz 디스플레이/GPU 측정이 아니다.
- 준비 시간 1.5초 뒤 일반 전투 8초, 일시정지 2.5초, 인위적 난전 8초, 그 난전에서 필살기 4초를 각각 측정했다. 난전은 25기 3성 동료와 45개 적(보스 5개 포함)을 둔 의도적인 스트레스 상태다. 일반 메인/월간의 보스 수를 주장하는 장면이 아니다.
- 기준과 변경 후를 **순차 단독 실행**했다. 앞선 시각 캡처와 겹친 진단값은 최종 보고서에서 제외했다. 브라우저 에뮬레이션/호스트 부하에 의존하는 단일 표본이다.

아래 CPU 시간은 전장을 그린 RAF 콜백 전체의 측정값이다(그 콜백의 시뮬레이션·HUD 작업 포함). GPU 시간, 브라우저 전체 CPU, 배터리 또는 최종 표시 지연으로 해석하지 않는다. WebKit은 오프라인 기능·저장·조작을 검사하지만 이 FPS 비교에는 포함하지 않았다.

원본 JSON에는 브라우저 버전, 실제 관찰 시간, 콜백 수, 시뮬레이션 시간, 저장 횟수, DPR, seed, 배포 파일/fixture SHA-256과 페이지 오류가 들어 있다.

## 관찰 결과

| 조건 | 전장 렌더/초 전→후 | 콜백 CPU 중앙값 ms 전→후 | p95 ms 전→후 | 구간 내 전투 저장 전→후 |
|---|---:|---:|---:|---:|
| 일반 전투, 8초 | 88.5 → 59.9 | 11.6 → 8.3 | 14.2 → 12.5 | 4 → 1 |
| 일시정지, 2.5초 | 120.3 → 12.0 | 0.3 → 0.4 | 0.5 → 0.7 | 0 → 0 |
| 25기/45적 난전, 8초 | 30.4 → 41.0 | 30.2 → 20.0 | 36.0 → 24.9 | 4 → 1 |
| 난전 필살기, 4초 | 27.8 → 38.2 | 28.7 → 19.5 | 41.4 → 26.3 | 2 → 0 |

일반 전투의 60회 상한은 초과 렌더를 줄이는 의도된 결과다. 난전은 이 환경에서 렌더 수가 약 35% 늘고 p95가 약 31% 줄었다. 실제 기기에서 60FPS를 보장하는 수치는 아니다. 일시정지에서는 약 90%의 전장 재그리기를 줄였다. 모든 측정 구간의 페이지 오류는 0이다.

표의 저장 횟수는 준비 시간을 제외한 구간 값이다. 입장, 웨이브 종료/상태 전환, 일시정지, 모달, 귀환, 숨김과 pagehide에서 수행한 별도 즉시 저장을 없앴다는 뜻이 아니다. `localStorage.setItem` 시간만 보면 JSON 직렬화/복원 검증 비용이 빠지므로, 그 작은 수치만으로 저장 최적화의 효과를 단정하지 않았다.

## 적용/보류 판단

| 권고 | 판단과 이유 |
|---|---|
| 60FPS 상한, 휴식 10~15FPS, 숨김 0 | 적용. 60/90/120Hz의 초과 재그리기를 막고, 타이밍 나머지를 이월해 작은 지터로 30FPS가 되지 않게 했다. 휴식은 12FPS, 시뮬레이션 20Hz는 그대로. |
| DPR·적응 화질 | 명시적 기본/고화질/절전 적용. DPR 상한 1.5/1.75/1.25. 기본은 DPR2 대비 픽셀 43.75% 감소. 작은 SD/초상/텍스트를 실제 화면에서 비교했다. 자동 화질 하락은 측정 필요성과 가독성 위험 때문에 보류했다. |
| 2초 동기 체크포인트 | 적용. 8초 간격에 idle job 하나만 예약하며 최신 run을 그때 직렬화. timeout 1.2초, 미지원 브라우저는 짧은 타이머. 필수 경계에서는 취소 후 즉시 flush. 저장 실패는 일시정지하고 성공적인 재시도 후 재개한다. |
| UI blur/backdrop-filter | 적용. 전투 중 본문 배경·경고·모달의 blur를 해제. 홈의 기존 연출은 유지. |
| HUD 캐시, 값이 달라질 때 갱신 | 적용. 주요 노드/5개 스킬 캐시, 게이지 transform, 같은 텍스트·수치 스타일을 재작성하지 않음. |
| 입자/충돌/활성 연출 예산 | 적용. 기본 파티클 180, 일반 충돌 64, 일반 효과 64. 고화질 240/80/76, 절전 100/40/44. 일반 충돌 장식을 먼저 버리고, 고정 대상·HP·실드·위험 예고는 엔진 상태에서 별도로 그림. 발동 연출은 동시에 최대 4개, 지속 상태/타이머는 모두 유지. |
| uid/좌표·합성 캐시 | 렌더 범위에 적용. 적 uid map과 프레임 좌표를 재사용해 투사체/적 그림 검색을 줄임. uid/종류/랭크가 달라졌을 때만 합성 가능 칸 갱신. 엔티티 배열 재사용. |
| combatStats 문자열 분리 | 적용. 공격/재사용 계산은 수치만 반환, 상세 요청에서만 보너스 설명 작성. 수치·주기를 비교하는 회귀 계약으로 동일성 확인. |
| 전부 source-over로 전환 | 신규 투명 전용 그림에만 적용. 기존 효과 아틀라스는 screen 합성에 맞춘 그림이므로 일괄 변경하면 검은 셀/색 변화가 생길 수 있어 유지했다. |
| 실시간 그라데이션/배경 | 이미 정적 배경 캐시가 존재. 반복되는 포털의 그라데이션만 캐시. 장식 필드의 구조 전체를 바꾸지 않음. |
| clearRect 제거 | 보류. 흔들림으로 배경이 캔버스 경계에서 이동하므로 지우기를 없애면 가장자리 잔상이 생길 수 있음. 측정상 큰 구조 변경이 필요하지 않음. |
| 모든 배열/객체 풀, 엔진 공간 인덱스 | 보류. 관찰된 문제보다 변경 위험이 큼. 충돌·상태·타깃/uid 의미를 바꾸지 않는 렌더 캐시에만 범위 제한. |
| ImageBitmap, 분리 캔버스, Worker/WebGL | 보류. 휴대폰 측정 없이 렌더·복원·오프라인 호환 구조를 바꿀 근거가 부족. |
| 오디오 전면 수정 | 보류. 현재 공격/명중은 80/55ms로 제한되고 생성 음은 짧게 종료됨. 비교는 음소거 조건이며, 새 보이스 구조가 필요한 병목 증거를 확보하지 않았다. |

저장 간격을 늘린 결과, OS 강제 종료처럼 숨김/pagehide 콜백조차 실행되지 않는 경우 마지막 예약 체크포인트 이후 약 8초(예약 지연 포함 최대 약 9.2초)의 전투 상태가 되돌아갈 수 있다. 정상적인 화면 전환·일시정지·귀환은 즉시 저장한다. 소환 재화/보상/월간 확정 같은 프로필 거래는 계속 즉시 원자적으로 저장한다.

## 검사한 범위와 한계

스케줄러와 저장 큐의 경계, 중복 예약 방지, 최신 상태 직렬화, 실패 보존/재시도, 실제 브라우저 저장 공간 부족·일시정지·귀환을 확인했다. 초기 팀은 성장 없이 3개 seed에서 메인 1을 실제 엔진으로 완료했다. 30명 기본/필살기, 8종 지속 상태를 게임 화면에서 보았고, 모바일/데스크톱 조작 및 월간 결과/보상 화면은 Chromium/WebKit으로 검사한다.

이 작업에서 **실제 Android/iPhone, 물리적 90/120Hz 패널, 발열·배터리·GPU 시간, 모바일 저장 지연, 15분 soak/반복 탭 장기 루프, 원격 측정 또는 장기 밸런스**를 검증하지 않았다. 지속형 스킬과 보스 정보의 가독성을 우선하므로 그 결과가 나오기 전에 더 공격적인 자동 해상도/연출 축소를 추가하지 않았다.
