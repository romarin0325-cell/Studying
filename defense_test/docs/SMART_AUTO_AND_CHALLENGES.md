# 합리 오토 · 밸런스 3차 · 주간/월간 리뉴얼 (2026-10-11)

## 1. 합리 오토 (시뮬레이션용 플레이어 모델)

`src/smart-auto.js`의 `smartAutoPlay(s)`.

- **쓰는 곳:**
  - 스테이지 모의전, 보스 점검, 주간/월간 점검, 필살기 실측 도구의 기본 오토 (`--ai basic`이면 이전 오토)
  - 전체 해금 테스트판의 인게임 오토
- **쓰지 않는 곳:** 정식판의 인게임 오토. 가벼운 보조 기능으로 그대로 둔다.
- 엔진의 공개 명령(소환, 이동, 합성, 회수, 훈련, 필살기, 축복)만 쓴다. 난수는 건드리지 않는다.

### 판단 규칙

모든 판단을 같은 기준으로 비교한다. 기준은 "유닛 가치"이고, 다음을 곱한 값이다.

- 위력 ÷ 공격 주기 (오라·조화·번개 연결 등은 엔진 `combatStats`가 이미 반영)
- 공격 방식별 평균 타격 수
- 사거리 안 경로 비율 (경로 뒤쪽일수록 가중치가 높다)
- 제어·증폭 계수: 눈토끼, 시간의지배자, 혹한의마녀, 은하고래, 팬텀, 가디언, 명탐정 등

시간의마술사는 이웃의 추가 공격 가치를 더한다.

| 상황 | 판단 |
|---|---|
| 배치 | 소환 직후 빈칸 중 가치가 가장 커지는 칸으로 옮긴다(오라 인접, 사거리). 판이 바뀌거나 4초마다 상위 10기와 지원형의 이동·교체 중 가장 좋은 수를 하나 둔다(이득 3% 이상일 때) |
| 합성 | 가능한 쌍 중 가치 증가가 가장 큰 것을 고르고, 결과가 놓일 칸도 고른다. 다음을 반영한다 |
| ↳ 합성 보정 | 별빛 +12, 둠 환급, 여왕 배당 감소(초반엔 따로 두는 편이 이득), 저주 해제 우선 |
| 소환 vs 훈련 | 골드당 가치로 비교한다. 소환은 짝이 있으면 합성 가능성을 더 쳐 주고, 판이 얇으면 가산한다. 훈련은 그 동료 전체 가치 증가로 잰다. 그래서 성급이 높은 주력부터 훈련하게 된다. 가장 좋은 선택이 곧 살 수 있으면 모은다 |
| 필살기 가치 | 실제 수치로 계산한다. 다음 행에 정리했다 |
| ↳ 가치 요소 | 피해(남은 체력까지만), 버프(팀 초당 피해 × 증가분 × 남은 전투 시간, 같은 종류 버프 중첩 규칙 반영), 제어(코어에 가까운 적 기준), 경제(골드의 가치 = 새 소환의 남은 판 가치 ÷ 소환 비용) |
| ↳ 트리거 | 루나 처형, 체리프린스 화상·성광, 지크 코어 절반, 메이드 기절·빙결, 화염 폭발, 별똥별 별빛 가득 등은 조건이 맞으면 가치가 커져서 자연히 우선된다 |
| 필살기 시점 | 아래 순서로 판단한다 |
| ↳ 1. 사랑의 시험 | 별빛 −60이 예고되면 먼저 쓴다 |
| ↳ 2. 위기 | 적이 코어 가까이 오면 쓴다 |
| ↳ 3. 넘침 | 별빛이 가득 차기 직전이면 쓴다 |
| ↳ 4. 경제 | 1·2웨이브에는 여왕·산타 필살기를 쓴다 |
| ↳ 5. 보스 | 보스가 있으면 별빛당 가치가 가장 높은 것을 쓴다 |
| ↳ 6. 보스 전 웨이브 | 쓰지 않고 별빛을 모은다 |
| ↳ 콤보 | 명탐정 노출과 아우로라 거울은 뒤따를 큰 필살기의 가치까지 쳐서 먼저 쓴다 |
| 둠 골드 | 보스 웨이브에 둠 필살기가 가까우면 85G를 남긴다(+3배) |
| 보스 대응 | 표시된 칸에서 가치가 큰 동료 2기를 안전한 빈칸으로 옮긴다. 천벌은 전부 옮긴다. 빈칸이 없으면 약한 동료와 자리를 바꾼다 |
| 저주 | 합성으로 푸는 것을 우선한다. 짝이 없는 2성 이하는 회수한다 |
| 축복 | 2성 합류, 새벽검(보스 직전 가치 ↑), 할인, 약속, 보급, 회복(체력이 낮을 때 ↑)을 같은 가치 기준으로 비교한다 |

## 2. 밸런스 변경

| 대상 | 변경 |
|---|---|
| 저주의 여신 | 저주를 등장마다 1회로 줄였다 |
| 토르 | 길 중간 천둥 심판(전원 4초 기절, 기절로 취소)을 바꿨다. 무작위 세로 3줄을 3.5초 예고한 뒤 그 칸만 3초 기절하고, 등장마다 1회다. 상시 패턴인 낙뢰 3칸은 그대로다 |
| 세이렌 필살기 | 공속 +50% → +30% (8초) |
| 에인션트드래곤 필살기 | 위력 +60%·10초 → +35%·8초 |
| 하모니어스 필살기 | 다른 종류 수에 비례하던 효과를 고정 위력 +15%·공속 +15%(8초)로 바꿨다. 이제 필살기 버프로 분류되어 배치 오라에 더해지고, 각성·가속과는 큰 쪽만 적용된다 |
| 둠 필살기 | 기본 12배 → 7배 (+훈련 단계, 남은 골드 20G마다 +1, 최대 +5) |
| 팬텀 | 일반 공격 3타 넉백을 없앴다. 덫 피해를 25% 내렸다 |
| 명탐정 | 일반 노출 10%/보스 18% → 8%/15%. 필살기 별빛 60 → 70 |
| 번개의현자 | 인접 보너스 +10/+18/+30% → +15/+30/+50% |
| 가디언 | 위력 58 → 67 |
| 루나 | 처형 기준을 일반·보스 모두 40%로 맞췄다. 강화 5단계마다 +2%p, 최대 50% |
| 은토끼 | 위력 24 → 26. 은빛 행진 공속 20% → 25%, 6초 → 8초 (필살기가 약해서 둘 다 올림) |
| 폭풍의현자 | 위력 30 → 34 (필살기는 경쟁력이 있어서 기본만) |

- **감속과 강화 (정정):** 감속은 이미 강화 5단계마다 +10%씩 오르고 있었다. 엔진의 `addSlow`가 강화 배율을 곱하고 상한은 80%다. 지난번 답에서 "안 오른다"고 한 것은 틀렸다. 상한이 있으니 기본 수치는 바꾸지 않았다.
- **둠 7배를 고른 이유:**
  - 별빛 비용이 60으로 다른 필살기(70~85)보다 싸서, 7배(위력 34 × 7 = 238)여도 별빛 1당 피해가 조건 없는 번개의현자(7 × 39 = 273, 비용 80)보다 약 18% 높다. 25G를 내는 대가가 이 정도는 돼야 누를 이유가 있다.
  - 훈련 2단계와 남은 골드 40G면 11배(374)다. 조건을 채운 지크(350)·메이드(384)와 비슷하다.
  - 모두 채우면 17배(578)로 둠만의 상한이 된다.
  - 실측(6장)에서 같은 덱 안 별빛 100당 가치는 둠 4.9, 조건 없는 혹한의마녀 2.8, 하모니어스 3.7, 신데렐라 5.9다.
  - 스테이지 모의전에서는 6·7·8·10배 결과가 5.09~5.11로 거의 같았다. 결과를 가르는 것은 필살기 배율보다 기본 위력과 환급이다.

## 3. UI

- **엄지 안전 여백:** 메뉴 상단 바는 최소 14px(노치가 있으면 그만큼 더) 아래에서 시작한다. 전투 독은 바닥에서 최소 18px 위에서 끝난다.
- **동료 카드:** 초상 옆에 짧은 세 줄(이름·성급, 위력·주기·훈련, 특성 한 줄)을 두고, 그 아래 버튼 한 줄(필살기, 목표, 회수)을 둔다. 132px 칸 안에 들어가 겹치지 않는다.
  - 특성 줄은 발동 중이면 청록색 점과 함께 강조된다.
  - 특성 표시가 없는 동료는 역할 문구를 보여 줘서 빈 줄이 생기지 않는다.
- **강화 기준 실제 수치:** 동료 상세의 특성·필살기 아래에 "현재 강화 기준 · 인접 공속 +18% · 지속 9.6초"처럼 강화가 반영된 값을 보여 준다(강화 5단계 이상일 때).
- **전투 ⓘ:** "이 동료가 주는 효과"를 추가했다. 예시는 이렇다.
  - 세이렌: 인접 몇 명에게 공속 몇 %
  - 하모니어스: 조화 종류 수와 수치
  - 명탐정: 노출 수치
  - 감속형: 감속량
  - 여왕·둠: 배당·환급
  - 루나: 처형 기준

## 4. 주간 드래프트 · 월간 보스전 리뉴얼

| | 쉬움 | 어려움 | 심연 |
|---|---|---|---|
| 해금 | 스테이지 3 | 스테이지 18 | 스테이지 36 |
| 체력 곡선 (메인 스테이지 환산) | 4 → 14 | 15 → 30 | 28 → 48 |
| 후반 추가 체력 | +120% | +200% | +340% |
| 주간 보상 배율 | ×1 | ×1.5 | ×2.2 |

- **공통:** 18웨이브(월간은 18보스)를 넘기면 완주다. 제한 시간은 없다.
  - 체력 곡선은 메인 스테이지 12웨이브 곡선 위에서 단계별 구간을 올라간다.
  - 18웨이브 동안 판이 크게 자라는 만큼 후반에 체력을 더한다(진행도 제곱).
- **주간:**
  - 2택 1 드래프트는 그대로다.
  - 3웨이브마다 보스가 나온다. 이번 주 보스 6종은 주 번호로 정해지고 준비 화면에 표시된다.
  - 보상: (100 + 웨이브당 25 + 완주 100) × 배율. 예: 쉬움 완주 650, 어려움 975, 심연 1,430
- **월간:**
  - 아홉 보스가 두 바퀴, 18연전이다. 보스가 코어에 닿으면 끝난다.
  - 기록 판정은 난이도가 우선이고, 같은 난이도면 격파 수, 그다음 총 피해다.
  - 보상: (100 + 격파당 35 + 완주 150) × 배율
- 기존 저장의 진행 중 도전과 기록은 쉬움으로 처리한다.

- **구조적 문제: 전역 버프 필살기가 전역 피해 필살기보다 별빛당 3~6배 약하다.**

  - 모든 적을 4~7배로 치는 필살기는 적 수만큼 곱해지지만, 버프는 팀 화력 × 30% × 8초 정도에 그친다.
  - 버프를 오라보다 약하게 둔 원칙은 맞지만, 그러면 버프 필살기는 거의 누를 이유가 없어진다.
  - 다음 조정 제안: 버프 필살기의 별빛 비용을 크게 낮추기(예: 40), 또는 작은 즉시 피해·부가 효과 붙이기.
- **조합 없으면 거의 무의미:** 아우로라 거울(1.5초). 뒤따를 큰 필살기가 있어야 의미가 생기는데, 그러려면 별빛 80 + α가 필요하다.
- **유난히 강함:** 가디언(17초). 위력 상향(67) 뒤 3배 전체 피해에 밀어내기와 기절이 겹쳐 12초 안 추가 피해가 크다. 기절 수치나 위력을 다시 볼 후보다.
- **12초 창 밖의 가치는 빠져 있다:** 산타 합류 유닛, 머쉬룸킹 독, 눈토끼 빙결의 생존 기여는 이 창보다 길게 남는다. 이 셋은 낮게 나온 만큼 할인해서 봐야 한다.
- 루미는 판에 남지 않고 합성 재료로 쓰여 표본이 없었다.

### 보스 체감 (합리 오토, 덱 5종)

| 사이클 | 승률 | 보스 웨이브 손실 | 일반 웨이브 손실 |
|---|---|---|---|
| 1 (1~9) | 60~100% | 0 ~ 6.5 | 거의 0 |
| 2 (10~18) | 35~70% | 4.3 ~ 8.7 | 0.6 ~ 0.9 |
| 3 (19~27) | 15~45% | 6.6 ~ 9.4 | 0.8 ~ 1.2 |

- **보스 웨이브 손실이 일반 웨이브의 7~10배다.** 합리적으로 플레이하면 잡몹은 거의 위협이 안 되고 보스가 승패를 정한다. 보스가 한두 스테이지 위 화력을 요구한다는 체감이 맞다.
- 다음 조정 제안: 보스 체력 배율 0.8 → 0.65 정도로 낮추고, 일반 적 체력을 소폭 올려 위협을 나누기.
- 저주의 여신은 1회로 바꾼 뒤 순서에 맞는 위치(사이클 1에서 85%)로 돌아왔다. 토르도 비슷한 위치다.
- **벨제뷔트가 사이클 2·3에서 가장 어렵다** (35%, 15%). 아스테아(45%, 30%)보다 낮다. 공간 붕괴(앞으로 순간이동)가 원인으로 보인다.
- **제어 덱의 강세:** 감속 상한 80%가 보스에게도 그대로 걸린다. 그래서 제어 덱은 30스테이지까지 거의 지지 않는다. 보스 감속 상한(예: 50%)을 다음 후보로 제안한다.
