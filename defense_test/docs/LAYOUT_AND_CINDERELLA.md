# 전투 화면 배치 · 신데렐라 리뉴얼 · 여왕/둠 2차 조정 · 점검 (2026-10-10)

## 1. 전투 화면 배치

모바일 세로 화면에서 전투 UI가 위로 몰려 있었다. 위쪽에는 여백이 없고 아래쪽은 비어 있었으며, 동료 카드가 전장 아래쪽을 덮어 드래그와 합성을 막았다.

- **전체 높이 사용:** 전투 화면을 세로 한 열로 짰다.
  - 위: 타이틀과 HUD
  - 가운데: 전장. 남는 공간 한가운데에 놓인다.
  - 아래: 독(dock). 화면 바닥에 붙는다.
- **타이틀:** 위쪽에 안전 여백(최소 12px, 노치가 있으면 그만큼 더)을 두었다. 스테이지 번호를 금테 배지로 표시하고, 스테이지 이름은 디스플레이 폰트로 바꿨다.
- **하단 독 구성:**
  - 정보 칸(132px). 평소에는 웨이브 띠를 보여 준다: 웨이브 진행 점(보스 웨이브는 왕관), 남은 적 수, 보스 줄(등장 전에는 "3웨이브 등장"과 보스 특성, 등장하면 체력 막대), 조작 안내.
  - 필살기 버튼
  - 소환·훈련·자동
- **동료 카드:** 정보 칸 안에서 열린다. 전장을 덮지 않는다. 자세한 효과(ⓘ 시트)는 길어서 지금처럼 전장 위에 띄운다.
- **작은 화면:** 정보 칸 때문에 전장 폭이 90% 아래로 줄어드는 화면(예: 360×640)에서는 정보 칸을 접는다. 이때 카드는 필살기·조작 버튼 위에 불투명하게 겹친다. 전장은 덮지 않는다.
- **전장 안 알림:** 보스 체력은 웨이브 띠로 옮겼다. 전장 안에는 보스 예고만 남겼다. 작은 화면에서는 예전처럼 보스 체력도 전장 안에 표시한다.

### 그 밖의 UI

- **상단 바:** 메인과 소환 화면에서 400px 이하일 때 로고, 재화, 버튼이 한 단계씩 작아진다. 로고는 재화 밑으로 파고들지 않고 잘린다. 금액 줄바꿈("12.8 / 만")도 막았다. 340px 이하에서는 로고 글자를 숨긴다.
- **홈 꿈의 온실 카드:** 360px에서 "꿈의 온…"으로 잘리던 문구를 "꿈의 온실" / "+N% 위력"으로 나눴다.
- **파견:** 각 슬롯에 해금 스테이지가 이미 적혀 있다. 그래서 아래쪽의 "9·18·27·36 클리어 시 하나씩 열립니다" 문구를 지웠다.
- **히든 동료 획득처:** 수호자는 매달 한 명씩 6개월 주기로 돈다. 그런데 모든 히든 동료에 "10월 시즌 소환에서만 획득"이라고 적혀 있어, 이번 달에 얻을 수 없는 5명에게는 사실과 다른 문구였다. 이제 동료마다 다음 등장 달과 반년 뒤 등장 달을 적는다. 이번 달 수호자라면 "지금 획득할 수 있다"고 적는다.
- **둠 설명:** "(또는 루미와)"를 지웠다. 동작(루미와 합성해도 환급)은 그대로다.

## 2. 보스 예고와 표적

- **표적 방식 확인:** 지금도 모든 표적은 무작위다. 최고 성급을 노리는 패턴은 없다.
  - 봉인: 무작위 한 행
  - 낙뢰: 무작위 동료 칸 3개 (모자라면 빈칸)
  - 기절과 천벌: 무작위 동료 칸 1개
  - 저주: 무작위 동료 1명
  - 재배치와 천둥 심판: 전체
- **예고 시간:** 표적이 있는 패턴(봉인, 낙뢰, 1칸 기절, 천벌)은 2.6초에서 3.5초로 늘렸다. 전체 대상 패턴은 2.6초 그대로다. 토르의 천둥 심판은 3초로 별도다. 천벌 빛기둥도 늘어난 시간에 맞춰 내려온다.
- **오토 플레이 영향:** 오토는 피하지 않으므로 클리어율은 거의 그대로다. 스테이지 1 기본 덱 60시드에서 98%가 97%로 바뀌었는데, 시드 타이밍이 바뀐 차이다.

## 3. 신데렐라 리뉴얼

컨셉 메모에서 신데렐라는 모두의 소망이 모여 나타난 전설이고, 시간의마술사(어둠의 신데렐라)와 짝을 이룬다. 그래서 단 한 명의 진짜 신데렐라와 자정의 시계를 중심으로 다시 짰다.

| | 이전 | 이후 |
|---|---|---|
| 기본 | 위력 26, 주기 1.05초, 단일 | 위력 26, 주기 1.0초, 단일 |
| 특성 | 세 번째 공격 1.8배. 최고 성급 1명만 위력 +50% | 최고 성급 1명이 진짜 신데렐라가 되어 위력 +50%. 공격마다 시계가 1시간 가고, 12번째 공격은 자정의 종: 보스(없으면 대상)에게 위력 10배, 반경 150 안의 적에게 3배 |
| 필살기 (65) | 적 전체 6배. 10초 동안 공격이 반경 100에 퍼짐 | 적 전체 3배. 10초 동안 진짜 신데렐라의 공속 +50%, 공격마다 시계가 3시간 감(4번째 공격마다 자정의 종). 시계는 0시로 맞춰짐 |

- **포지션:** 보스 저격이 주 역할이다. 자정의 종은 보스를 자동으로 노리고, 종이 울릴 때 주변을 쓸어 광역도 한다. 일반 공격은 "앞쪽" 표적을 유지하므로, 평소에는 앞줄을 치다가 종은 보스에게 떨어진다.
- **연출:**
  - 진짜 신데렐라 발밑에 12칸 시계판이 생긴다. 지나간 시간이 켜지고, 종 직전에는 금빛으로 깜빡인다. 필살기 중에는 분홍빛이 된다.
  - 종이 울리면 유리 별이 떨어진다. 이어서 시계 고리가 반경 150까지 퍼지고, 시계 문장과 유리 파편이 튄다. "자정의 종" 문구와 화면 흔들림이 함께 나온다.
- **카드 특성 줄:** "진짜 신데렐라 · 위력 +50% · 자정의 종까지 N회". 두 번째 신데렐라에는 진짜가 따로 있다고 표시한다.
- **저주:** 저주받은 신데렐라는 진짜 자격을 잃는다. 자격은 다음 신데렐라로 넘어간다.

## 4. 여왕과 둠 2차 조정

### 둠: 훈련과 합성의 충돌 해소

이전에는 합성 환급이 훈련 단계에 비례했다(18G + 훈련당 4G, × 재료 성급). 합성은 한 번 하면 끝나는 소모성 조작인데, 효율을 내려면 훈련을 먼저 해야 했다.

| | 이전 | 이후 |
|---|---|---|
| 기본 | 위력 20, 주기 1.2초, 관통 | 위력 34, 주기 1.1초, 관통 |
| 합성 환급 | (18 + 훈련×4)G × 재료 성급 | 50G × 재료 성급 (훈련과 무관) |
| 필살기 (60 + 25G) | 10배 + 남은 골드 20G마다 +1배 (최대 15배) | 12배 + 훈련 단계 + 남은 골드 20G마다 +1배 (최대 +5배) |

- 이제 합성은 언제 해도 같은 값을 돌려준다. 훈련은 필살기 기본 배율을 1배씩 올리는 평범한 성장이 됐다.
