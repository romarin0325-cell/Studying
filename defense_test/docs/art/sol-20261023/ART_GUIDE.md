# 이번 GPT 디펜스 SD의 재사용 기준

이 문서는 Sol이 원화와 과거 GPT 캐스트를 보고 이번 여섯 캐릭터를 독립 제작하며 사용한 기준이다. 다른 제작자의 결과·체형을 승인 마스터로 삼지 않는다. 생성기는 내장 `image_gen`이며, 다른 판단 모델/이미지 API를 호출하지 않았다. 숨겨진 이미지 모델 버전은 단정하지 않는다.

## 그림을 시작하기 전에

원화 전체와 가공하지 않은 얼굴 확대를 먼저 본다. 눈의 외곽·동공·눈꺼풀, 입과 이, 피부 색, 표정의 좌우 비대칭을 구체적으로 적는다. 설정은 표정 선택을 돕는 자료이며, 원화의 눈에 보이는 특징을 대신하지 않는다. 가려진 뒤나 발을 해석할 때는 원화에서 확정된 내용과 보완한 부분을 구분한다.

같은 캐스트의 기존 GPT 에셋 하나를 화풍 기준으로 선택하고 파일 해시를 남긴다. 이번 기준은 토피애플/해바라기=세이렌, 조커=별똥별소년, 언더독=지크, 큐어마스터=아발란체메이드, 베놈=여왕이다. 새 결과를 다음 새 캐릭터의 마스터로 이어 쓰면 화풍이 누적해서 변하므로 원래 승인본을 다시 사용한다.

## 공통 그림체

진한 남색의 의도적인 윤곽선, 안쪽보다 조금 강한 바깥 선, 큰 기본색과 명료한 셀 그림자를 사용한다. 작은 면을 전부 반짝이게 만들지 않는다. 머리는 제한된 띠 하이라이트, 피부는 작은 부드러운 명암, 금속은 적은 수의 강한 반사, 천은 큰 접힘으로 구분한다. 원화의 광택·매트한 부분 차이는 캐릭터별로 유지한다.

정면은 몸통과 얼굴이 정면을 향하고, 후면에는 얼굴이 없다. 좌우는 코가 각각 화면 왼쪽/오른쪽을 향한다. 카메라는 기존 캐스트처럼 조금 높은 직교 시점이다. 전면/후면의 소폭 고개 기울임을 옆을 보는 자세와 혼동하지 않는다.

## 비율과 기준점

머리는 얼굴과 두개골이다. 머리카락의 부피, 외이, 동물 귀, 모자, 꽃, 덩굴, 뿔, 후광, 무기는 포함하지 않는다. 노출된 피부만의 상자도 아니다. 이마·관자·뺨·턱과 귀가 붙는 위치를 보고 머리에 가려진 두개부를 수동 추정한다. 확신할 수 없는 경계와 방향별 추정을 기록한다.

512px 셀의 정면 두개부 면적은 기존 GPT 기준 160×150px다. 정면 상자의 면적에서 전신 균일 배율을 한 번 구하고 네 방향 모두 같은 값을 쓴다. 발은 `(256,480)`을 기준으로 평행이동한다. 머리/몸/다리를 따로 변형하거나 가로·세로를 독립해서 늘이지 않는다. 큰 머리 장식 때문에 외곽을 셀에 자동 맞춤하지 않는다. 셀 밖으로 나가는 장식은 다시 그려 해결한다.

몸이 길면 머리를 더 키우거나 얼굴만 덮어 씌우는 대신, 원래 얼굴의 인상을 유지하도록 요청하면서 작은 몸통·짧은 다리·의복 주름을 이미지 모델로 다시 그린다. 구체적인 현재/목표 발 좌표를 줄 수 있지만 모델의 지시 준수는 확인해야 한다. 요청 좌표를 실제 달성한 좌표로 기록하지 않는다.

## 네 방향은 같은 몸이다

손을 들거나 소품을 쥐는 쪽을 해부학적 좌우로 정하고 네 칸별로 적는다. 정면의 오른손은 화면 왼쪽, 후면에서는 화면 오른쪽이다. 왼쪽을 보는 옆모습은 왼팔이 가까우며 오른쪽을 보는 옆모습은 오른팔이 가깝다. 가까운 팔과 먼 팔의 가림도 검수한다. 후드가 한쪽만 올라가거나 윙크/문신/핀/팔찌가 다른 쪽으로 옮겨가면 다시 수정한다. 좌우 반전은 비대칭을 바꾸므로 기본 해결책으로 쓰지 않는다.

옆모습의 다리 굽힘과 머리 기울기 때문에 정면과 턱~발 투영이 다를 수 있다. 차이는 수치와 그림에 남기며, 방향별 다른 배율로 숨기지 않는다. 과도하면 해당 방향의 자세를 다시 그린다. 이번 파일은 방향별 대기 그림으로, 보행/베기 모션의 연속 프레임은 아니다.

## 전처리와 비교

생성 원본을 그대로 별도 보존한다. 실제 알파를 사용하며 색상 키로 흰 머리·옷을 지우지 않는다. 이번 원본의 250~255 알파는 255로 복구했고, 아주 약한 알파 잡음과 불투명 경계에서 떨어진 약한 배경 잔여물만 제거했다. RGB를 다시 칠하지 않는다. 실제 그림의 반투명 장식/마법이 있는 미래 에셋에는 이 정책을 자동 적용하지 말고 별도로 확인한다.

완성 PNG를 1024×1024로 패킹한 뒤 그 PNG에서 방향별 512×512를 추출한다. 이렇게 해야 별도 합성 과정의 알파 반올림 차이가 없다. 배포 WebP는 quality 95, alphaQuality 100이다.

숫자만 보고 승인하지 않는다. 같은 셀과 발 기준으로 기존 캐스트 옆에 세워 40·64·96px, 밝은/어두운 바닥, 같은 배율의 얼굴 crop을 실제로 본다. 얼굴을 각각 화면에 꽉 차게 확대해 놓고 머리 크기가 같다고 판단하지 않는다. 모자·꽃 때문에 전체 외곽 높이가 다른 것은 얼굴 크기와 별개로 평가한다.

규격·알파·그림 잘림·발 기준·파일 해시·방향 PNG와 아틀라스 픽셀 일치·오프라인 검토기를 검사한다. 수동 두개부 추정은 정확한 해부학의 자동 인증이 아니다. 실제 게임에 설치할 때는 별도로 전투에서 좌우 적을 두고 방향·가독성과 캐릭터 정보/소환/컷인 크기를 확인한다. 비교용 에셋 검수만으로 인게임 검증을 완료했다고 보고하지 않는다.

실제 프롬프트, 채택/탈락 사유, 마스터 및 출력 해시, 측정과 추정 오차는 `records/`에 있다. 외부 키나 다른 서비스 계정은 필요하지 않았다.
