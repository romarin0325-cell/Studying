# 전투 연출·월간 기록 후속 설계와 검증

2026-10-05. 기준은 최신 main `415e2b5c6d6bca69cf9c902b8943f754a0dd5058` (UI 수정 PR #577)이다. 하단 5개 메뉴, 어두운 남색 패널, 금색 출격 버튼, 캐릭터 초상/방향 아틀라스와 메인·수집 화면의 최신 구성을 유지했다. 이번 변경은 월간 도전, 전투 조작, 공격 가독성, 지속형 스킬과 근거가 있는 성능 개선에 집중한다.

## 월간 도전 화면과 보상

입장은 무제한이다. 전투 종료와 중도 종료는 기록만 저장한다. 같은 달의 최고 기록은 격파한 보스 수를 먼저 비교하고, 같은 수이면 실제 누적 피해로 비교한다. 더 낮은 기록이 최고 기록을 덮어쓰지 않는다. 최고 기록에는 종료 날짜, 총 피해, 전투 시간과 편성한 5명이 저장된다. 월간 최고 기록과 역대 최고 기록은 최근 30개 결과 목록과 별도로 유지한다.

월간 카드와 결과 화면에서 최고 기록을 크게 표시하고, 아래에 당시 편성과 받을 보상을 배치했다. 결과를 확인하자마자 재도전하거나, 보상 확인 화면에서 **그 기록의 토큰과 금액**을 확정할 수 있다. 이전의 월 1회 도전 보상 구조를 유지한다는 해석으로 **보상 확정은 달마다 1회**, 확정 후 입장과 최고 기록 갱신은 계속 가능하다. 무제한 입장마다 소환 재화가 지급되는 경제 변경은 요청 범위에 포함하지 않았다.

보상 공식은 `150 + 50 × 최고 기록의 격파 보스 수`이다. 기존 월간 난이도·보상 계수는 그대로 유지하고 지급 시점만 분리했다. UTC+9 매월 1일에 새 월간 기록/보상이 열린다. 월을 넘겨 종료한 시도는 **종료한 달**에 귀속하며, 역대 최고는 남는다. 주간 입장은 계속 주 1회다.

저장 데이터의 월간 입장 마커는 보상 확정 마커로 이관한다. 이전 버전에서 종료한 월간은 이미 자동 지급되었으므로 다시 지급하지 않는다. 이전 버전의 진행 중 도전은 아직 지급되지 않았으므로 종료 후 확정할 수 있다. 옛 결과에 없던 피해·시간을 만들어 넣지 않는다. 옛 최고 기록은 남아 있는 최근 결과에서만 복원할 수 있으며, 이미 삭제된 과거 최고는 복원할 수 없다. 이미 수령했지만 기존 결과가 삭제되어 금액을 알 수 없는 경우 UI는 금액 없이 수령 완료를 표시한다.

## 기본 조작과 전투 규칙

- 편성/해금은 기존 5명 그대로다. 새 전투의 전장에는 편성 5명 중 **서로 다른 랜덤 3명**을 삼각형 배치로 시작한다. 새 입장마다 저장된 난수 상태를 전진시켜 새 구성을 얻으며, 같은 저장 전투의 재개는 같은 배치를 유지한다.
- 이동·교환·합성은 드래그로만 한다. 다른 동료를 탭하면 그 동료의 정보를 표시한다. 빈칸 탭과 키보드 정보 탐색도 배치를 바꾸지 않는다. 드래그 시작 시 uid를 잡고, 드래그 동안 자동 배치 보조를 대기시켜 다른 동료가 옮겨지는 것을 막았다.
- 별빛 최대치는 엔진, 주간 전술 보정, 복원 검증, 게이지와 설명에서 120으로 통일했다. 스킬 비용·충전 속도는 그대로다.
- 별똥별소년/체리프린스는 발동부터 명중까지 0.3초다. 20Hz 시뮬레이션의 부동소수점 잔여 때문에 한 틱 늦게 명중하지 않도록 경계를 처리했다.
- 아우로라의 천만경은 3초간 피해를 기록하는 스킬이므로 3초를 유지했다. 일반 환영탄의 대기+비행은 0.06+0.24=0.3초로 줄였다. 표시 대상은 원래 고정 uid를 끝까지 따른다. 표적 사망 시 다른 적에게 몰래 재지정하지 않는다.
- 진행 중인 구버전 전투의 5기 배치와 남은 지연은 보존한다. 새 규칙은 새 입장/새 발동에 적용한다.

## 에셋과 화면 배치 판단

기준 자료는 이 게임의 기존 `finishers.webp`, `effects.webp`, 확장 효과와 캐릭터 SD 그림이다. 보석 조각, 가늘어지는 광선, 작은 별빛, 보라/청록/금/분홍의 역할별 색을 새 생성 아틀라스에도 사용했다. 새 인물 그림을 생성해 원래 캐릭터의 체형이나 정체성을 바꾸지 않았다. 16개 전용 모티프를 하나의 RGBA 4×4 아틀라스에 담아, 셀마다 16px 투명 여백을 두고 lossless WebP로 내장했다. 최종 게임의 로컬 텍스처는 44개다. [생성 프롬프트](ULTIMATE_ASSET_PROMPT.md), [크기와 SHA-256](ASSET_PROVENANCE.json)을 별도로 보관한다.

큰 발동 연출은 약 1.2초에 끝난다. 지속형 상태는 실제 엔진의 남은 시간과 총 시간을 저장·복원해 그린다. 캐릭터 발 주변의 낮고 작은 오라, 시전자 옆 문양, **스킬 버튼의 남은 초 표시**를 조합했다. 지속 시간을 숫자로 확인하면서 전장을 가리지 않기 위해 상시 전장 테두리 효과는 쓰지 않았다. 수치는 일시정지/모달에서 멈추며, 재개 후 그대로 이어진다. 조화 오라의 수신 표시는 실제 인접 동료로 제한했다.

보스 경고, HP/실드, 선택 범위와 타깃 고정 표시는 장식 파티클 예산과 별도로 그린다. 단일/도탄/체인 스킬에 전장 전체 색막을 깔지 않는다. 관통 공격은 길게 늘린 기존 래스터 투사체를 사용하고, 명중 시 추가로 그리던 원점~끝점 레이저 선을 제거했다.

## 합격 기준과 재검토

| 기준 | 판정 근거 |
|---|---|
| 기록/보상이 분리되고 반복 수령할 수 없음 | 월간 무제한 입장, 낮은 기록/동률/월 경계/수령 후 갱신/구버전 이관/동시 창/저장 실패 계약과 실제 결과→확정→재입장 UI |
| 탭이 이동하지 않음 | 실제 캔버스 탭·빈칸 탭·키보드 전후 uid 배열 동일, 실제 드래그 후 대상 칸 uid 이동 |
| 새 전투와 저장 재개가 구별됨 | 80개 분산 seed에서 3종·같은 seed 동일 결과, 새 입장 seed 전진, 중간 저장 재개 결정론 |
| 게이지/지연이 실제 엔진과 같음 | 120 저장·복원/초과 거부, 0.3초 명중 계약, 천만경 3초, 지속 시간 저장·일시정지 UI |
| 전용 래스터 그림과 HP/조작 가독성 | 30명 기본/필살기 및 8종 지속 화면을 실제 390×844 게임에서 캡처. 320×568/390×844/1280×900에서 조작 경계 검사 |
| 최적화가 저장 실패를 숨기지 않음 | 저장 실패 후 동결, 실패 중 재개/나가기 창 닫기에서도 동결, 저장 공간 복구 후 실제 재개·귀환 |
| 독립 게임/오프라인 배포 유지 | 루트 verify의 작은 매핑, 44개 로컬 텍스처, 잠긴 패키지, committed HTML 부팅, Chromium/WebKit 외부 요청·페이지 오류 검사 |

첫 시각 검토에서는 십자 공격의 눈 문양이 네 번 늘어나 반복되고, 은하고래 그림이 모인 적마다 겹치는 구성이 기준을 충족하지 못했다. 십자를 하나의 그림으로 클리핑하고 고래는 중심 하나에만 쓰도록 수정한 후 해당 화면을 다시 확인했다. 성능 측정과 시각 캡처가 겹친 임시 측정은 최종 비교에서 제외하고 브라우저 부하가 없는 단독 측정 결과만 저장했다.

[대표 화면](review/combat-polish/)과 [단발 성능 결과/한계](PERFORMANCE_REVIEW.md)를 함께 확인한다. 에뮬레이션과 저장된 전투 fixture는 실제 전투/모바일 UI를 검사하지만, 실제 Android/iPhone의 발열·배터리·장시간 터치 성능을 인증하지 않는다. 최종 필수 검증 결과는 아래 완료 시 추가한다.
