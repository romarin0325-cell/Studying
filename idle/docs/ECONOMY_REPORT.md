# 실제 전투 기반 경제 보고

저장소 루트에서 `npm run simulate:idle`로 재현합니다. 초기 9개 프로필의 180일 원자료는 [economy-long.json](economy-long.json), 추가로 검증한 집중 육성 후 전환은 [economy-focus-switch.json](economy-focus-switch.json)입니다. 현재 기본 명령은 전환 프로필도 포함합니다.

고정 시작 시각 2026-01-01 UTC, 동일 기본 RNG seed417, 실제 reducer와 20Hz 전투를 사용했습니다. 최고 단계=3×(레벨−1) 가정을 사용하지 않았습니다. 영웅마다 최대 네 번의 30단계 버튼 묶음을 실행하고 첫 패배에서 멈춥니다. 새 동료·유물로 편성이 달라지면 같은 세션에서 다시 시도합니다. 게임 UI 버튼 자체의 최대치는30단계입니다.

| 프로필 | 행동 |
|---|---|
| A | 하루1회 수령·성장·원정·소환·교류. 미보유 유물 우선, 추천 보스 최적화·모험 없음 |
| B | 하루2회 12시간 간격, 당일 편지와 추천 보스 연구 |
| C | B + 실제 패배 분석 후보 적용 + 주3회 보상 모험 |
| focus | 루미 우선, 남는 예산으로 다른 영웅 성장 |
| focus-switch | 첫28일 루미 우선, 이후 최저 레벨부터 균등 육성 |
| unlucky | 128개 seed 중 최초100회 동료 완성품이 가장 적었던 seed44 |
| starter | 소환을 전혀 사용하지 않고 초기5동료로 진행 |
| missed | 4일째 하루 결석 |
| comeback | 6~8일째 결석 후 복귀 |
| gates | 1회 세션에 세 선택 보너스 사용, 기본 A/B/C 가드와 별도 |

자동화한 세션 모델이며 실제 사람이 하루5분 안에 동일한 선택을 한다는 사용자 연구가 아닙니다. 장기 경제의 다양한 seed 분산과 실제 리텐션은 측정하지 않았습니다. 소환 확률·재료 기대값은 두 종류 각100만 회로 별도 확인했습니다.

## 조정과 해석

[조정 전28일](economy-baseline-v2.json)의 v2 관문 HP5,000·ATK55에서는 A 레벨101~102, 단계합계3,155, B/A EXP·골드1.1095로 기준1.10을 초과했습니다. [조정 후28일](economy-tuning.json)은 관문 HP10,000·ATK82.5로 A 레벨88, 단계합계2,075, B/A1.094입니다. 기본 시간 수율 30×(1+s/25) EXP·90×(1+s/25) 골드와 강화 비용은 유지했습니다. 수율 제수50 실험은 기본 수율 불변 조건 때문에 채택하지 않았습니다. 프로필별 숨은 보정은 없습니다.

28일 레벨88은 사양의 전투 미계산 참고치 약70보다 높습니다. 180일에는 대표 모델이 모든 원정1,200단계에 도달하며, 이후 성장은 레벨400·보스 티어50·장비·숙련·수집 중심입니다. 후반 신규 원정 콘텐츠가 무한히 제공되는 구조는 아닙니다.

후반 B/A가1보다 작아지는 데에는 하루1회 귀환 상자가 A의 약24시간 첫 수령과 B의 약12시간 첫 수령에 적용되는 차이가 있습니다. 방문 횟수별 비공개 지급 배율을 사용하지 않았습니다.

첫 시즌 전일 활동의 기억권은123장, 하루 결석은120장으로, 소환을 일일 과제로 요구하지 않아도 누적60회 선택권 두 번에 도달합니다. starter 프로필도 신규 소환 없이 필수 원정을 진행했습니다. 기억은 전투력을 올리지 않습니다.

전체 모델에서 레벨·장비·숙련·단계가 동시에3일 멈춘 구간은 없었습니다. 최소 한 성장 수치가 바뀌었다는 뜻이며 매일의 체감 재미를 보증하지 않습니다. 최종 브라우저에서는 실제 30일 편성의 상대 HP1%를 남긴 패배, 동일 엔진 분석, 무료 편성 변경과 재도전을 확인했습니다.

비완성 청동 이상10연 기대값은 동료4.1·기억4.2입니다. 제한된180일 실측 표본과 장기 확률을 혼동하지 않습니다. 각100만 회 검사는 공개 확률 ±0.1%p와 비완성 재료 기대값(동료1.85±0.02, 기억1.94±0.01)을 별도로 검사합니다.
