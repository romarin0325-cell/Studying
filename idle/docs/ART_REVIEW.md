# 그림 및 화면 배치 검토

원본 41점(전투 인물 29, 보스 10, 동일인물 변주·공동 모습 2)과 신규 기억 13점을 사용합니다. 기억 15점 가운데 2점은 기존 특수 그림입니다. 원본은 WebP 변환·비율 유지 축소만 했습니다. 출처 경로, 출처 SHA-256, 배포 SHA-256, 픽셀 크기, 동일인물 ID, crop=none, anchor를 [manifest](../assets/manifest.json)에 기록했습니다.

## 역할별 그림 계약

| 사용 기능 | 채움 방식 | 가로 그림 처리 |
|---|---|---|
| 홈 | contain, 이름표 구분 | 가로 전용 높이, 그림 아래 제목·인물, 두 사람을 모두 표시 |
| 이야기 | contain, 전체 보기 버튼 | 전체 장면 표시 후 대사를 별도 영역에 배치 |
| 기억 카드·감상 앨범 | contain, 썸네일도 원본 비율 | 두 열 너비를 사용 |
| 전투 | contain | 실루엣 변형 없이 전투 프레임 내부 배치 |
| 확대 보기 | contain, 1~3배 확대와 초기화 | 초기 상태는 전체 구도, 확대 후 스크롤 |
| 인물 선택 아바타 | cover | 인물 식별용 작은 아이콘에만 크롭 허용 |

코드 계약은 `src/ui/art.js`, `styles/base.css`에 있습니다. 새 그림은 기능별로 별도 파일을 복제할 필요 없이 manifest의 실제 크기로 분기합니다. 원본 파일 자체의 가로세로 비율을 변경하지 않습니다. 54장의 내부 썸네일은 화면 로딩 시 전체 해상도를 한꺼번에 디코딩하는 부담을 줄입니다.

## 재작성 네 장

- `bond_jasmine_01`: 책상에 앉은 상체를 새로 그려 어깨가 과도하게 넓어 보이던 구도를 조정. 은보라 머리·푸른 눈·흰 의상·금관 보존.
- `archive_queen_01`: 얼굴/머리 존재감이 커지도록 스탠딩을 재작성. 백색 겉옷·붉은 치마·장미 지팡이·방사형 관 보존.
- `archive_zeke_01`, `bond_zeke_01`: 머리의 비중을 키운 새 스탠딩·책상 장면. 붉은 머리·검붉은 갑옷·망토·검과 남성 정체성 보존.

추가 비율 재검토 요청을 받아 지크·여왕 스탠딩 두 장은 한 번 더 새로 그렸습니다. 머리 장식이 아닌 얼굴과 두개부의 비중을 키웠고, 의상·성별·인상은 원본에 맞췄습니다. [이전/재작성 비교](review/standing-redraw-comparison.jpg)와 [최종 생성 프롬프트](standing-redraw-prompts.json)를 남겼습니다. 내장 image_gen을 사용했습니다.

## 화면 증거

[모바일 공동 기억 홈](review/mobile-shared-home.png), [공동 기억 확대](review/mobile-shared-viewer.png), [모바일 앨범](review/mobile-album.png), [스토리](review/mobile-story.png), [PC 홈](review/desktop-home.png)을 함께 확인합니다. 자동 브라우저 검사는 contain 설정, 3:2 원본, 공동 기억 인물 이름, 확대/초기화, 이미지 디코딩 실패, 360/390/1280 너비의 넘침을 확인합니다.

그림의 주관적인 미적 만족과 실제 휴대폰에서의 색·열·메모리는 자동 검사로 보증하지 않습니다. SD 스타일 자산을 섞지 않고 원본과 기억을 중심으로 화면을 구성했습니다.
