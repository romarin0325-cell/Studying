# 검증 기록

최종 로컬 `npm run verify`가 통과했습니다. 전체 실행 로그는 [verify-run.txt](verify-run.txt), 브라우저 결과는 [browser-evidence.json](browser-evidence.json)입니다. 소스와 배포물 검증 후 Ready PR의 CI도 별도로 확인합니다.

## 실행 환경과 배포물

- Windows, Node24.13.1, Playwright Chromium147.0.7727.15, headless.
- 실제 `file://` 독립 HTML을 네트워크 차단 상태로 실행했습니다.
- 화면 크기 360×800, 390×844, 1280×720. 실물 모바일 결과가 아닙니다.
- HTML 약13.67MiB. 54개 전체 그림과 54개 비율 유지 썸네일 내장. 목표35MiB 이하.
- SHA-256: `1c60bc5ade114a3c6e6cda3086ad127819d6b28ced60c0be19cc09441ae1c9cf`.
- Card·Shooter·Defense 런타임 테스트 및 배포물 빌드는 실행하지 않았습니다.

기본 verify에 장기 시뮬레이션을 넣지 않았습니다. 최초 출시 범위여서 경제 검증을 명시적으로 실행했습니다. 이후 테스트·문서만 바뀌면 빌드나 다른 게임 런타임을 불필요하게 선택하지 않습니다.

## 단위 계약 증거

- 123개 장면의 고유 ID·본문·분류·행 수, 90개 홈 문장, 15개 기억, 54개 이미지 크기·SHA-256·검토 상태.
- 24시간 미수령 상한, 수령 빈도별 동일 기본 보상, 과거 수율 구간과 정수 나머지, 날짜 경계·시계 역행.
- 중복 명령·오래된 revision 차단, 프리셋/동료/유물 중복 방지, 전투와 무관한 관계·기록이 전투 RNG를 바꾸지 않음.
- 문법 강의 선행, 오답 무차감, 2/4/12/24시간 귀환 증폭, 광석·티켓 제외, 가호 30분과 다음 날 보관, 정상 추가 소환·공용 한도.
- 두 소환 종류 각100만 회 분포 ±0.1%p, 비완성 재료 기대값, 초보 보장·누적 선택권·중복 보상.
- 기억권123/120, 소환 없는 일일 완료, 시즌 아카이브/복각과 동일 그림 보상 중복 방지, 편지 보존, 상자/별나비/반짝 흔적 한도.
- 혼합 피해·속성·치명 처리, 1/2/4배·빠른 결과 digest 일치, 24지원×5영웅, 10보스/유물, 12임시 유물 실행.
- DoT 마지막 tick, 전투 시작 방어 구간, 지크 치명상 생존 한 번, 아스테아 영웅별 최고점과3.5/5.0 기준.
- 최대8후보 분석과 실제 적용 후 전투 일치. 지원 동료 등급을 바꿀 때도 loadout·seed가 같은지 회귀 검사.
- 모험 재시도 시드, 소유하지 않은 숙련 운용 미해금, 초기 지원 동료로 대표 경로 완료.
- 백업 왕복·미래 버전·음수·위험 키·초대형 입력 거부, 알려지지 않은 기억 ID 보존.

## 실제 배포 HTML 시나리오

1. 새 저장 안내, 실제 성장 구매, 관전과 결과 확정.
2. 10회 소환 공개 도중 새로고침, 저장된 동일 결과 재개, 오답 뒤 정상+1회.
3. 12시간 원정 보상을 먼저 받은 뒤 강의→문제→무료 재시도, 정확한4시간 증폭과 가호.
4. 7일 저장에서 다섯 대표 영웅, 이야기·건너뛰기·그림 보상.
5. 세로·가로 혼합 앨범, 공동 기억 홈 제목/인물 표시, 전체 비율·확대·초기화.
6. 30일 보스 화면, 실제 지원 배속 교환, 같은 시드 모험 재시작과8노드 완주.
7. 실제 30일 편성의 상대 HP1% 근접 패배, 동일 엔진 분석, 숙련 스타일·전술 두 변경 후 재도전.
8. 하루 결석 후 시즌 최종 기억,3일 결석 후 복귀 가호 fixture.
9. 세 화면 크기에서 다섯 탭 가로 넘침 없음.
10. 실제 두 탭의 같은 revision 구매 경쟁에서 정확히 한 거래만 성공, 새로고침 후 유지.
11. 미래 버전 가져오기 실패 후 정상 저장 보존, 정상 백업 가져오기, 최근2개 백업 유지.
12. IndexedDB 차단 시 localStorage, 저장 용량 오류 시 재화·RNG 지출 취소, 두 저장소 차단 시 상시 경고.
13. 키보드 Enter/Escape 그림 뷰어, 한 이미지 손상 시 대체 이름과 버튼·다른 화면 사용 가능.

외부 HTTP 요청0, 처리되지 않은 페이지 예외0입니다. 이미지 실패 회귀에서는 의도적으로 한 개의 이미지 오류 로그를 발생시켰습니다. 로그를 숨겨 정상 로드로 판정하지 않았습니다.

## 남는 한계

실물 Android/iOS의 터치·백그라운드 종료·RAM·발열·브라우저별 파일 저장 정책은 확인하지 않았습니다. Safari/WebKit·Firefox 동작과 실제 사용자5분 소요 시간, 입력100ms/분석500ms 목표의 별도 성능 측정, 장기 재미·접속률·리텐션도 인증하지 않습니다. 대표곡은 음원이 없어 비활성 ‘제작 중’입니다. 자동 시뮬레이션이 오래 실행된다는 사실과 장기 재미를 구분합니다.

그림의 객관적인 파일·레이아웃 계약은 자동 검사했으며, 외형·의상·비율은 [이미지 비교표](ART_REVIEW.md)와 실제 화면을 육안 검토했습니다.
