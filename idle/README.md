# 별의 동행 · ASTRAL COMPANIONS

다섯 영웅을 영구 육성하며 하루 한두 번 돌아와 원정 보상, 성장, 소환, 짧은 이야기를 이어가는 개인용 방치 RPG입니다.

## 실행

[독립 실행 HTML](dist/AstralCompanions.html)을 브라우저에서 엽니다. 게임 코드, 학습 데이터, 그림과 썸네일이 모두 들어 있으므로 네트워크가 필요하지 않습니다. 브라우저 데이터는 같은 파일 위치와 브라우저에 종속될 수 있습니다. 이동 전 설정에서 JSON 백업을 내려받을 수 있습니다.

- 다섯 원정: 각 영웅의 다음 관문을 관전하거나 영웅당 최대 30단계씩 빠르게 진행합니다.
- 영웅: 레벨·장비·숙련, 서로 중복되지 않는 동료·유물 배속, 무료 전술 변경, 용도별 프리셋을 관리합니다.
- 교류: 관계점으로 장면을 열고, 건너뛰어도 같은 보상을 받으며 다시 읽습니다.
- 수집: 동료 24종, 기억 15종, 누적 선택권, 지정 교환, 원본 비율 감상 앨범을 제공합니다.
- 작은 모험: 여덟 노드의 사건·전투·임시 유물을 고릅니다. 보상은 장식용 배지이며 필수 성장과 분리됩니다.

## 선택 학습 보너스

기본 보상은 먼저 전액 지급합니다. 그 뒤 귀환의 별(문법 강의→문제), 10연 뒤 별빛의 잔향(숙어), 종료 전 원정의 가호(단어)를 각각 하루 한 번 선택할 수 있습니다. 오답에는 비용이 없고 세 종류를 모두 사용해도 연쇄 보상은 없습니다. 가호의 30분 보너스는 다음 날 받아도 남아 있습니다.

## 개발과 검증

저장소 루트에서 `npm ci`, `npm run build:idle`을 사용합니다. 기본 개발 진입점은 `idle/index.html`이며 ES module을 제공하는 로컬 HTTP 서버에서 열 수 있습니다. 배포 검증 대상은 `idle/dist/AstralCompanions.html`입니다.

```sh
npm run verify:plan
npm run verify
npm run simulate:idle
```

마지막 명령은 초기 출시·경제식 변경 시 별도로 실행하는 180일 시뮬레이션입니다. 기본 verify에 장기 시뮬레이션이나 다른 게임의 테스트를 넣지 않습니다. 브라우저 검증에는 Playwright Chromium이 필요합니다.
