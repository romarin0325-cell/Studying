# DREAMWEAVER · Astra

아스트라의 세리프 워드마크, 하늘과 관측소, 파티 3장을 중심에 둔 구성을 다듬은 독립 UI 버전입니다. 원본 `card/`와 비교 버전 `card_claude/`는 그대로 유지합니다.

**실행 파일: [dist/DREAMWEAVER-Astra.html](dist/DREAMWEAVER-Astra.html)** — 다운로드 후 브라우저에서 엽니다. [화면 미리보기와 확인 범위](docs/REVIEW.md)도 함께 볼 수 있습니다.

## 실행과 빌드

저장소 루트에서:

```sh
npm ci
npm run build:card-astra
npm run serve --prefix card_astra
```

미리보기 주소는 `http://127.0.0.1:4181`입니다. 배포 파일은 약 3.2 MiB의 단일 HTML입니다. 코드·학습 데이터·화면 이미지·Noto Sans KR 서브셋을 포함하며, 화면 실행에 CDN이나 원격 글꼴이 필요하지 않습니다.

개인 캐릭터 PNG와 음악 MP3는 기존 파일명 그대로 HTML 옆에 놓습니다. 폴더가 다르면 설정에서 초상화 폴더를 지정하거나 선택하세요. 이미지가 없을 때는 테마의 카드 뒷면을 표시합니다. AI 질문·과외 등 기존 외부 서비스 기능의 API 키와 네트워크 요구는 동일합니다.

## 달라진 화면

- **로비:** 파티 3장과 다음 상대를 먼저 보여주고, 출전을 유일한 주 버튼으로 강조합니다. 이미 구성된 파티의 반복 설명은 줄였습니다. 짧은 모바일에서도 출전·두 소환 버튼·미션·축복에 접근할 수 있습니다.
- **편성:** 하단 탐색을 잠시 숨기고 완료 버튼을 고정합니다. 이름·속성·역할·등급 검색, 3열/4열 선택, 배치 번호, 카드 상세 버튼, 선택 자리 비우기를 제공합니다. 모바일 기본 3열에서는 390×844 기준 카드 6장을 완전히 보여줍니다.
- **도감:** 이번 여정의 보유 목록과 전체 도감을 구분합니다. 영구 해금 수치와 잠금 여부는 기존 계정 데이터에서 읽고, 획득 경로는 상세창에 표시합니다. 도감 열람으로 카드를 지급하지 않습니다.
- **카드 상세:** 3:5 초상화 옆에 능력치 숫자를 정리하고, 고정 높이 창 안에서 본문만 스크롤합니다. 현재 목록을 이전/다음 버튼 또는 좌우 화살표로 탐색합니다. Escape로 닫으면 상세를 열었던 버튼으로 포커스가 돌아갑니다.
- **전투:** 실제 HP·MP 숫자, 스킬 유형과 비용을 구분합니다. 상태 영역은 높이를 예약하고 기록과 하단 스킬에 공간을 남깁니다. 기존 스킬 설명·비용·실행 콜백을 그대로 사용합니다.
- **학습:** TOEIC을 주요 행동으로 두고, 나머지 활동은 간결한 목록으로 정리합니다. 진행 수치는 실제 이번 여정의 퀴즈 기록입니다.
- **테마:** 아스트라·드림스카이·마법소녀의 그림과 색은 유지하되 같은 글꼴과 배치 규칙을 적용합니다. 모션 감소 설정도 유지합니다.

3열/4열 버튼은 모바일 기준입니다. 넓은 화면에서는 각각 5열/7열로 확장합니다. 열 수만 기기에 저장하며, 게임 저장 형식은 바꾸지 않습니다.

## 소스와 호환성

| 경로 | 역할 |
| --- | --- |
| `src/shell.html` | 주요 화면과 새 카드 상세의 마크업 |
| `src/edition.css` | 아스트라 전용 색·여백·타이포·반응형 표현 |
| `src/edition.js` | 목록 밀도·검색·상세 이동·수치 표시 어댑터 |
| `build.mjs` | 공유 게임과 UI 지원 코드를 단일 HTML로 조립 |
| `assets/` | 압축 배경, 새 천문도 카드 뒷면, 글꼴과 라이선스 |
| `tests/smoke.mjs` | 변경된 UI와 실제 플레이 흐름 검증 |

규칙과 저장은 `card/game/`가 소스 오브 트루스입니다. 초상화 로딩, 저장 내보내기/가져오기, 중첩 모달 접근성은 `card/src/astra.js`를 공유합니다. 기본 CSS도 `card/src/`에서 읽고 새 표현을 마지막에 적용합니다. **`card_claude/`나 삭제된 DeepSeek 폴더에 빌드 의존성이 없습니다.** 원본 게임의 모드·보상·밸런스를 재구현하지 않습니다.

기존 버전과 저장 키는 같지만 브라우저와 파일 경로가 달라지면 저장 공간도 달라질 수 있습니다. 기존 버전에서 저장 후 **설정 → 기록 내보내기**, 새 버전에서 **기록 가져오기**를 사용하세요. API 키는 내보내지 않습니다.

## 검증

```sh
npm run test:card-astra
```

기본 검증은 Playwright Chromium에서 `file://`로 엽니다. 실행 환경 정책이 로컬 파일 탐색을 막는 경우 동일 HTML을 임시 로컬 서버로 제공하는 검증을 사용할 수 있습니다.

```sh
ASTRA_TEST_HTTP=1 CHROMIUM_PATH=/usr/bin/chromium npm run test:card-astra
```

테스트는 신규 게임·소환·편성·저장 복원, 상세 이동과 포커스, 도감과 학습, 전투 승리, 360×640·390×844·1440×960 배치, 세 테마의 출전 버튼 위치를 확인합니다. 버튼의 화면 좌표뿐 아니라 실제로 다른 요소에 가려지지 않았는지도 확인합니다. 결과는 `test-results/`에 저장됩니다.
