# UI 방향: 새벽 꿈 (2026-11-21, Claude 직접 작업)

소유자 요청(11-21 오후): 지금 UI는 "AI 슬롭" 그 자체이니, 가볍고 밝은 일본 트렌디 서브컬처 게임 UI를 도트에 접목한다. 참조 게임에서 공통으로 나타나는 디자인·배치·버튼·색감·연출을 확인해서 적용하고, 흐름·메뉴·배치·시각적 느낌도 필요하면 같이 고친다. 목표는 상용 게임에 준하는 세련된 UI. 같은 지시를 제미나이와 GPT에게도 주고 결과를 비교한다.

그래서 이번 작업은 GPT(Astra·Sol)에게 맡기지 않고 Claude가 조사·설계·구현·검수를 모두 했다. 비교가 섞이지 않게 하려는 것이다. 작업은 별도 브랜치 `claude/relaymare-ui`(작업 폴더 `Studying-card-pixel-ui`)에 있고, main의 게임 규칙·수치·문구(제미나이 문구 수정 PR 694·695 포함)는 바꾸지 않았다.

## 1. 도트 어비스·달토끼 키우기는 도트 서브컬처인가

둘 다 "도트 전투 + 서브컬처 캐릭터 매력"이라는 점에서 도트 계열 서브컬처라고 볼 수 있다. 다만 UI는 둘 다 밝은 트렌디 계열이 아니다.

- **도트 어비스**(DMM GAMES, 일본 2026-06-11 출시): "도트 그림 × 심연 탐색 RPG", 방치형 수집 RPG. 도트 캐릭터가 걸어 다니는 아이소메트릭 거점, 도트 그림 퀘스트 카드. 메뉴에는 고해상도 애니 일러스트를 쓰고 UI 자체는 도트가 아닌 벡터(남색·보라 바, 노란 수령 버튼, 파란 선택 탭, 분홍 마름모 장식, 모서리를 깎은 말풍선). 제목 일부만 도트 글꼴. 성인향 버전도 있는 게임이다.
- **달토끼 키우기**(Able Games): 한국 "키우기"류 방치형 액션 RPG. 전투는 도트, 동료는 애니 일러스트. UI는 남색 우주 테마의 촘촘한 방치형 UI로, 세련된 참조로 쓰기는 어렵다.
- 공통점: 캐릭터와 전투는 도트여도 UI·메뉴 연출은 도트가 아니다. 소유자 말대로 "도트 게임이라고 UI까지 도트일 필요는 없다"를 두 게임 모두 그대로 보여 준다.

### 관찰한 구체적인 모양

- **스텔라 소라 홈**: 캐릭터가 화면 중앙에 크게 서고 말풍선으로 말을 건다. 왼쪽 위 레벨 배지(청록 테두리 핀 모양)와 반투명 흰 자원 바(오른쪽 끝이 비스듬함, 남색 "+" 원). 오른쪽 아래에 반투명 흰 원형 버튼 무리. 원 안에 컬러 일러스트 아이콘이 원 밖으로 튀어나오고, 이름은 흰 글자에 남색 외곽선. 가장 큰 원이 "出発"이고 그 아래 자홍색 리본에 현재 진행("暴風と雷光 難易度2 第10層")이 붙는다.
- **스텔라 소라 선택 화면**: 남색 평행사변형 제목 띠("運命カードを1枚選択しましょう!", 숫자만 노랑). 카드는 흰 몸통 + 무늬 있는 색 머리 + 그 경계에 걸친 남색 알약 이름표. 고른 카드는 위로 떠오르고 그 아래에 청록 "確定" 버튼이 나타난다. 닫기는 진홍 평행사변형 ×.
- **스텔라 소라 스테이지 선택**: 왼쪽 위 흰 원 뒤로가기 + 남색 위치 바(핀 아이콘, 끝이 비스듬함). 왼쪽 흰 알약 목록, 선택은 남색으로 바뀌며 패널 쪽을 가리킨다. 잠긴 칸은 반투명 남색 + 자물쇠. 오른쪽 흰 패널에 적 그림, 청록 평행사변형 "報酬一覧" 꼬리표(반짝이 아이콘). 오른쪽 아래 흰 "掃討"와 청록 "出発".
- **학원 아이돌마스터**: 흰 둥근 칩에 "작은 라벨 + 아주 큰 숫자"("最終まで 4週"), 라벨 밑 얇은 산호색 선과 가운데 작은 마름모. 굵은 남색 테두리의 둥근 HP 바. 진한 그라데이션 정사각 행동 타일(분홍·파랑·노랑) 안에 흰 선 아이콘. 큰 원형 목표 카운터("CLEARまで 30").
- **도트 어비스**: 왼쪽 위 흰 사각 뒤로가기 + 흰 제목, 오른쪽 위 남색 캡슐 자원 바. 파란 선택 탭(사다리꼴). 목록 행은 흰 카드 + 주황 진행 바 + 노란 "受け取り". 퀘스트 카드는 도트 그림 + 남색 제비꼬리 리본 제목. 아래 남색 메뉴 바에 흰 선 아이콘.
- **인디 로그라이트**: 코발트 코어는 남색 우주 + 네온 도트 테두리(정통 도트 UI 재해석 쪽). 와일드프로스트는 나무·종이 같은 사물형 카드, 굵은 외곽선, 따뜻한 갈색 + 눈 흰색 + 청록 결정.

## 3. 공통 규칙과 적용

1. **캐릭터가 주인공, UI는 가장자리.** 홈은 캐릭터가 가운데, 메뉴는 오른쪽 원형 버튼 무리, 큰 출발 버튼은 엄지 닿는 아래. → 관측소를 홈 화면으로 재배치: 리더가 방 가운데 서고 다음 목표를 말풍선으로 말한다. 행선지·동료·수첩·기록은 오른쪽 원형 버튼(도트 아이콘 + 남색 외곽선 이름). 아래에 오늘의 균열 배너와 출발 티켓.
2. **두 가지 바탕: 남색 구조 + 흰 내용.** 위치 바·제목 띠·선택 상태·메시지 띠는 남색(#29266a), 끝은 비스듬히 자른다. 카드·시트·목록은 흰 종이. 바탕은 어둡지 않은 새벽 하늘 그라데이션(하늘색→라벤더→연분홍) + 도트 반짝이 무늬.
3. **주 행동 하나만 진한 색.** 청록 그라데이션 + 아래 턱 + 흰 글자 + 주기적인 빛 훑기. 보조는 흰 버튼, 보상·유품은 금색, 위험은 산호색.
4. **제목 띠·꼬리표·리본.** 남색 평행사변형 위치 판에 작은 영문 키커(OBSERVATORY, DESTINATION…). 시트 제목도 같은 판. 소제목은 반짝이가 달린 청록 평행사변형 꼬리표. 이벤트 대화창은 남색 이름표가 걸친 흰 상자(비주얼 노벨식).
5. **큰 숫자.** 기술 타일은 종류 색 기둥 + 이름 + 아주 큰 예측 숫자(종류 색) + MP 알약. HP 바는 남색 테두리의 둥근 바.
6. **선택은 떠오름 + 청록 테두리.** 고른 카드·문·좌석은 위로 뜨고 청록 고리가 생긴다.
7. **도트 접목.** 캐릭터·배경·아이콘은 도트 그대로(배경은 흰 테두리 둥근 창 안), 장식은 도트 반짝이(4각 별), 전투 피해 숫자·HP 숫자는 도트 글꼴(Galmuri). 그 밖의 글자는 둥근 제목체(주아) + 본문 고딕(Noto Sans KR).
8. **연출.** 화면이 바뀔 때 남색 띠(청록 테두리 + 반짝이)가 가로로 훑고 지나간다. 문·선택지·행선지 카드는 차례로 떠오른다. 시트는 아래에서 튀어 오르며 뒤를 어둡게 한다. 메뉴의 말풍선·해금 알림은 통통 튀며 나온다.

## 4. 흐름·배치에서 바꾼 것

- 관측소: 세로로 쌓인 버튼 5줄 → 홈 화면(말풍선, 원형 메뉴, 균열 배너, 행선지 그림이 붙은 출발 티켓). "행선지 바꾸기"는 망원경 원형 버튼으로 옮김(망원경 클릭도 그대로 됨).
- 타이틀: 어두운 상자 → 밝은 하늘에 로고("너"만 분홍으로 크게), RELAYMARE 남색 리본, 표어 알약, 숲길에 선 일행, 큰 청록 시작 버튼.
- 행선지: 작은 썸네일 행 → 스테이지 카드(배경 그림 띠 + 남색 이름판 + 보스 얼굴 원 + 생환 도장).
- 탐험 지도: 층 진행을 알약 트랙으로(지나온 층 남색, 지금 층 청록), 문 카드는 종류 색 띠와 실루엣 타일, 보상 알약.
- 전투: 흰 적 정보판(종류 알약, 의도 줄), 흰 동료 칩(지금 순서 청록 고리), 남색 자막 띠, 기술 타일. 상단 바가 좁아서 전투 중에만 전체화면 버튼을 숨김(다른 화면에는 그대로).
- 게임 규칙, 수치, 문구, 버튼 순서, 저장 형식은 바꾸지 않았다.
