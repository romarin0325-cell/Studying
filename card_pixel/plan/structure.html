카드 리뉴얼 · 구조 지도

공용 전투 규칙에서 도트 시험판까지. 실제 읽는 파일과 전달하는 자료를 기준으로 정리했습니다.

한눈에변경 영향그림 경로확인 방법계획과 내역담당미확인

1한눈에

상자를 누르면 그곳을 바꿀 때 영향을 받는 곳이 남습니다. 한 번 더 누르거나 전체 보기를 누르면 돌아옵니다.

선택한 곳: 굵은 테두리 · 영향받는 곳: 밝게
상자를 선택하면 역할과 전체 파일 경로가 여기에 나옵니다.

아래로: 규칙 → 연결 → 원정 → 화면 → 제작 결과. 오른쪽: 다른 카드 화면·그림·검사. 화살표는 자료 전달과 파일 읽기를 나타냅니다.

상자 안 경로에서 card_pixel/slice/는 생략했습니다. 번호별 화살표 설명:

  1. 공용 전투 규칙 → 카드 화면 다섯 개
    다섯 화면의 제작 명령이 공용 규칙을 읽음
  2. 공용 전투 규칙 → 규칙 묶음
    변경하지 않은 전투 규칙 네 파일
  3. 규칙 묶음 → 전투 연결층 · A–H
    전투 계산과 진행 함수
  4. 규칙 묶음 → 동료 목록·출현 후보
    카드·적·기본덱 자료
  5. 전투 연결층 · A–H → 일곱 층 원정·경제
    난수 함수·꿈의 변덕·적 접두사 목록
  6. 동료 목록·출현 후보 → 일곱 층 원정·경제
    동료 후보와 생성한 적
  7. 일곱 층 원정·경제 → 화면·선택·사건 재생
    층·문·보상과 원정 상태
  8. 전투 연결층 · A–H → 화면·선택·사건 재생
    상태·행동 후보·순서 있는 전투 사건
  9. 화면·선택·사건 재생 → 무대·카메라·소리
    사건에 맞춘 그리기·카메라·소리 명령
  10. 무대·카메라·소리 → 한 파일로 만들기
    무대 코드 원문
  11. 화면·선택·사건 재생 → 한 파일로 만들기
    화면 코드와 꾸밈 원문
  12. 한 파일로 만들기 → 플레이하는 시험판
    규칙·화면·그림을 넣은 한 문서
  13. 그림 원본·자르기 → 게임용 그림·치수
    대기·공격·피격 그림과 치수 자료
  14. 게임용 그림·치수 → 동료 목록·출현 후보
    대기 그림의 유무·방향으로 후보를 거름
  15. 게임용 그림·치수 → 무대·카메라·소리
    제작 때 넣은 그림·몸 중심·발 기준
  16. 규칙 묶음 → 규칙 검사·자동 플레이
    규칙 검사에 실제 전투 규칙을 제공
  17. 일곱 층 원정·경제 → 수치 모의 실행
    화면과 같은 원정 함수·경제 규칙
  18. 플레이하는 시험판 → 규칙 검사·자동 플레이
    자동 플레이가 읽는 제작 결과

2바꾸면 어디까지 가나

직접 읽는 곳과 그 뒤로 이어지는 곳입니다. 제작 결과는 해당 명령으로 다시 만들어야 바뀝니다. 그림 변화는 실제 그림을 쓰는 시험판에 반영되며, 가짜 그림 목록을 쓰는 모의 실행에는 반영되지 않습니다.

3그림이 게임에 들어가는 길

  1. 생성 기록

    card_pixel/art/prompts.md

    입력
    그림 지시문·참고 그림

    결과
    card_pixel/art/strips/의 세 자세 원본과 manifest.json의 상태 기록; 생성 도구 자동 연결은 확인되지 않음

  2. 선별·자르기

    node card_pixel/slice/tools/cut-sprites.mjs

    입력
    manifest.json에서 status가 ok인 원본만

    결과
    자세별 그림과 sprites.json; 배경 제거·분리된 조각 제거·32색 정리·몸 중심과 발 기준 계산

  3. 크기 맞추기

    card_pixel/slice/tools/cut-sprites.mjs

    입력
    대기 자세의 높이를 기준으로 세 자세에 같은 배율 적용

    결과
    동료 72점·생물 48/64/80점·보스 104점 높이 기준; 현재 187장에는 분리된 ash-fx.png도 포함

  4. 문서에 넣기

    node card_pixel/slice/build.mjs

    입력
    slice/assets/의 그림과 sprites.json

    결과
    RelaySlice.html 안의 RELAY_ASSETS; 목록·무대·화면이 함께 읽음

  • 이 페이지의 휴대폰·데스크톱 화면은 Claude가 설치된 Chrome으로 찍어 확인했다(2026-11-18). 도표는 휴대폰에서 상자 안에서 가로로 스크롤된다.
  • 이 지도 작업에서는 게임 규칙 검사·모의 실행·시험판 제작·자동 플레이를 실행하지 않았다. 소요 시간은 명령의 작업 범위로 추정했으며 측정값이 아니다.
  • manifest.json의 ok는 자르기 대상 상태다. 그림의 최종 품질·잘림·방향·보스 크기와 생성부터 등록까지의 자동 연결은 확인하지 않았다.
  • 영향 표는 읽는 코드와 전달되는 자료를 기준으로 한다. 공용 전투 규칙 네 파일 밖의 card/game 파일이 모두 시험판에 들어가는 것은 아니다. 이미 만든 게임 문서는 해당 제작 명령을 다시 실행해야 바뀐다.
