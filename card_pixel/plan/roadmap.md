# v1 이후

## v1에 들어간 것

- 새벽의 숲 입문 5층, 테마 던전 5곳과 창조의 탑 각 8층. 본편 여정 첫 클리어로 악몽 해금, 탑 격파로 엔딩.
- 3인 릴레이·예고·물러나기·원정 중 영구 사망, 유품·최후의 일인·꿈의 변덕·접두사, 지역 규칙 5종.
- 사건 28종, 유물 14종(장착 4칸), 소환의 샘과 혼돈의 제단.
- 관측소, 생환 영입·대표·동행·인연·봉인, 도감·수첩 7장·기록, 방 사이 저장과 이어하기.
- 캐릭터 3포즈 도트, 던전·관측소 배경, 합성 배경음 12곡.

## 소유자 확인

v1의 Claude 판단과 근거는 [v1 결정 기록](v1-decisions.md), 구현과 검수 경과는 [11월 20일 작업 기록](../history/2026-11-20.md)에 있다.

| 질문 | 현재 상태 |
|---|---|
| Galmuri 글꼴을 내장할까 | **내장함**(11-21 소유자 승인). Galmuri9·11·14 woff2(약 1.5MB)를 `game/assets/fonts/`에 두고 빌드가 페이지에 넣는다. 인터넷 없이도 같은 글꼴. 페이지 3.7→5.7MB. 필요한 글자만 추리는 축소는 도구(fontTools 등) 설치가 필요해 하지 않았다 |
| 에인션트소울 도트를 다시 만들까 | **보류(11-21 소유자).** 도트 전반을 추후 재확인할 예정이라 지금은 유지. 일러스트 자체가 여성형이고 컨셉 문서는 남성이라, 재확인 때 기준을 정한다 |
| 배경음 12곡을 그대로 쓸까 | **유지(11-21 소유자: "사운드는 나쁘지 않다").** 마스터 -10dB. 곡 구조 점검은 빠진 효과음 보완에만 쓴다 |
| 본편 시작 수치를 유지할까 | 골라 깨우기 2명 + 무작위 3명, 결정 1. 대표가 있으면 대표 1명 + 직접 선택 1명 + 무작위 3명(4.6) |
| 첫 본편 난이도는 적당한가 | 시뮬레이션 목표는 클리어율 60~70%였고, 편성을 바꾸지 않은 Chrome 봇은 본편 네 판 모두 보스에서 졌다. 홍련 화산·황혼 성당은 직접 플레이해 판단한다. [v1 검토 페이지](v1-review.html) |
