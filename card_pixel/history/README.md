## 위임과 작업 도구

- [모델 위임 기록](model-log.md)은 일과 모델·걸린 시간·판정·누락을 연결한다. 11월 15~19일 조사·파일럿·리뷰 대응, 20일 v1 제작, 21~22일 검수·입장권 작업을 따라갈 수 있다.
- [작업 지침](../AGENTS.md)은 소유자 결정, Claude의 방향·검수, GPT의 명세 기반 구현·테스트 역할과 변경별 검증 명령을 설명한다. [게임 README](../game/README.md)는 배포 HTML·런처, 엔진·도구·갤러리를 찾는 입구다.
- [초기 기획서](../plan/renewal-plan.html)와 [초기 구조도](../plan/structure.html)는 시험판 시점의 기록이다. [원본 대비 규칙 검수](../plan/changes-review.html)는 현행 규칙·콘텐츠 검수용 생성 페이지이며, 결정 근거는 [장부](../plan/v1-decisions.md)에 있다.

작업 공간 지도의 시간순 기록은 한국·일본 시각(UTC+9) 기준이고, PR의 원본 시각과 `generatedAt`은 UTC다. 파일의 최초·마지막 날짜는 기준 HEAD에서 `git log --follow`로 확인한 커밋 작성일이다. 폴더에는 경로 이력을 쓰며 `tracked`는 하위에 추적 파일이 있음을 뜻한다. `grouped`가 있는 폴더는 하위 파일을 묶었고, `location`은 현재 작업 트리 밖에서 확인한 위치다.

작업 이력을 추가할 때는 작업 날짜, 소유자 지시 또는 판단 근거, 관련 커밋·PR, 확인한 범위와 남은 확인을 적는다. 측정값과 추정값을 구별한다. 소유자 원문은 `feedback/`에, 자문 전문은 `consults/`에, 위임 평가는 `model-log.md`에 남긴다.
