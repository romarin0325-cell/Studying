# 글꼴

`Galmuri9.woff2`, `Galmuri11.woff2`, `Galmuri14.woff2`는 Galmuri 2.40.3(quiple, https://github.com/quiple/galmuri)이다. npm 패키지 `galmuri@2.40.3`의 `dist/`에서 받았다(2026-11-21, 소유자 승인).

SIL Open Font License 1.1로 배포된다. 게임에 넣어 함께 배포할 수 있고, 저작권·라이선스 고지는 각 글꼴 파일의 메타데이터에 들어 있다. 라이선스 전문: https://cdn.jsdelivr.net/npm/galmuri@2.40.3/dist/LICENSE.txt

`build.mjs`가 세 파일을 `@font-face` 데이터 URL로 페이지에 넣는다. 그래서 인터넷이 없어도 같은 글꼴로 보인다.
