# DREAMWEAVER Legacy

기존 `card/game/index.html`의 어두운 UI를 유지하면서 현재의 공통 게임 규칙·카드·학습 데이터·저장을 사용하는 단일 HTML입니다. 별도로 복제한 옛 데이터는 사용하지 않습니다. 루멘·아스트라와 같은 소스를 빌드하므로 신규 공통 데이터와 게임 기능도 함께 반영됩니다.

```sh
npm run build:card-legacy
```

결과물은 `card_legacy/dist/DREAMWEAVER-Legacy.html`입니다. HTML 하나에 모든 코드와 학습 데이터, CSS를 포함하며, 서버나 CDN 없이 브라우저에서 직접 열 수 있습니다. 기존 초상화 PNG와 음악·리스닝 MP3는 HTML 옆에 둡니다.

전체 화면 버튼은 모든 화면의 오른쪽 위에 있습니다. 모바일에서는 브라우저의 표시 높이와 안전 영역을 따르고, 긴 메뉴와 대화창은 안쪽에서 스크롤할 수 있습니다.

타이틀 또는 게임 메뉴의 **기록 옮기기**에서 기록 파일을 내보내고 가져올 수 있습니다. 진행 중인 게임은 먼저 저장하세요. 루멘·아스트라와 같은 백업 형식이며, API 키를 제외한 해금·게임 진행·학습 기록을 옮깁니다. 파일 경로가 바뀌면 브라우저의 저장 영역도 달라질 수 있으므로 세 UI의 기록이 자동으로 동기화된다고 가정하지 마세요.

`build.mjs`는 공통 HTML의 로더에 선언된 스크립트 목록과 로컬 CSS를 직접 읽습니다. `src/legacy.css`와 `src/legacy.js`에는 레거시 화면의 배치·전체 화면·기록 이동 버튼만 둡니다.
