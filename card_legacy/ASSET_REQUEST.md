# 생성된 UI 이미지 사양

아래 이미지는 로컬에 생성되어 `UI_ASSETS`와 연결되어 있습니다. 배경은 CSS 오버레이와 함께 사용하며, 이미지를 제거하고 매니페스트 값을 `null`로 되돌려도 기존 CSS 폴백이 유지됩니다. `statusAtlas`는 실제 파일이 없으므로 계속 `null`입니다.

| 파일 | 크기 | 형식 및 조건 | 권장 용량 |
|---|---:|---|---:|
| `ui_title_bg.png` | 720×1280 | 불투명, 글자 없음, 중앙 55% 낮은 대비 | 900KB 이하 |
| `ui_hub_bg.png` | 720×1280 | 불투명, 어두운 마도서관, 카드 패널을 방해하지 않는 대비 | 700KB 이하 |
| `ui_battle_bg.png` | 720×1280 | 불투명, 좌우 캐릭터 영역 낮은 대비, 중앙이 빈 전투 무대 | 700KB 이하 |
| `ui_panel_9slice.png` | 192×192 | 투명 PNG, 모서리 보호 32px, 금속/마도서 장식 프레임 | 150KB 이하 |
